# 萨迦格言 · 结构化知识库与白话全书

《萨迦格言》（萨迦班智达·贡噶坚赞，1182—1251，13 世纪）的**汉译九品全文、逐品精解、459 颂逐颂白话**，以及一套让 AI 按该技能规范回答问题的工具链。

本项目既可以直接阅读，也可以作为 AI 的「知识技能（skill）」挂载使用：把 `SKILL.md` 交给支持 skill 的客户端，提问时它会按第 1—9 品判断框架作答，并遵守「引颂标品号、原文必配白话、正反成对、不虚构」等规范。

### 白话全书

每颂两行，格式固定：

```
**1.2** 无论有或无学问，能知取舍为智者，犹如铁屑混灰尘，磁石方能吸出彼。
→ 白话：读没读过书不算数，能在一堆东西里挑出该要的那条才算本事——磁石吸铁不吸灰。
```

白话只做**直译＋喻体落地**，不加感悟、不掺义理解释；13 世纪语境（种姓、女性、轮回）照原译写出并标注「取其原则，不取对象」。

- **在线读全书**：<https://zhikedan.github.io/sakya-gnomic-verses/>（搜索＋按品筛选，无需下载）
- [白话全书/萨迦格言-原文白话全本.html](白话全书/萨迦格言-原文白话全本.html) — 同一份内容的本地单文件版，双击即开，可离线、可发手机（仓库根的 `index.html` 是它的副本，由 `node build_baihua.js` 生成，勿手工改）
- [白话全书/萨迦格言-原文白话全本.md](白话全书/萨迦格言-原文白话全本.md) — 合并全本（含目录）

## 快速开始

```bash
node check_baihua.js     # 459 颂：逐字比对原文、每颂配白话、无漏颂
node check_refs.js       # 引用编号真实性、翻译残留、九品一览覆盖
node test_core.js        # 抽取/合并/去重/统计内核
node test_commit.js      # 问答入库端到端（在临时目录跑，不碰真实台账）
node record.js rebuild   # 重建问答台账 .md / .html
node build_baihua.js     # 重建白话全书 md / html
```

或一次跑全部：

```bash
npm test
```

只需要 [Node.js](https://nodejs.org/)（≥ 18），无第三方依赖。

## 问答留痕

`record.js` 把「提问 + 按技能规范给出的回答」逐条落盘，并重建可读台账。规则写在 [SKILL.md](SKILL.md) 第七节：答案末尾必须有独立一行 `动作：…`，颂号以 `20-全文.md` 校验，白话逐颂配齐。

```bash
# 1) 写 问答记录/pending.txt（首行「问：…」，其余为答案）
node record.js commit          # 入库并重建台账
node record.js todo            # 看还没做到的动作
node record.js done 3 已做到   # 打勾
node record.js stats           # 类型分布、动作完成率、白话覆盖
```

> **回看标准是「动作做到几条」，不是「读了多少颂」。**

`问答记录/` 里的 `qa.json`、`问答记录.md`、`问答记录.html` 目前是**格式示例**。它们被 `.gitignore` 排除，使用者的真实问答只留在自己机器上。`node record.js rebuild` 可随时从示例重建。

```
├── 白话全书/             逐颂原文＋白话、合并全本、网页
└── 问答记录/             问答台账（本地数据，已忽略）
```
