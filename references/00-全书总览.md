# 《萨迦格言》全书总览

> **底本**：用户提供的九品汉译本（《格言宝藏论》系统，四句一颂，共九品）。
> **作者**：萨迦班智达·贡噶坚赞（1182—1251），藏传佛教萨迦派第四祖，人称「萨迦班智达」（萨迦大智者）。他通晓声明、因明、工巧、医方、内明五明，是西藏第一位获「班智达」称号的学者。
> **成书**：13 世纪，萨迦寺。是藏族文学史上第一部**格言体哲理诗集**，被誉为「藏地的《论语》」。
> **体量**：九品，约四百五十余颂；每颂四句，句式为七言（汉译），以**比喻＋判断**为基本结构。
> **性质**：不是佛经，也不是纯文学，而是一部**世俗伦理与修行次第合一的格言集**——前八品讲世间法（如何做学者、如何辨人、如何处事），第九品讲佛法（如何修行、如何面对死亡）。

---

## 一、全书骨架（九品）

```
第一品 观察学者   —— 什么是「智」，学问为何是第一德
第二品 观察正士   —— 什么是「正士」（高尚者），其行相与果报
第三品 观察愚者   —— 什么是「愚者/劣者」，其种种丑态与成因
第四品 观察多士   —— 贤愚混杂之世，如何分辨、如何取舍
第五品 观察恶行   —— 恶的形态学：狡诈、忘恩、两舌、嗔恨
第六品 观察性情   —— 人性与处境：傲慢、贪欲、亲疏、盛衰、因果
第七品 观察非理   —— 不合理之行：越分、放逸、颠倒、积而不施
第八品 观察事业   —— 做事之法：谨慎、协商、择友、用人、收税、施政
第九品 观察佛法   —— 出世间：知足、布施、无常、死亡、闻思修
```

**结构上的三层递进**

```
第一层 认识人（第1—4品）
   学者／正士／愚者／多士 —— 建立「贤愚之辨」的判断力
        ↓
第二层 认识行（第5—7品）
   恶行／性情／非理 —— 从「是什么人」到「会做什么事」，看清行为模式与后果
        ↓
第三层 认识事与法（第8—9品）
   事业／佛法 —— 从「看清」到「做成」，再到「超越」
```

> 一句话概括全书逻辑：**先学会看人（1—4），再学会看事（5—7），然后学会做事（8），最后学会超越（9）。**

## 二、六条贯穿全书的主线

### 主线1：贤愚之辨——全书的骨架
- 每一品几乎都在做同一件事：**把「智者/正士」与「愚者/劣者」并置**，用同一个比喻的两面照出差别。
- 判断标准不是出身、财富、地位，而是：**有无学问、能否取舍、是否利他、有无羞耻、能否知足**。
- 典型句式：「……者，……；犹如……，……。」

### 主线2：学问至上——第一品立下的价值排序
- 「即使明早要死亡，亦应学习诸知识」——学问被置于生命之上。
- 学问的三个层次：**广闻（学）→ 观察（思）→ 取舍（行）**。
- 学问的社会功能：学问不是装饰，而是**让人在世间能自立、能利他、能辨识**的工具。

### 主线3：取舍（知进退）——全书最实用的能力
- 「无论有或无学问，能知取舍为智者」——**知取舍**被定义为智者的第一标志。
- 取舍的具体对象：**境（该不该去）、人（该不该交）、事（该不该做）、财（该不该取/施）、言（该不该说）、时（该不该现在做）**。
- 反面：愚者不是不努力，而是**在不该处用力**（「愚者不至所需处，反而常诣无用处」）。

### 主线4：利他与布施——德性的落点
- 判断一个人高低，最终看他是**损人利己、自利不损人，还是利他而成自利**。
- 布施被反复强调：第九品用大量篇幅讲「悭者不会成富裕，施者不会成贫困」。
- 利他不是道德说教，而是**因果意义上的投资**：「若欲专为私利者，彼者先应利他人。」

### 主线5：无常与因果——全书的底色
- 无常：财富、权势、亲友、青春、生命，无一可恃（第6、7、9品反复出现）。
- 因果：盛衰、苦乐、贤愚、遇合，皆由业感（「何处有缘彼兴盛，若无业缘彼衰退」）。
- 二者合起来构成一种**清醒的乐观**：不因顺境而慢，不因逆境而馁，因为一切都在变，而变有其因。

### 主线6：世俗与出世的统一
- 前八品讲「如何在此世做好一个人」，第九品讲「如何超越此世」。
- 二者不矛盾：**世间法是修行的基础**（「了知教法未修行，则彼教法有何用？」），出离心是世间智的完成（「若执恒常真毁己」）。

## 三、体裁与读法：三重解码

《萨迦格言》每颂都是一个「微型论证」，读的时候要拆三层：

| 层次 | 问什么 | 例（第一品） |
|---|---|---|
| **喻** | 这个比喻在讲什么自然现象？ | 「如海即是江河库，是故百川流大海」 |
| **理** | 由喻到人，推出什么命题？ | 智者如海，故能容纳一切学问 |
| **用** | 对我当下的处境，意味着什么？ | 我是否因「已有所知」而停止吸收？ |

> 只读到「喻」是看热闹，读到「理」是懂文意，读到「用」才算用它。

## 四、各品一句话主旨

| 品 | 一句话 | 关键词 |
|---|---|---|
| 1 观察学者 | 学问是一切德行的根，学而无厌、学而能用者才是智者 | 学、观察、取舍 |
| 2 观察正士 | 正士的标准是「德性稳定」：衰不失态、困不改节、受恩必报 | 稳、报恩、守节 |
| 3 观察愚者 | 愚者的本质不是笨，而是「不辨善恶、不受教化、自以为是」 | 傲慢、嫉妒、盲从 |
| 4 观察多士 | 世上多是贤愚混杂，要看他「遇事、遇财、遇难」时的反应 | 分辨、检验、亲疏 |
| 5 观察恶行 | 恶的可怕在于「伪装」：甜言、假善、慢报恩、暗怀恨 | 狡诈、两舌、忘恩 |
| 6 观察性情 | 性情决定命运：傲慢招损、贪欲招耻、亲疏无常、盛衰有因 | 慢、贪、亲疏、盛衰 |
| 7 观察非理 | 五种「速毁之因」与种种颠倒，都是「不知分际」 | 越分、放逸、颠倒 |
| 8 观察事业 | 成事五要：谨慎、协商、择友、用人、知时 | 谨慎、协议、善友 |
| 9 观察佛法 | 知足、布施、无常、闻思修——从世间走向解脱 | 知足、施、无常、修 |

## 五、它适合用来做什么

| 场景 | 用法 |
|---|---|
| **自我修养** | 每日取一颂，按「喻—理—用」三层写三句话，月底回看 |
| **识人用人** | 第3、4、5品是最好的「人品识别清单」，可提取为观察指标 |
| **管理与领导** | 第6、8品大量讲国王、长官、眷属、赋税，是古代的「治理手册」 |
| **教育与家教** | 第1、3、9品讲学与不学、教与不教，可直接用于劝学 |
| **逆境与抉择** | 第2、6、7品讲衰败、亲疏、取舍，适合失意时读 |
| **写作与演讲** | 比喻库（见 `11-比喻意象词典`）可直接化用 |

**不建议**：把它当「成功学语录」抽取单句。它的每条判断都依赖**对比结构**——只取半句容易变成反面的教条（例如只取「柔和能胜粗暴」，忽略「粗者方能调粗暴」）。
