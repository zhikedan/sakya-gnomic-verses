# 现代应用手册

> 把九品格言转成**可执行的动作**。每一节：常见困境 → 格言给的原则 → 今天能做的动作。
> 使用方式：先找自己的困境，只做"动作"那一栏，不要停在"原则"上。

---

## 一、职场：如何被看见、又不招祸

| 困境 | 原则 | 动作 |
|---|---|---|
| 干得多却没人知道 | 德藏而香自远（2.12）；但也需"形式"（6.25 蝙蝠无羽） | 每月做一次"成果外化"：一页纸写清做了什么、解决了什么 |
| 一有成绩就想说 | 小富即露慢（6.19）；多语招过（6.36） | 成绩先说给一个人听，再决定是否公开 |
| 被抢功 | 智者以慧护自己（1.11） | 事前留痕：邮件确认分工，会议纪要署名 |
| 遇到抢功/甩锅的人 | 明敌易制，暗恨难防（5.39） | 不与之争口舌，改为"把事实写在公开处" |
| 被无端批评 | 毁誉不动（2.24）；不进入对方战场（2.22） | 只回应事实部分，情绪部分不接 |
| 想跳槽又怕 | 未察新境，不弃旧境（8.28） | 新机会先做"三个月预演"：找到人、问到细节、算清代价 |

## 二、管理：从"管住"到"护住"

| 困境 | 原则 | 动作 |
|---|---|---|
| 团队不服 | 权力来自"护"（2.19、2.27） | 本季度为团队挡下一次不合理要求，并公开说明 |
| 看不到自己的问题 | 高位者缺镜子（6.1） | 设一个"固定反对者"，每月一次只挑毛病 |
| 下属能力不行 | 委托予所知（8.63）；善教可变愚（8.7） | 先调岗到其长处，再给一次针对性训练 |
| 团队人数多但不成事 | 芨草捆不成柱（3.26） | 砍掉冗余协作，明确三个"柱"（关键角色） |
| 只会做好人 | 柔能胜刚，但该粗则粗（8.25、8.34） | 为一件必须纠正的事，准备一次"硬对话" |
| 指标压得太狠 | 香脂过流则树枯（8.21） | 给团队留 20% 余量，明确"不做什么" |

## 三、合作与创业：先想散，再想合

| 困境 | 原则 | 动作 |
|---|---|---|
| 朋友合伙，不好意思谈钱 | 小事亦协议（8.1） | 写一页"散伙条款"：怎么分、怎么退、怎么算 |
| 涉及机密的事知道的人太多 | 险事协商不过三（8.70） | 把知情圈缩到 3 人，其余人只知"需要知道的" |
| 找不到靠谱伙伴 | 成大事靠善友（8.93） | 列出"懂且愿帮"的 5 个人，逐个真实求助一次 |
| 旧怨和解了，要不要深交 | 旧怨虽和莫密切（8.64） | 保持合作，不交底；用事实验证而非情感 |
| 有人来投靠但人品可疑 | 寡情者来投，稍施即遣（8.88） | 给一次性帮助，不给长期位置 |

## 四、交友与亲密关系：留白与同心

| 困境 | 原则 | 动作 |
|---|---|---|
| 关系越近越容易烦 | 甘蔗常食则厌（6.5） | 主动制造距离：每周留一天不联系 |
| 对人太好反被怨 | 过慈成怨（6.30） | 把"无条件付出"改为"有节奏的付出" |
| 分不清谁是朋友 | 财尽友散（4.10） | 回想"你没用的时候，谁还在" |
| 总想改造对方 | 劣者不可化（7.24） | 停止说服，改为设定边界 |
| 被亲近的人伤 | 大者之害多来自内部（7.5） | 对内部人也要有"规则"，不只靠情分 |

## 五、教育子女与自我学习

| 困境 | 原则 | 动作 |
|---|---|---|
| 孩子不爱学 | 以不学为耻（9.40）；善教可变（8.7） | 不讲道理，做一次"一起学 30 分钟" |
| 学了很多用不上 | 知而不行，论典何用（9.50） | 每读完一份材料，写一个"明天改的动作" |
| 学习焦虑、贪多 | 一门通世间（1.9） | 砍到一门，学到能"照路"为止 |
| 年纪大了不想学 | 老亦广学（8.3） | 每天记一句（9.51），只记一句 |
| 孩子骄傲 | 蹄窝易满（3.13） | 给一个"比他强的人"的真实反馈 |

## 六、自处：情绪、欲望、逆境

| 困境 | 原则 | 动作 |
|---|---|---|
| 生气时想说狠话 | 嗔即自焚（6.38）；恶语难愈（5.40） | 24 小时规则：写成草稿，不发 |
| 总想赢过某人 | 灭自嗔即灭诸敌（9.26） | 把"赢他"改成"不受他影响" |
| 钱总不够 | 知足用不尽（9.3） | 写下"够"的具体数字 |
| 舍不得花也舍不得给 | 不享不施是病（7.13） | 设三个出口：享 10%、施 10%、投 80% |
| 失意时自我怀疑 | 火把下垂焰仍向上（2.6） | 只做一件事：把标准守住，别降 |
| 同时开太多事 | 多事者无成（7.29） | 砍到三件，其余写进"暂不做清单" |
| 焦虑未来 | 见河脱鞋（7.42） | 把焦虑分成"现在可动/不可动"两栏 |

## 七、说话：一份发言前自检表

按顺序问五句（出自第5、6、8品）：

1. **是真的吗？**（8.32 恶语如回声）
2. **应时吗？**（8.48 语不合时，众人欺凌）
3. **合境吗？**（8.30 非合境不说人过）
4. **有必要说吗？**（6.36 多语招过）
5. **说了能改善什么？**（8.82 利自他之事方可说）

> 五问过不了三问，就不说。

## 八、决策：一张"分际"清单

做重大决定前，按第7品的"五速毁之因"过一遍：

| 检查项 | 问句 |
|---|---|
| 能力边界 | 这件事超出我能承担的范围了吗？ |
| 树敌 | 会不会因此与太多人结怨？ |
| 赌气 | 我是在做事，还是在争强？ |
| 轻信 | 我依赖的关键信息/关键人，核实过吗？ |
| 同伴 | 我选的合作者，是"善友"还是"恶友"？ |

再加两问（第8品）：

- 如果失败，损失我承受得起吗？（8.1 协议）
- 现在是最好的时机吗？（7.42 见河脱鞋）

## 九、把格言用成"日常仪表盘"

每周选一格，只盯一个指标：

| 周主题 | 观察指标 | 出处 |
|---|---|---|
| 取舍周 | 这周我拒绝了什么 | 1.2 |
| 守节周 | 失意时有没有降标准 | 2.6 |
| 慎言周 | 说错几句话 | 6.36 |
| 施与周 | 给出去了什么 | 9.6 |
| 知足周 | 想买而未买的东西 | 9.3 |
| 精进周 | "等有空"的事做了几件 | 9.35 |
| 灭嗔周 | 发火几次、持续多久 | 9.26 |

> 一年 52 周，够把这九品过五遍。
