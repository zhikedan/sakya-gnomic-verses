# 第一品 观察学者　（30 颂）

**1.1** 智者即是学问库，彼等收集格言宝，如海即是江河库，是故百川流大海。
→ 白话：有智慧的人本身就是一座知识仓库，好的道理都往他那儿聚；就像海是江河的仓库，所以百川统统流进海里。

**1.2** 无论有或无学问，能知取舍为智者，犹如铁屑混灰尘，磁石方能吸出彼。
→ 白话：读没读过书不算数，能挑出该要的、扔掉该扔的，才算聪明。铁屑和灰尘混在一堆，只有磁石能把铁吸出来。

**1.3** 智者以慧知格言，然而愚者非如是，犹如阳光普照时，鸱鸮皆成盲眼也。
→ 白话：同一句好话，聪明人读出道理，糊涂人只看见字。就像太阳出来，人见光明，猫头鹰反倒瞎了眼——条件一样，接收的人不一样。

**1.4** 智者能除诸过患，然而愚者非如是，大鹏能啄有毒蛇，乌鸦不能如是行。
→ 白话：毛病和祸患，聪明人治得了，糊涂人治不了。大鹏鸟敢去啄毒蛇，乌鸦干不了这事。本事得配得上要解决的问题。

**1.5** 智者即使受挫折，彼智更加成顽强，犹如兽王饥饿时，速能撕裂大象脑。
→ 白话：受了挫，聪明人的脑子反而更硬更清楚。像饿了的狮子，出手就能撕开大象。挫折对他是加压，不是断电。

**1.6** 不询不辩于学者，不知学识之深浅，犹如槌子不擂鼓，彼与余物有何异？
→ 白话：不问、不跟他辩，你永远不知道他懂多深。鼓不拿槌子敲，跟一块木头有什么两样——测深浅唯一的办法是敲。

**1.7** 即使明早要死亡，亦应学习诸知识，今生虽不成智者，来世如自取储存。
→ 白话：就算明天就死，今天照样学。这辈子成不了行家，学到的东西也像存起来的财物，将来自己取得回来。学习不因"来不及"就失去意义。（原译依托轮回观；不接受这套框架，可读作：学问会以你察觉不到的方式留存并传下去。）

**1.8** 设若具有真知识，众人自然会集聚，犹如香花虽远方，蜜蜂环绕如云集。
→ 白话：真有本事，人自己会聚过来。花香再远，蜜蜂也会成片飞过去——不用你到处去找人。

**1.9** 智者学习诸知识，究竟一门通世间，愚者虽是见识广，不能照明如星光。
→ 白话：学问要学到能把一件事彻底想通。见得多懂得杂，像满天的星星，照不亮脚下这条路；一盏小灯胜过一堆星。

**1.10** 智者知识虽渊博，亦取他人之微德，长期如是行持者，速成一切智智位。
→ 白话：懂得再多，也照样从别人身上捡一点长处；能长期这么干的人，进步最快。

**1.11** 智者以慧护自己，怨敌虽多亦无奈，如吾仗那婆罗门，彼子一人摧敌众。
→ 白话：聪明人靠判断力保护自己，敌人再多也拿他没办法。像经书里那个婆罗门，他一个儿子就击溃了整群敌人。

**1.12** 愚者争吵哄闹时，智者设法使之静，如水浑浊不清时，澄清宝珠能清之。
→ 白话：一群人在吵，明白人想法子让它静下来。水浑的时候往里放一颗澄清珠，泥沙自己就沉底了。他的作用是让浑水沉淀，不是把水搅得更浑。

**1.13** 智者无论再计穷，绝不迈步愚者道，犹如燕子虽口渴，绝不吸饮落地水。
→ 白话：办法再穷也不走蠢路。燕子再渴，也不喝落在地上的那口水。看一个人聪明不聪明，就看他走投无路时选什么。

**1.14** 智者虽然被人骗，亦不入迷诸事业，含生蚂蚁虽无眼，较与有眼者更快。
→ 白话：上过当，也不因此把该做的事搞糊涂。蚂蚁看不见路，走得比看得见的人还利索。被骗一次，不等于要丢掉方向感。

**1.15** 若二智者共商议，则将生出善智慧，姜黄硼砂配一起，便会变出余色彩。
→ 白话：两个明白人商量，会长出比两人各自都更好的判断。姜黄和硼砂搁到一起，会调出第三种颜色——结果不等于两样东西相加。

**1.16** 具备智慧造福者，一人亦能胜一切，犹如狮子转轮王，彼等不需友相助。
→ 白话：又有智慧又能给人好处的，一个人也顶用。像狮子和转轮王，不靠帮手。

**1.17** 若有善巧方便法，役使大者亦不难，如同大鹏高本领，亦成毗纽天之骑。
→ 白话：会想办法，使动比你强的人也不难。大鹏鸟本事通天，也只是毗纽天（毗湿奴）的坐骑——本事挂在别人的需要上，才叫杠杆。

**1.18** 求得今生来世乐，皆为依靠智慧力，达瓦王子用智慧，拯救暂桑今来世。
→ 白话：眼前和长远的安稳，都靠智慧挣来。像达瓦王子凭智谋救了整个地方，连后人跟着受益。

**1.19** 即使英勇又顽强，若非智者难得盛，即使获得诸财富，若无福份岂能常？
→ 白话：又勇又猛，但没脑子，很难真正成事。钱拿到了也守不住，不会长久。

**1.20** 谁能了知过与德，智者方能辨彼二，从牛挤奶皆能会，由水分奶唯天鹅。
→ 白话：谁能分清毛病和好处？只有明白人。牛奶谁都会挤；可把混在一起的奶和水分开，只有天鹅办得到。

**1.21** 即使嘱咐又催促，虽是傍生亦能知，他人未说亦未催，自觉领会方智者。
→ 白话：要人反复交代、催着才动的，畜生也做得到。不用人说、不用人催，自己就领会的，才是聪明人。

**1.22** 若具智慧虽不说，表情亦能知所想，未尝尼泊尔之榴，看色亦能知滋味。
→ 白话：有智慧的人不开口，看神色也知道他想什么。没吃过尼泊尔的石榴，看颜色就能把味道猜出来。

**1.23** 智者离开自处境，至于余处更受敬，犹如外地宝畅销，岛上岂有彼销售？
→ 白话：明白人离开本地，到别处反而更受尊重。珍宝常常在产地不值钱，运到外地才卖得上价。

**1.24** 智者学时即困苦，贪乐安住不成名，贪图微小逸乐者，彼将不会得大乐。
→ 白话：学的时候本来就苦。贪图舒服的人成不了事；恋着一点小安逸的人，拿不到真正的大好处。

**1.25** 若具智慧虽弱小，有势怨敌亦无奈，兽王虽有强势力，具智兔儿谋杀之。
→ 白话：有脑子，弱小也不怕，势力再大的敌人也拿你没办法。狮子力气那么大，却被一只动了脑筋的兔子弄死。

**1.26** 若知所作同他人，和睦相处即智者，即便傍生同类众，岂非类聚住一群？
→ 白话：知道怎么跟人配合、处得来，就是聪明。连动物都是同类凑在一块儿过活的。

**1.27** 必定发生之事前，对此研究则分清，智者愚者之差别，事后观察即愚者。
→ 白话：一定会发生的事，提前研究清楚，这是聪明；事后才来复盘"我早知道"，这是糊涂。聪明和糊涂的分界线就在这儿。

**1.28** 智者若以善观察，精通知识是学者，鉴别牦牛之大小，愚者亦能非学问。
→ 白话：经过仔细考察才弄通的，才叫学问。一眼看出这头牦牛大、那头小，谁都会，那不算本事。

**1.29** 大海不厌河水多，国库不厌珠宝多，欲者不厌受用多，学者不厌格言多。
→ 白话：海不嫌河多，国库不嫌宝多。贪的人不嫌享受多，做学问的人不嫌好话多。

**1.30** 即使由从孩童前，智者亦要闻格言，气味芬芳之麝香，虽在兽脐亦取之。
→ 白话：哪怕是从小孩嘴里听来的道理，明白人照样学。麝香长在野兽肚脐上，位置不雅，香是真的香——取的是那条道理，不是取它的来源。

# 第二品 观察正士　（28 颂）

**2.1** 正士特意常宣扬，所有高士之功德，马拉雅山檀香味，被风传送于十方。
→ 白话：品行端正的人，总爱把别人的好处讲出去。像马拉雅山的檀香，香气被风送到各个方向——他不藏，也不独占。

**2.2** 若立正士为高官，既能成事又得乐，如宝供于幢顶上，智者称颂境吉祥。
→ 白话：让正派人当官，事情办得成，大家也得好处。像把宝珠供在幡杆顶上，有眼光的人一看就知道这地方要兴旺。

**2.3** 若被暴君残害时，则彼更为念法王，犹如众生受疫时，心里总是念雪水。
→ 白话：被横暴的上司折磨时，人反而更想念讲道理的领袖。就像瘟疫流行那阵子，谁心里都惦记着清凉的雪水。

**2.4** 遭受暴君迫害时，人主法王特护之，如当恶魔缠身时，密咒上师会摄收。
→ 白话：真到了被暴君迫害的关头，讲法的君王反而格外护着你。像人撞见邪祟缠身，这时候有本事的上师才会出手收摄。

**2.5** 正士断除微小罪，劣者大罪亦不断，犹如奶酪清除尘，酒中特为放酒曲。
→ 白话：正派人连小毛病都肯去掉，糊涂人大错也不改。一个像往奶酪里挑干净灰，一个像往酒里故意下曲——方向是反的。

**2.6** 正士虽然遭衰失，行为显得更如法，犹如火把向下垂，火焰一直向上燃。
→ 白话：正派人就算倒了霉，行事反而更守规矩。火把即使被倒着拿，火焰照样往上烧——处境可以往下，标准不必往下。

**2.7** 正士虽然住远方，亦会守护自眷属，天空密布浓云时，地上庄稼更增长。
→ 白话：正派人哪怕离得很远，也照样护得住自己人。天上乌云密布的时候，地里的庄稼反倒长得更欢。

**2.8** 名声今生欢喜因，福份来世欢喜因，此外惟有凭财富，智者绝不生欢欣。
→ 白话：好名声让人这辈子高兴，福德让下辈子高兴。只有钱这一样，聪明人绝不会拿它当快乐的本事。

**2.9** 往后应有远目光，忍苦耐劳不放逸，勤学稳重机灵者，即使奴仆亦为官。
→ 白话：往远处看、肯吃苦、不松劲，又勤学又稳重又机灵——这样的人哪怕眼下是奴仆，也能做到官位。

**2.10** 恒时欢喜发施者，名声如风传诸方，如同乞丐聚施处，愿意赠者将更多。
→ 白话：乐意一直施舍的人，名声像风一样传开。就像乞丐都往肯给的地方聚，越肯给的人，聚到手的越多。

**2.11** 若已施舍不收回，能容劣者之侮辱，受恩虽小亦不忘，此等即是圣者相。
→ 白话：给出去的不往回要，受得了混人的冒犯，别人帮过一点小忙也记着——这三条就是明白人的样子。

**2.12** 正士学问虽隐藏，声望传扬诸世界，犹如密藏豆蔻花，芬香遍于诸四方。
→ 白话：正派人的学问藏着不露，名声却传得开。像裹在里面的豆蔻花，包得再严实，香气照样飘到四面。

**2.13** 国王仅在本国大，智者处处受人敬，花朵仅是一天饰，顶宝永时受供奉。
→ 白话：国王只在自己国内算大，有智慧的人走到哪儿都被敬重。花只能戴一天，头顶的宝珠是长久供着的。判断标准是"有德"，不是"有位"。

**2.14** 弯弯树木果实多，雅驯孔雀尾屏美，驯良骏马行道快，诚挚温和智者相。
→ 白话：压弯的树都是果子多的，孔雀的尾屏好看在温顺，骏马走得快在听话。诚实、脾气好，是聪明人的长相。

**2.15** 正士常人同做事，彼二报恩却不同，于田撒下同种子，长出庄稼不相同。
→ 白话：正派人和普通人做一样的事，回报却差得远。同样的种子撒进两块地，长出来的庄稼不一样——差别在地不在种。

**2.16** 若于圣者作贤事，无论再小亦有果，犹如施一油柑果，法王待彼若王子。
→ 白话：对值得敬的人做件好事，再小也有结果。像只布施了一颗油柑果，法王却待他如同王子。

**2.17** 行为护持高门阀，若失行为则无义，诸人喜爱檀香味，烧尽成炭谁需之。
→ 白话：撑得起好门第的是品行，品行没了，门第就不值一提。人都爱檀香的味儿，烧成了炭，谁还要它？

**2.18** 大者暂虽受衰失，不必为彼生忧伤，月亮暂被罗睺食，立即将会得解脱。
→ 白话：有分量的人暂时栽了跟头，不必替他难过。月亮被罗睺（食月的魔神）咬了一口，很快就会松开——蚀不是坏了，是暂时走到影子里。

**2.19** 大者仁慈诸怨敌，则能制服怨敌众，众人敬王护他众，故彼推选为国王。
→ 白话：对敌人也能仁慈，反而能把敌人收服。大家推一个人当国王，是因为他能护住所有人——权力来自"护"，不来自"压"。

**2.20** 正士无论再困苦，不吃杂罪之食物，狮子无论再饥饿，不会食用呕吐物。
→ 白话：正派人再难，也不吃沾着罪过的那口饭。狮子饿到极点，也不会回头吃吐出来的东西。

**2.21** 正士即使遇命难，亦不舍弃善本性，真金无论再烧砍，彼色总是不会变。
→ 白话：正派人到了要命的关头也不丢掉本性。真金怎么烧、怎么砍，颜色都不会变。

**2.22** 卑者虽嗔高尚士，正士不会复发怒，胡狐发出大嚎声，兽王于彼起可怜。
→ 白话：小人冲高尚的人发火，高尚的人不接着骂。狐狸叫得再凶，狮子听了只觉得它可怜——不是被激怒，是被降级。

**2.23** 众人寻察智者过，常人不会有如是，如于珠宝寻瑕疵，谁管烬薪有裂痕。
→ 白话：大家都拿着放大镜找聪明人的毛病，对普通人却不管。珠宝才有人验瑕疵，烧过的柴谁看它裂没裂——被挑剔本身是身价。

**2.24** 不因赞称而高兴，不因辱骂而忧伤，善持自之功德者，此乃正士之法相。
→ 白话：夸他不飘，骂他不垮，守得住自己的好处——这就是正派人的标准像。

**2.25** 依罪武力所得财，怎能算为真财富，犹如猫狗虽充腹，皆是无耻之经历。
→ 白话：靠狠和脏弄来的钱，算不上真财富。猫狗也吃得肚圆，可那经历是丢人的。

**2.26** 眷属若得诸圆满，此乃长官之光彩，为马严饰缨络者，岂非主人之庄严？
→ 白话：手下人过得好，就是长官的脸面。马身上披金挂银，好看的是主人，不是马。

**2.27** 长官如何以大恩，爱护一切诸眷属，如是所有眷民众，亦对长官敬服侍。
→ 白话：上头怎么用心护着下面，下面就会怎么敬着上头。这条是双向的，护在先。

**2.28** 圣者居住之住所，谁有尊敬余学者，太阳照射天空时，星星虽多亦不见。
→ 白话：圣人在的地方，别处的学者就没人敬了。太阳一当空，星星再多也看不见。

# 第三品 观察愚者　（43 颂）

**3.1** 恶人尽管得财富，行为变得更恶劣，瀑布无论再阻挡，然彼一直往下流。
→ 白话：坏人有了钱，只会更坏。瀑布你越去拦，它越是一个劲儿往下冲。

**3.2** 劣者有时变善良，此行即是伪装相，玻璃涂上珠宝色，遇见水即露本相。
→ 白话：混的人偶尔装出好样子，那正是他在演。玻璃涂上一层珠宝的颜色，一沾水就露馅。

**3.3** 愚者虽然完成事，亦是运气非本事，如蚕会吐丝抽线，并非彼之巧本事。
→ 白话：糊涂人偶尔办成事，是运气不是能耐。蚕也会吐丝结线，那不算它的巧本事。

**3.4** 大者精勤成协议，恶人一瞬便摧之，农夫累时种庄稼，冰雹一瞬即毁尽。
→ 白话：正经人辛苦谈成的事，坏人一下子就能砸掉。农民起早贪黑种出的庄稼，一场冰雹就全没了。

**3.5** 劣者自己之过失，总是染推于他人，乌鸦自食不净嘴，使劲擦于干净处。
→ 白话：自己的毛病，全推到别人身上。乌鸦吃了脏东西，嘴要在干净地方使劲擦——脏在自己身上，却去弄脏别处。

**3.6** 若让愚者办事情，既是毁事又毁己，如兽狐狸立为王，众兽受苦自亦亡。
→ 白话：让糊涂人管事，事情毁掉，他自己也毁掉。狐狸被立成兽王，所有兽跟着受罪，它自己也活不长。

**3.7** 愚者欲求为安乐，所作皆成为痛苦，如同有些遭魔者，为除痛苦而自杀。
→ 白话：糊涂人想要的是安稳，做出来的却全是苦。像某些中了邪的人，为了摆脱痛苦反而把自己弄死。

**3.8** 愚蠢又是憨直人，有者毁己有伤他，林中直树被人砍，笔直利箭会伤他。
→ 白话：又蠢又"直"的人，有的先毁自己，有的直接伤人。林子里最直的树最先被砍，笔直的箭最会伤人——不加判断的直，是凶器。

**3.9** 平日不为利他想，此人行为如牲畜，唯寻自己之吃喝，岂非牲畜亦能行？
→ 白话：平时从不替别人想，这种活法跟牲畜没区别。只顾找吃找喝，牲口不也这样吗？

**3.10** 不察有益和无益，不求智慧不闻法，惟有寻求充腹者，真实一头无毛猪。
→ 白话：不管什么有用什么没用，不学不问，只想着填饱肚子——那就是一头没毛的猪。

**3.11** 愚者之中欢欣游，学者之前怯而躲，颈无垂肉顶无峰，具有上牙黄牯牛。
→ 白话：只在糊涂人堆里自在，见到明白人就发怵躲开。脖子上没垂肉、头顶没肉峰、还缺上牙的那头黄牛——它不是牛的样子，也干不了牛的活。

**3.12** 若有饮食至彼处，委托办事时逃避，虽能说话亦能笑，仍是无尾之老狗。
→ 白话：有吃的就到场，派他办事就溜。会说话、会陪笑，也只是条没尾巴的老狗——缺的那一件东西，正是干不了活的证据。

**3.13** 蹄窝易被水灌满，小库易被财装满，小田容易播种子，浅学之人易自满。
→ 白话：马蹄印一小洼水就满，小仓库装点东西就满。学得不深的人最容易满足——容器小，才显得满。

**3.14** 愚者傲慢轻诺者，势力再大亦失败，非天施给一步地，遍入天得三界也。
→ 白话：又骄傲又随便许诺的人，势力再大也要败。对方只给一步之地，他反倒把三界全丢了。

**3.15** 小人心藏怀恨时，害他之前露表情，恶狗已见怨敌时，咬人之前狂乱吠。
→ 白话：小人心里记恨，还没动手脸上先露出来。恶狗看见了要咬的人，先狂叫一通——藏不住，是它的破绽。

**3.16** 愚者唯受积财苦，始终不得积财乐，又复寻求看守财，悭吝积财如老鼠。
→ 白话：糊涂人只尝到攒钱的苦，从没尝到攒钱的乐。一边攒一边守，守得比挣还累，像老鼠屯粮。

**3.17** 学者处于愚者前，不如耍猴之高贵，耍猴之人得食财，学者空手而行也。
→ 白话：有学问的人在糊涂人堆里，还不如耍猴的吃香。耍猴的能讨到钱，读书人两手空空。这是环境的评价体系坏了，不是学问不值钱。

**3.18** 无有学问之士众，特别嫉恨有学者，冬天雪域长庄稼，诸人视为不祥兆。
→ 白话：没学问的人群里，最恨有学问的人。就像大冬天雪域高原上长出了庄稼，人不觉得稀奇，反倒认为是不祥之兆——环境排斥超出它认知的东西。

**3.19** 有些学习邪道者，经常轻毁好学士，如同某些岛屿上，无瘿当为残肢者。
→ 白话：学偏了的人，专门瞧不起真学问。就像某些岛上人人脖子上都长肉瘿，谁没有反倒被当成残疾人。【13世纪社会语境，取其原则：标准颠倒时，正常反被视为异常】

**3.20** 有些仪轨不全者，欺凌圆满仪轨士，犹如至于仔达地，凡长双足不算人。
→ 白话：自己规矩不全的人，去欺负做得圆满的人。到了某些地方，长着两条腿的都不算人——规则由当地定，你按外面的标准去比没用。【同上，取原则不取对象】

**3.21** 有些邪行仪轨者，辱骂正行仪轨士，如同自长狗头者，美男讥毁为女人。
→ 白话：行为不正的人反骂品行端正的人。就像自己长了狗头，反倒讥笑相貌堂堂的人。【原译把"像女人"当贬义，是13世纪语境；取其原则：有毛病的人靠贬低别人来抬高自己，不取其对女性的看法】

**3.22** 有些邪命养活者，特别蔑视穷学者，犹如老猴抓住人，嘲笑说他无尾巴。
→ 白话：靠不正当手段谋生的人，最看不起清贫的读书人。像老猴抓住人，反过来笑人没尾巴——它只看见别人缺的那一样。

**3.23** 若遭业力之逼迫，智者亦入愚人中，犹如芬香茉莉花，被风刮进粪中踏。
→ 白话：时运不济的时候，聪明人也会落到糊涂人堆里去。像香的茉莉被大风刮进粪堆踩了——不是花不香，是位置错了。

**3.24** 精勤持执诸过患，不存毫许之功德，劣者即同滤水器，唯留渣滓漏精华。
→ 白话：勤奋地抓住毛病不放，一点好处都不留。混的人就像滤水器，渣滓留下，精华漏掉。

**3.25** 无有辨别善恶者，学者之前受驱逐，整天谈论钱财食，此即双足之畜牲。
→ 白话：分不清好坏的人，在明白人面前待不住。整天只谈钱和吃，那就是长了两条腿的牲口。

**3.26** 小人即使再多聚，不能成办大事件，犹如芨草捆再多，不能作为大厦柱。
→ 白话：靠不住的人再多，也办不成大事。芨草捆成一堆堆，也当不了房子的柱子——数量补不了材质。

**3.27** 未经观察虽成事，谁会当彼为智者，如虫咬出花纹时，虽成文字非书家。
→ 白话：没经过思考就做成的事，谁也不会因此当他聪明。虫子偶尔咬出了像字的纹路，那是巧，它不是书法家。

**3.28** 愚者所说之诳语，未经驯服之良马，掉落战场宝剑等，对谁有利尚不定。
→ 白话：糊涂人的谎话、没驯过的好马、战场上掉落的宝剑——这三样落在谁手里还不一定，别以为它们只伤别人。

**3.29** 无智愚者再众多，亦会被敌所制服，成群具势大象众，亦被一兔皆驱逐。
→ 白话：没脑子的再多，也会被对手压住。成群的大象，可能被一只兔子全赶跑——人数和块头都不算数。

**3.30** 无智光有财富者，多半对自无益处，犹如奶牛之乳汁，牛犊能喝极罕见。
→ 白话：有钱没脑的人，多半享受不到自己的钱。像母牛的奶，小牛能喝上的机会极少。

**3.31** 学者处于愚者前，亦不一定会尊敬，犹如阳光虽明灿，岂非魔鬼皆逃避？
→ 白话：有学问的人在糊涂人面前，不一定受敬重。阳光再亮，见不得光的东西只会躲开它，不会感谢它。

**3.32** 愚者唯顾积财富，此人怎有亲友念？苦罪积财如老鼠，终于人死财留世。
→ 白话：只顾攒钱的人，哪还有心思顾亲友？辛辛苦苦攒下，到头人死了钱留在世上，一分没带走。

**3.33** 恶劣愚者聚会中，有学之士怎受敬？犹如居住毒蛇处，灯火再亮不发光。
→ 白话：在坏人堆里，有学问的人得不到尊重。像屋里满是毒蛇，灯再亮也不敢点。

**3.34** 恶业深重悭吝者，有财亦无享受时，犹如葡萄成熟时，乌鸦经常生嘴疮。
→ 白话：又吝啬又造业的人，有钱也轮不到享受。像葡萄熟的时候，乌鸦偏偏嘴上长疮——东西熟了，他正好吃不了。

**3.35** 常依他人扶持者，一旦此人会遭殃，天鹅所携之乌龟，终于摔死于地上。
→ 白话：一直靠别人抬着的人，那个人一倒，他也完蛋。天鹅叼着乌龟飞，乌龟最后是被摔死的——它的命不在自己爪子上。

**3.36** 不辨善恶忘恩惠，希有谈论不生奇，现量所见亦询问，胆怯盲从愚者相。
→ 白话：分不清好坏、记不住人情，听到稀罕事也不觉稀奇，亲眼见到的还要反复问，遇事就跟着人走——这是糊涂人的几个记号。

**3.37** 懦夫仅嘴说灭敌，远见怨敌恐叫号，战场遇敌敬合掌，返回家中说大话。
→ 白话：胆小鬼嘴上说要灭敌，远远看见对手就吓叫；真到阵前双手合十客客气气，回到家又吹得天花乱坠。

**3.38** 懦夫商议时勇敢，一旦派差即算财，出征之时复生病，远见战场亦惧喊。
→ 白话：议事的时候他最勇敢，一派任务就装病算账；还没开打，远远望见战场就先喊怕。

**3.39** 懦夫稍胜便自诩，一旦失败恨亲友，集会讨论引争论，秘密商议亦泄漏。
→ 白话：赢一点就到处吹，输了就怪自己人。开会时挑事吵架，机密的事转头就说出去。

**3.40** 沙场之上擦拭衣，遇见恨敌即躲避，亲近彼较敌生惧，武器送于怨敌前。
→ 白话：战场上只顾掸自己衣服，见了仇人就躲；跟他亲近的人比对手还怕他，手里的兵器反倒送到了敌人面前。

**3.41** 列队上阵在排尾，凯旋归回在排头，若见吃喝拼命挤，遇见难事设法躲。
→ 白话：上阵时站最后，得胜回来时跑最前；有吃的拼命挤，有难事先躲开。

**3.42** 如此凡是恶人相，虽有不可思议数，然谁愿掏脏水坑，智者谁尝呕吐味。
→ 白话：坏人的样子说也说不完。但谁愿意去掏那口脏水坑？明白人连尝过的苦头都不肯再尝第二次。

**3.43** 为人指示撅嘴唇，说话之时仅眨眼，听闻传记出呻吟，此人亦具庸俗相。
→ 白话：给人指路时撅嘴，说话时只会挤眼睛，听人讲事迹就哼哼出声——这些也是上不了台面的样子。

# 第四品 观察多士　（43 颂）

**4.1** 劣者尽管具受用，亦被贫穷智者胜，如饥老虎一声吼，树顶猢狲皆落地。
→ 白话：混的人再有钱有势，最后还是输给穷而有智的人。饿虎一声吼，树上猴子全吓掉下来。

**4.2** 愚者学问挂嘴上，智者学问藏心底，麦秸漂于水面上，宝石沉没于水底。
→ 白话：糊涂人把学问挂在嘴边，明白人把学问沉在心里。麦秸浮在水面，宝石自己沉到水底。

**4.3** 浅学之人极骄傲，学者谦逊又温和，溪水经常哗哗响，大海从来不喧嚣。
→ 白话：懂得少的人最张扬，真有学问的又谦虚又和气。浅溪一路哗哗作响，大海从来不吵。

**4.4** 劣者轻蔑高尚士，高士不会如是行，狮子善护诸狐狸，狐狸之间互争斗。
→ 白话：小人去贬低高尚的人，高尚的人不干这事。狮子反倒护着狐狸，狐狸自己互相咬。

**4.5** 正士发怒敬而息，劣者发怒敬更嗔，金银虽硬可熔化，狗粪熔化生臭气。
→ 白话：你敬他一分，正派人的火气就消；你敬他一分，小人的火气更大。金银虽硬，化了还是宝；狗粪化了只出臭味。

**4.6** 智者具足诸功德，愚者具有诸过失，宝贝能赐如意财，毒蛇唯能生过患。
→ 白话：聪明人身上是好处，糊涂人身上是毛病。宝贝能给人想要的财，毒蛇只会给人祸。

**4.7** 恶人住林亦粗暴，正士住城亦温柔，林中猛兽常发怒，市里良马亦驯顺。
→ 白话：坏人住在清净山林也粗暴，正派人住在闹市也温和。林里的野兽天生易怒，城里的良马照样驯顺——环境不决定人。

**4.8** 圣士观察自过失，劣者观察他过失，孔雀观察自身体，鸱鸮给人起恶兆。
→ 白话：明白人先查自己哪儿错了，小人专挑别人的毛病。孔雀照看自己身上有没有斑，猫头鹰一落下人就当它是坏消息。

**4.9** 温柔正士护自他，固执愚者害自他，犹如果树利自他，枯树烧人又焚自。
→ 白话：温和的正派人护得住自己也护得住别人，固执的糊涂人害自己也害别人。果树养活人，枯树只能当柴，烧了人又烧了自己。

**4.10** 有财之时皆为友，一旦穷困皆成敌，宝岛虽远皆来聚，海水干涸谁肯游？
→ 白话：你有钱时人人是朋友，你一落魄人人是敌人。宝岛再远也有人游过来，海水干了谁还肯下水。

**4.11** 愚者得财心安乐，正士施财心安乐，癞者搔痒觉痛快，智者见癞心生惧。
→ 白话：糊涂人攥着钱才安心，正派人把钱分出去才安心。癞病人挠痒觉得痛快，明白人看见癞就发怵——同一个动作，一种是病，一种是好。

**4.12** 智者遇难成助缘，愚者遇难成损害，如风助燃森林火，然彼吹灭小灯火。
→ 白话：同样的灾难，聪明人变成助力，糊涂人变成伤害。风能让森林大火更旺，也能吹灭一盏小灯。

**4.13** 狭慧之人常辨别，此是朋友彼是敌，智者仁慈一切众，因谁有利不定故。
→ 白话：心眼小的人成天分谁是朋友谁是敌人，明白人对谁都留余地——因为利益格局一变，敌友就换了。

**4.14** 有学之士爱学问，无学之士非如是，犹如蜜蜂喜鲜花，苍蝇从不喜爱花。
→ 白话：爱学问的是有根底的人，没根底的不爱。蜜蜂见了花就来，苍蝇从来不去花上。

**4.15** 智者总知学者贵，愚者谁知学者高，旃檀虽比黄金贵，愚者使彼烧成炭。
→ 白话：聪明人知道读书人值钱，糊涂人不知道。檀香比黄金贵，糊涂人拿它当柴烧。

**4.16** 智者自己能观察，愚者总是随声行，如同老狗狂乱吠，群狗亦是随声奔。
→ 白话：明白人自己判断，糊涂人跟着别人的话走。一条老狗乱叫，一群狗就跟着跑。

**4.17** 智者极为艰难时，亦以格言令人喜，愚者已成富裕时，唯以争吵毁自他。
→ 白话：聪明人再难，说出来的话还能让人受用；糊涂人已经发达了，却靠吵架毁掉自己也毁掉别人。

**4.18** 有些说后复办事，有些不悦而干事，恶犬见敌即狂吠，鱼鹰猫儿潜伏击。
→ 白话：有人先说后做，有人不说照做。恶狗一看见对手就先狂叫，鱼鹰和猫是先蹲住再出手。

**4.19** 高士责难亦有利，劣者亲近亦有害，圣神发怒亦护众，阎王发笑害他命。
→ 白话：高尚的人骂你，对你也有好处；混的人跟你亲热，反倒害你。护法神发怒还是在护众生，阎王笑着来是要你的命。

**4.20** 高尚之士如珍宝，何时亦无稍变质，卑劣之人如小秤，稍有不平成高低。
→ 白话：高尚的人像珍宝，什么时候都不变味。卑下的人像小秤杆，稍微压一下就有高低。

**4.21** 同心虽远亦得益，异心虽近将远离，如同莲花泥不染，太阳时常抚育彼。
→ 白话：一条心的，离得远也对你有益；两条心的，离得再近也会散。莲花出泥而不染，太阳还照着它。

**4.22** 乃至具有羞耻时，尔时彼有胜德饰，设若不顾羞耻时，则离功德增恶言。
→ 白话：只要还有羞耻心，他身上就还有像样的东西；一旦不要脸了，功德就跑了，闲话就多了。

**4.23** 未托圣者亦善示，询问贱者反邪说，蔑视佛子亦仁慈，敬奉阎王反遭害。
→ 白话：不用你求，圣者也会好好指点你；你去问格局小的人，他反倒给你歪主意。你轻慢菩萨，他还是慈悲；你巴结阎王，他照样害你。

**4.24** 一方有利之事情，余方或许会有害，犹如升出月亮时，盛开睡莲闭荷花。
→ 白话：一头得利的事，另一头可能受害。月亮升起来的时候，睡莲开了，荷花却合上。

**4.25** 有些造罪虽成事，智者对此怎羡慕，若造善事成错过，智者对此不耻笑。
→ 白话：有人靠造恶成了事，明白人不羡慕；有人做好事却办砸了，明白人不笑话他。

**4.26** 有些收益正收益，有些收益成仇怨，骒马怀驹增财富，骒骡怀胎则死亡。
→ 白话：有的收成是真收成，有的收成会变成仇怨。母马怀驹是添财，母骡怀胎要它的命——骡子本来不能生。

**4.27** 正士难分而易合，劣者易分而难合，树木难砍易生长，木炭易解难相合。
→ 白话：跟正派人闹翻难、和好容易；跟小人交好难、翻脸容易。树难砍倒却好活，木炭一碰就碎，碎了再也拼不回。

**4.28** 虽是弱者若谨慎，强者亦难以消灭，虽是大者若放逸，亦被弱者所摧毁。
→ 白话：弱的只要小心，强的也拿他没办法；大的只要松懈，也会被小的干掉。

**4.29** 多财势力亦增大，耗财势力亦减弱，西瓦意单宝被盗，偷盗之力亦失掉。
→ 白话：钱多势力就涨，钱光势力就落。像那件镇家的宝被盗走，连盗贼自己的力气也跟着丢了。

**4.30** 造有福德施舍者，财富如雨而涌来，若无福泽唯积财，当思谁人会享受。
→ 白话：肯舍的人，钱财像雨一样来。光攒不舍的，该想想最后是谁在享受这些。

**4.31** 高士暂时虽受衰，复盛犹如上弦月，劣者若遇一次衰，则灭犹如熄灯火。
→ 白话：底子好的人暂时栽了，会像上弦月一样一天天补回来；没底子的人一次失败就全灭，像灯被吹熄。

**4.32** 智者宽待敌人故，最后怨敌被制服，愚者报复敌人故，遭受苦难无间断。
→ 白话：聪明人对敌人宽一点，最后敌人反被收服；糊涂人只顾报复，苦就没完。

**4.33** 学者避开险恶境，此乃英勇之本志，狮子弑杀水牛时，躲开牛角岂胆怯？
→ 白话：聪明人绕开险地，这才是真胆气。狮子顶水牛时还先躲牛角，你能说它胆小？

**4.34** 毕竟一切不观察，盲冲敌众即愚蠢，飞蛾扑打油灯光，彼者岂能成英雄？
→ 白话：什么都不看清就冲进人堆，那是蠢。飞蛾扑油灯，扑得再猛也算不上英雄。

**4.35** 劣者摧毁自所依，正士保护自所依，如虫吃尽自所处，狮子保护自居地。
→ 白话：小人毁掉自己赖以立足的东西，正派人护住它。有些虫把自己待的地方吃光，狮子却守住自己的山头。

**4.36** 劣者隐瞒不密事，该密之事处处说，高士不隐非密事，宁死亦隐应密事。
→ 白话：小人把不该藏的藏起来，把该藏的到处说。高尚的人不隐瞒没什么好瞒的，该保密的宁死也不说。

**4.37** 劣者有财起慢因，高士有财和好因，狐狸充腹便嚎叫，狮子充腹安静睡。
→ 白话：小人有了钱就傲慢，正派人有了钱反倒好说话。狐狸吃饱就叫个不停，狮子吃饱安静睡。

**4.38** 高士劣者之行为，此二皆依串习力，如蜂寻花鸭喜水，此等不学亦自知。
→ 白话：好行为坏行为都是重复练出来的。蜂找花、鸭下水，不用学就会。

**4.39** 恶王若遇怨敌时，反而惩治自眷属，有些愚者未成事，亦以自杀而送命。
→ 白话：坏君王碰上对手，反倒收拾自己人。有些糊涂人事情没做成，先把命赔了。

**4.40** 法王若遇怨敌时，对自眷属更慈爱，如于生病之孩子，母亲更会起怜惜。
→ 白话：讲法的君王碰上对手，对自己人反而更疼。像孩子生病时，母亲格外心疼。

**4.41** 高士相合与劣者，则受恶习之熏染，恒河水味特甘美，若进大海成卤水。
→ 白话：高尚的人跟混的人搅在一起，也会被带坏。恒河的水再甜，流进大海就成了咸水。

**4.42** 劣者若依高尚士，则生高尚之行为，犹如涂抹麝香者，散发麝香之芬香。
→ 白话：混的人要是肯跟着高尚的人，也会做出高尚的事。像身上抹了麝香的人，走到哪儿都带那股香。

**4.43** 圣者巍然极稳固，犹如山王不动摇，劣者行为变化多，如同柳絮随风飘。
→ 白话：圣人在哪儿都稳，像大山不被风吹动。混的人一天一个样，像柳絮跟着风飘。

# 第五品 观察恶行　（48 颂）

**5.1** 奸诈者虽说爱语，是为私利非真敬，亲近鸱鸮虽发笑，此乃凶兆非真喜。
→ 白话：狡猾的人说得好听，是为自己的好处，不是真敬你。猫头鹰冲你笑，那是凶兆，不是高兴。

**5.2** 劣者先用言所哄，安心之后再欺骗，渔翁先放香饵后，诱杀极多鱼类也。
→ 白话：混的人先用话把你哄踏实，等你放下戒心再骗。打鱼的人先撒香饵，之后钓上来的多得很。

**5.3** 劣者乃至弱小时，本性尚是善良者，有毒荆棘未成时，尔时不能刺伤人。
→ 白话：小人还没得势时，看着也像好人。带刺的毒荆棘还没长成，那时候扎不了人。

**5.4** 心里思维一件事，口上言说另一事，此乃名为狡猾者，亦是愚人装学者。
→ 白话：心里想一套、嘴上说一套，这叫狡猾，也是糊涂人装读书人。

**5.5** 若是极为狡猾者，暂时虽成终摧毁，驴蒙豹皮偷食禾，最后被人杀掉已。
→ 白话：太狡猾的人，眼下占了便宜，最后要栽。驴披着豹皮去偷庄稼吃，最后被人认出来杀了。

**5.6** 若是奸猾诈巧者，公开谎言能骗人，盗者山羊说为狗，婆罗门便舍山羊。
→ 白话：真会骗的人，睁着眼睛说瞎话也能骗到手。小偷把羊说成狗，读书人就把羊让给了他。

**5.7** 狡者亲自行罪恶，反以诳言欺哄人，大天口出伤叹声，骗人而说苦谛声。
→ 白话：自己作恶，反用假话哄人。像故事里的大天，故意发出叹气声，让人以为他在念"苦谛"——把恶行包装成修行。

**5.8** 狡者伪装语甜蜜，未经观察勿轻信，孔雀身美声悦耳，然彼所食皆为毒。
→ 白话：狡猾的人话说得甜，没看清之前别信。孔雀好看也好听，可它吃的是毒虫。

**5.9** 狡者伪装老实人，一旦他会引诱人，无耻之人卖驴肉，先用兽尾让人看。
→ 白话：装老实的人，一旦动手就是引人上钩。不要脸的人卖驴肉，先把驴尾巴挂出来给人看——用一点真东西钓整笔假买卖。

**5.10** 有些寡廉鲜耻者，以他财物装门面，如同友衣当座垫，以表对客之尊敬。
→ 白话：有人拿别人的东西撑自己的场面。像把朋友的外套铺在地上当坐垫，用来招待客人——客气是做了，用的是人家的。

**5.11** 本来稍无羞耻者，丑事亦是当光荣，甘存地方诸王族，擂鼓庆贺杀父者。
→ 白话：脸皮厚到一定程度，丑事也当光荣事。像某些地方的王族，杀了父亲还击鼓庆祝。

**5.12** 愚者虽作有利事，有些亦成大祸根，如同雏鹊拔母羽，尚自以为报母恩。
→ 白话：糊涂人也在"为你好"，可有些做法是大祸。像小喜鹊给母鸟拔羽毛，还以为自己在报恩。

**5.13** 有些薄情寡义者，他恩所得装门面，龙王勤降之雨水，农夫以为自福德。
→ 白话：没良心的人，把别人给的恩惠拿来充自己的面子。像龙王辛苦下的雨，农夫当成是自己的福报。

**5.14** 愚者以业享福时，以为自己精勤果，啃骨刺破上颚血，老狗当作骨髓精。
→ 白话：糊涂人靠旧业享福，却以为是自己的努力。老狗啃骨头，上颚被刺出血，满嘴红还当是吃到了骨髓。

**5.15** 有些愚者夺亲人，仅为养活无关人，如于砍首严饰尾，除非疯人谁肯为？
→ 白话：有人坑自家人，只为养活不相干的人。头都砍了还去装饰尾巴，除非疯了谁干这种事？

**5.16** 愚者不至所需处，反而常诣无用外，无用泉水夏天流，春天需水时干涸。
→ 白话：糊涂人该去的地方不去，净往没用的地方跑。没用的泉水夏天哗哗流，春天要用水时它干了。

**5.17** 对于善良之正士，劣者特别会欺凌，如同火舌会焚烧，含油灯芯非余尔。
→ 白话：好人反而最招小人欺负。火苗专烧泡了油的灯芯，不烧别的东西。

**5.18** 粗者方能调粗暴，温者对此怎调伏？拔除痈疽须炙割，和缓治疗将毒化。
→ 白话：对付横的人得用硬手段，温和的那一套对他没用。大疮要灸要割，慢慢敷药只会让毒散开。

**5.19** 国王依法当护国，否则彼将会衰败，太阳若不除黑暗，则定彼受罗睺食。
→ 白话：君王得按规矩护住国家，不然自己先垮。太阳要是照不亮黑暗，就轮被罗睺吞掉。

**5.20** 若在恶人当管下，或速坍塌楼房下，或将崩溃山峰下，则会时时常生惧。
→ 白话：落在坏人管下、住在快塌的楼下、走在要崩的山下，这三处的人天天提心吊胆。

**5.21** 即使具有高智慧，性情恶劣亦被舍，毒蛇顶上虽饰宝，智者谁肯抱怀里？
→ 白话：本事再大，脾气坏到极点也没人跟他来往。毒蛇头上镶了宝，谁肯把它搂在怀里？

**5.22** 有些国王如烈火，亲近彼难满其愿，疏远亦惧不摄收，不亲不疏亦畏惧。
→ 白话：有的君王像火：凑上去，怎么都填不满；离远了，又怕他不收留；不亲不疏，照样害怕。

**5.23** 劣妻恶友及暴君，此三谁人肯亲近，猛兽横行之林中，智者谁人常安住？
→ 白话：坏伴侣、恶朋友、暴君，这三样谁愿意靠近？猛兽乱跑的林子，明白人不会常住。

**5.24** 傲慢令人变无知，贪欲令人变无耻，若常轻视自眷仆，则此长官定衰败。
→ 白话：傲慢把人变成没脑，贪欲把人变成不要脸。当头的要是长期瞧不起自己手下，这个头一定做不长。

**5.25** 有利之语说者少，听受彼言更为少，高明医师极难得，遵医嘱行者更少。
→ 白话：肯说有用话的人本来就少，肯听的人更少。好医生难得，照医嘱吃药的人更少。

**5.26** 过越狂妄自大者，不断遭受诸痛苦，狮子极为傲慢故，狐狸让它背象体。
→ 白话：狂妄过头的人，苦就没断过。狮子太自大，被狐狸哄去背整头大象。

**5.27** 乌鸦埋藏之食物，或为恶人谋福利，或于瘠田撒种子，此等望多受益少。
→ 白话：乌鸦藏的食物多半便宜了别人；替坏人谋好处也是白费；在瘦田里撒种，指望得多收成得少。

**5.28** 若无详细观察前，对谁亦不应信任，放逸之中出过错，亲友往往成怨仇。
→ 白话：没看清之前，谁都别全信。一松劲就出事，最亲的人常常变成最狠的对手。

**5.29** 世上劣物虽众多，然无劣人更可恶，其余劣物可改造，改造劣人除非灭。
→ 白话：坏东西很多，但没有比坏人更难缠的。东西坏了能修，人坏了除非他自己完蛋。

**5.30** 虽用百种知识来，助利劣者亦不喜，凡诸亲近人成敌，此乃劣者之特征。
→ 白话：用一百种办法帮他，他还不领情。谁靠近他谁变成他的敌人——这就是混人的标志。

**5.31** 劣者无论再改造，性情不会变贤善，煤炭无论再改造，其色无法变雪白。
→ 白话：小人怎么调教，性子也变不成好的。煤怎么洗，也洗不白。

**5.32** 遭受恶人所欺处，遇见贤人亦会舍，如被毒蛇所害处，虽见金链亦逃避。
→ 白话：被坏人骗过的人，连好人也会躲开。在蛇那儿吃过亏，看见金链子也要跑。

**5.33** 恭敬之境即圣者，恭敬劣者即祸根，乳汁对人是甘露，若喂毒蛇则增毒。
→ 白话：该敬的是圣人，敬小人招祸。奶对人像甘露，喂给毒蛇反倒让它更毒。

**5.34** 纵使设法依劣者，然而不会成齐心，如同麻雀再喂养，彼亦不会安心住。
→ 白话：你千方百计对小人好，也拢不到一条心。麻雀喂得再好，它也不肯在你家里安心住下。

**5.35** 时常精勤分裂者，甚至好友亦离开，如同河水常冲刷，岩石亦会出裂缝。
→ 白话：成天忙着拆台挑拨，再好的朋友也会走。水一直冲，石头也会裂。

**5.36** 自己骗人或害他，或谈上师友等过，彼等若假不必信，或若真实令人惊。
→ 白话：当着你面骗你、害别人，或者讲师父朋友的坏话——这些话是假的就别信；要是真的，这人更可怕。

**5.37** 本来不应所说事，他人之前谁讲说？无论虚假或是真，智者对此当小心。
→ 白话：不该说的事，谁在他面前讲？不管真假，明白人对这种人都得防着。

**5.38** 贪欲财富之劣者，虽是亲友勿信赖，大人面前受贿赂，多被亲友毁灭之。
→ 白话：贪财的人，就算是亲戚也别托底。他们到有权的人那儿告状，多半是自家亲友先被拖垮。

**5.39** 口说害人之语者，此等怨敌易制服，心恨口说利人者，此等怨敌难制服。
→ 白话：嘴上就说要害你的，好对付。心里恨你、嘴上净说为你好的，最难对付。

**5.40** 巧治余痕能愈合，恶语创伤难复愈，如同乌鸦谤鸱鸮，累劫彼此成仇恨。
→ 白话：伤疤好好治也能长平，被恶话刺出来的伤很难好。像乌鸦和猫头鹰互相毁谤，多少代都成死仇。

**5.41** 心里总是挂仇恨，嘴上尽说善妙语，此乃恶劣仙人教，即违圣者之法则。
→ 白话：心里装着恨，嘴上全是好话。这是坏人的路数，跟圣人的规矩正相反。

**5.42** 王规论中虽宣说，一切怨敌全消灭，应如拔除毒树根，然爱如子待如父。
→ 白话：治国书上说要彻底清除敌人，像拔掉毒树的根；但对人还得像父亲爱儿子那样。狠在事上，不在心上。

**5.43** 专门力求私利者，谁肯与彼交为友，农夫勤耕田地中，难以成长余杂草。
→ 白话：一心只谋自己好处的人，谁愿意跟他交朋友？农夫勤耕地，田里就长不出杂草——反过来，人只为自己，身边就没人。

**5.44** 何人不知报恩惠，谁肯与彼交为友，勤劳亦无熟果地，农夫谁肯去耕耘？
→ 白话：不懂报恩的人，谁跟他来往？一块再怎么种也不结果的地，没有农夫愿意去耕。

**5.45** 蛮横又是鲁莽者，此人速将遭失败，厚颜野象极横暴，岂非急受被阉割？
→ 白话：又横又莽的人，败得最快。脸皮厚的野象越凶，越会被牵去阉掉。

**5.46** 如何布施恶劣者，自需之时不回报，钳子虽常夹铁球，铁球怎能夹钳子。
→ 白话：给坏人好处，等他该出力的时候不会还你。钳子天天夹铁球，铁球什么时候夹过钳子？

**5.47** 劣者借口为利他，反而行持罪恶事，是为假装利众生，智者谁肯毁自己？
→ 白话：小人打着"为你好"的旗号作恶。嘴上说利益众人，明白人谁会为了这种话把自己搭进去？

**5.48** 债务尾数余恨敌，恶劣刑法恶语论，贱种以及劣行为，彼等自然会滋长。
→ 白话：欠债的零头、剩下的怨敌、糟糕的刑法、难听的争论、出身低微、恶劣行为——这六样都会自己往上长，不处理就越来越多。【"贱种"是13世纪种姓语境，取其原则：处境差、被人轻视的类别会自我繁殖，不取其对出身的判定】

# 第六品 观察性情　（64 颂）

**6.1** 设若何人当长官，难以了知自过失，如眼能见诸余法，观察自体需镜子。
→ 白话：当了头的人，最难看清自己的毛病。眼睛能看见别的东西，要看自己得靠镜子。

**6.2** 仅有一方智慧者，亦难精通一切事，极为敏锐之眼睛，亦是不能见声音。
→ 白话：只在一个方面聪明，不可能样样精通。眼睛再利，也看不见声音。

**6.3** 有时实话成过失，歪曲之语成功德，笔直道中亦遭难，右旋海螺成吉祥。
→ 白话：有时候实话反倒惹祸，绕着说倒成了得体。笔直的路照样让人摔倒，右旋的海螺却当吉祥物。

**6.4** 若无福分光有学，学问即将毁自己，犹如蚌壳有珍珠，因此彼者送性命。
→ 白话：没有护得住的运气，只有学问反而会害了自己。蚌壳里含着一颗珍珠，就为这个被人撬开丢了命。

**6.5** 过分亲近有学者，多半亦会生厌烦，如同甘蔗极甜美，若常食用则厌弃。
→ 白话：跟聪明人贴得太紧，多半会惹人烦。甘蔗再甜，天天吃也会腻。

**6.6** 性情尽管善良者，若常折磨亦生嗔，犹如檀香本清凉，若常磨擦亦燃烧。
→ 白话：脾气再好的人，被反复折磨也会翻脸。檀香本是凉的，磨得太久照样起火。

**6.7** 天下国王虽众多，依法护国极少数，天上神仙虽众多，无如光明日月轮。
→ 白话：世上国王多，按规矩护住百姓的极少。天上的神多，都不如日头月亮亮堂。

**6.8** 何人能作害人事，彼者亦有利人力，如能折砍人头王，彼王亦能施国政。
→ 白话：有能力害人的，也就有能力利人。敢砍人头的君王，也治得了一国政事——本事是中性的，看往哪头用。

**6.9** 具慧正直之大臣，能成君民诸事业，如同巧者射直箭，瞄准何处皆中鹄。
→ 白话：又有智慧又正直的大臣，能把君王和百姓的事都办成。像好射手放直的箭，瞄哪儿中哪儿。

**6.10** 若王何人不理睬，全知亦无人尊敬，如同离开命根时，尸体再妙有谁取？
→ 白话：君王谁都不搭理，就算什么都懂也没人敬。像人断了气，尸身长得再好谁要？

**6.11** 倘若众人一齐心，弱者亦能成大事，如蚂蚁曾聚成群，最后弑杀幼狮也。
→ 白话：人一齐心，弱的也能办成大事。蚂蚁成群，最后咬死了小狮子。

**6.12** 胆怯不肯勤奋者，虽有强力亦衰败，犹如大象力虽大，牧童役彼使作仆。
→ 白话：胆小又不肯下力的，条件再好也要败。大象力气那么大，照样被放牛的使唤。

**6.13** 充满自信精进者，强者亦能被胜伏，海螺躯体虽渺小，而能啖食摩羯鱼。
→ 白话：敢持续下手的人能赢过强者。海螺那么小，却吃得下大鱼。

**6.14** 大者无须自傲慢，劣者傲慢有何用？真宝不用语夸赞，假宝再夸亦谁买？
→ 白话：真有分量的人不用自己吹；没分量的人吹有什么用？真宝贝不用夸，假的夸上天谁买？

**6.15** 圣者财富能长久，劣者发财速衰失，太阳时常放光芒，月过望日便薄蚀。
→ 白话：明白人的财路能长久，混的人来得快去得也快。太阳天天亮，月亮一过十五就开始亏。

**6.16** 国王过越赞地位，则彼最后将毁灭，如同鸡蛋扔高空，最后必定摔粉碎。
→ 白话：君王把自己地位捧得越高，最后摔得越惨。像把鸡蛋往高空扔，落地必碎。

**6.17** 世上多半士夫众，常受同类所损害，如同阳光普照时，星宿皆成无踪影。
→ 白话：大多数人常常是被同行、同辈拖累的。太阳一出，星星全看不见。

**6.18** 若利敌人亦接近，若害亲人亦远离，海宝虽远亦购买，腹疼虽近亦治疗。
→ 白话：能对自己有好处的，就算是敌人也要靠近；会伤自己的，就算是亲人也要疏远。海底的宝再远也去买，肚子疼离自己再近也得治。

**6.19** 内有稍微财富时，便外露出傲慢相，如同饱含雨水时，浓云飘动雷声响。
→ 白话：肚子里刚有点货就摆架子。云吸饱了水，就飘着打雷。

**6.20** 具足诸德者极少，无有微德者亦少，德过混为一起时，智者依止多德者。
→ 白话：全是优点的人极少，一点优点没有的人也少。多数人好坏掺在一起，那就挑好处占多的来往。

**6.21** 最初尚未了解时，无法肯定敌或友，食不消化变为毒，认清毒亦变良药。
→ 白话：还没摸清之前，说不准谁是敌谁是友。吃下去不消化就成了毒，摸清了毒性反倒能入药。

**6.22** 何处有缘彼兴盛，若无业缘彼衰退，野鸭屋中不肯住，从湖驱彼亦返回。
→ 白话：跟哪儿有缘分，就在哪儿兴旺；没缘分，怎么都留不住。野鸭不肯住屋里，从湖里赶它，它还是飞回湖。

**6.23** 智者花钱求学问，愚者虽学亦舍弃，众人生病即服药，有人亦会自杀也。
→ 白话：聪明人掏钱去换学问，糊涂人学到手又扔掉。人生病都吃药，也有人偏要自己寻死。

**6.24** 诸有自由即安乐，诸无自由即痛苦，共同即是争论根，誓愿即是束缚因。
→ 白话：能做主就自在，做不了主就苦。跟人合伙是吵架的根，许下的愿是绑住自己的绳。

**6.25** 即使内具诸学问，装束褴褛受人欺，如同蝙蝠有本事，无羽之故被鸟弃。
→ 白话：肚里有学问，穿得破烂照样被人轻看。蝙蝠有本事，因为没羽毛，鸟都不认它是同类。

**6.26** 非应之处若正直，往往毁他亦毁己，如同直箭毁他人，或者毁坏自己也。
→ 白话：在不该直的地方硬要直，往往伤了别人也伤了自己。箭射出去，可能中别人，也可能扎自己。

**6.27** 雨水江河入大海，智者方有智慧心，国王能集财眷民，温湿之处长丛林。
→ 白话：雨水和江河都往海里汇。有智慧的人聚得住东西，君王聚得住钱财、人手、百姓，潮湿的地方长得成林子——东西都往能装它的地方去。

**6.28** 夏天泉水燃草火，云间太阳十五月，愚者学问恶劣友，需时不定能用上。
→ 白话：夏天的泉水、烧草的火、云里的太阳、十五的月亮，还有糊涂人的学问、坏朋友——这六样都靠不住，真要用的时候不一定在。

**6.29** 愚者少说极为佳，国王深居极为妙，魔术偶尔观为奇，珍宝罕见亦为贵。
→ 白话：糊涂人少开口最好，君王少见人最好。戏法偶尔看才叫奇，宝贝少见才值钱。

**6.30** 倘若过分慈爱者，亦会变成仇恨因，世人众多之纠纷，亦从相属而产生。
→ 白话：好得过了头，也会变成结仇的原因。世上多半的纠纷，都出在原本亲近的关系里。

**6.31** 即使激烈之争论，亦会变成友爱因，常见争论之结局，多以和解而告终。
→ 白话：再激烈的争吵，也可能变成交情的起点。吵到最后，多半是握手。

**6.32** 悭吝富人之财物，嫉妒心重之友伴，卑劣恶人之理智，彼等不会令人喜。
→ 白话：小气的有钱人、爱嫉妒的伴、坏人的那点理智——这三样没人受用。

**6.33** 贪者得财即欢喜，慢者夸奖即欢喜，愚者同行即欢喜，正士讲实即欢喜。
→ 白话：贪的人给钱就高兴，傲的人夸他就高兴，糊涂人有人陪就高兴，正派人听到实话才高兴。

**6.34** 卑劣恶人之学问，胆怯士夫之理智，横暴长官之恩惠，彼等难以利他人。
→ 白话：坏人肚子里的学问、胆小鬼的理智、暴官的恩典，都帮不了人。

**6.35** 有财人语皆入耳，无财讲实亦不闻，如同产自玛拉雅，即使朽木亦贵重。
→ 白话：有钱人说什么大家都爱听，没钱人说实话也没人理。像产自马拉雅山的东西，哪怕是块烂木头也值钱——值钱的是产地，不是木头。

**6.36** 多语即是过患因，少语即是除过根，解语鹦鹉进笼中，喑哑飞禽均自由。
→ 白话：话多是惹祸的根，话少是避祸的法子。会说话的鹦鹉被关进笼子，不会叫的鸟都自在。

**6.37** 何人若于怨敌前，经常无欺而饶益，则敌亦会如是敬，此乃诸法之规律。
→ 白话：一个人能长期不掺假地对手下人好，连敌人都照样敬他。事情本来就是这个规律。

**6.38** 弱者发怒有何用？强者为何起嗔恚？是故为办事务时，若生嗔恨即自焚。
→ 白话：弱的发起火来有什么用？强的何必动气？所以办事的时候生气，等于先烧自己。

**6.39** 有施敌人亦自聚，无施亲人亦远离，犹如母牛尽乳时，虽持牛犊亦离开。
→ 白话：肯给，敌人也会聚到你身边；不给，亲人也会走。母牛没奶的时候，就算小牛在跟前它也走掉。

**6.40** 即使精通某些事，不定了知余一切，如鹅虽能辨水乳，仍自身影为食物。
→ 白话：精通一件事，不等于什么都懂。鹅能把水和奶分开，却把自己的影子当吃的。

**6.41** 主人经常爱护人，则彼易得自眷仆，如于莲花盛开湖，水鸭亦会自然聚。
→ 白话：当头的常护着人，手下就容易拢住。莲花开满的湖，水鸭自己会来。

**6.42** 富人广施自享受，学者温雅又善良，大者爱护卑劣众，此三利他亦益己。
→ 白话：有钱又肯舍肯享受、有学问又和气善良、有地位又爱护底下人——这三种人帮了别人也成全了自己。

**6.43** 若依福德成诸事，如同阳光不依余，若依精勤成事业，如同灯光仍依余。
→ 白话：靠福分成事，像阳光不用添油；靠苦拼成事，像点灯还得有人添油护着。

**6.44** 倘若依止高尚士，劣者亦会得高位，如同藤蔓依大树，一直盘绕于树顶。
→ 白话：肯跟着高尚的人走，混的人也能爬到高位。藤靠着大树，一路绕到树顶。

**6.45** 有学之士虽有过，爱学之人尚依止，如同雨水虽害屋，世间之人令生喜。
→ 白话：读书人也有毛病，爱学问的人照样跟他学。像雨水也会漏坏屋顶，可地里还是靠它长庄稼。

**6.46** 若无学问凭装束，智者不能生欢喜，如同骏马不奔驰，虽美亦为无价值。
→ 白话：没学问只靠穿戴，明白人不会看重。马长得再漂亮不跑，也不值钱。

**6.47** 愚者当中富翁多，猛兽群中有英雄，世上学者正士中，能出格言极罕见。
→ 白话：糊涂人里有钱的多，猛兽里有英雄，可在读书人和正派人里，能留下几句好话的极少。

**6.48** 何人具有何本领，彼人亦闻彼声誉，学者能闻智者名，英雄能闻英勇名。
→ 白话：你有什么本事，就听得见谁的名声。读书人认得聪明人的名字，勇士认得勇士的名字。

**6.49** 诸大能人行供时，劣者对此会轻蔑，如同自在天顶饰，却被非天所食也。
→ 白话：有大本事的人被人供奉，小人反而瞧不起。像神头顶上的装饰，却被魔吃了——好东西落在看不懂的人那儿就是糟蹋。

**6.50** 书卷当中之学问，尚未修成之密咒，健忘者之学处等，需用之时常诱人。
→ 白话：只存在书里的学问、还没修成的咒、记性差的人学过的那些东西，真要用时都靠不住，只会勾着你以为自己有。

**6.51** 纵有智慧具财富，懒汉难以得高位，如耳虽是先长出，岂能高超角顶矣？
→ 白话：又聪明又有钱，只要懒，也上不去。耳朵虽然先长出来，位置却高不过头顶的角。

**6.52** 猪狗香味有何用？盲人灯火有何用？停食者食有何用？愚者正法有何用？
→ 白话：猪狗闻不出香，盲人用不上灯，断食的人不能吃，糊涂人听不进道理——这四样给了也是白给。

**6.53** 深慧学者纯黄金，沙场英雄胜骏马，善巧医师妙饰品，赴于何处受欢迎。
→ 白话：见识深的学者像纯金，战场上的英雄像好马，高明的医生像顶好的首饰——这种人走到哪儿都受欢迎。

**6.54** 若有智慧精进者，则彼怎不成诸事？如班图子曾消灭，十二兵队俱卢族。
→ 白话：又有脑子又肯下手的，怎么会办不成事？像故事里班图家的儿子，一个人灭了对面十二支军队。

**6.55** 所有儿孙之行为，皆为跟随前祖辈，如小杜鹃随鹞子，此乃即是少见也。
→ 白话：儿孙的做派都是跟着长辈学的。小杜鹃跟着鹰长大，这倒是少见——环境能改习性，但极少改得动。

**6.56** 山岳河水大象马，树木光耀珍宝石，男汉以及妇女等，虽是同类异胜劣。
→ 白话：山、河、象、马、树、光、宝石，还有男女——同一类里，好和差的能差出十万八千里。【13世纪同类比较的表述，取其原则：起点相同不等于结果相同，不取性别判定】

**6.57** 有福之人说一句，弱者对此亦难当，如同果札王一言，加措国王被束缚。
→ 白话：有分量的人说一句，分量轻的人根本扛不住。像果札王一句话，就把另一个国王捆住了。

**6.58** 虽勤承办一切事，真得成功靠福份，犹如商人入海中，未得之宝在王库。
→ 白话：再拼命把事都办了，真到手还得看运气。像商人下海找宝，那颗宝却在国王的库里。

**6.59** 愚者爱憎易推知，智者爱憎却相反，老狗微笑知彼欣，阎王微笑即杀众。
→ 白话：糊涂人高兴讨厌一眼就看得出，明白人正相反。老狗咧嘴是真高兴，阎王咧嘴是要杀人。

**6.60** 最胜财物即施舍，最胜安乐心舒畅，最胜装饰闻正法，最胜之友诚实者。
→ 白话：最值钱的财产是能舍出去的那份，最踏实的安乐是心里不堵，最好的装饰是听过道理，最好的朋友是不骗你的人。

**6.61** 谁人不为财所苦？谁人永时住安闲？一切安乐及痛苦，如同冬夏而循环。
→ 白话：谁没为钱苦过？谁能一直清闲？安乐和痛苦像冬天夏天一样轮着来。

**6.62** 弱者仅提强者名，他人亦会守护彼，如人唯说指鬘名，众多邪魔保护之。
→ 白话：弱小的人只要报出强者的名字，别人也会让着他。像只提那个凶人的名号，连魔都护着他。

**6.63** 众生谁与谁相属，皆由前世业所感，犹如鹰鹫背旱獭，水獭供养鸱鸮矣。
→ 白话：谁跟谁缠在一起，都说前世结下的缘。像老鹰驮着旱獭，水獭反倒喂猫头鹰——关系常常不讲道理。

**6.64** 若欲积累受用者，增时发施最殊胜，若欲河水引进塘，放水养池是良方。
→ 白话：想攒东西，最好的办法是在进账时舍出去一点。想把河水引进塘，得先把塘里的水放掉腾出地方。

# 第七品 观察非理　（47 颂）

**7.1** 奴仆之人自傲慢，苦行之士讲究衣，国王不依教法行，此三即是不合理。
→ 白话：当下人的摆架子，修行人讲究穿戴，君王不守规矩——这三样都是位置上不该有的样子。

**7.2** 承办力所不及事，结仇众人争强士，信赖女人交恶友，五者为速毁自因。
→ 白话：接自己扛不动的活、跟大众结仇、跟强者争、轻信不该托付的人、交坏朋友——这五条是自毁的快车道。【"女人"是13世纪语境，取其原则：别把身家押在你控制不了的人身上，不取性别判定】

**7.3** 无财而欲着妙衣，于人乞讨又自慢，不懂经论想辩论，此三众人所笑处。
→ 白话：没钱偏要穿好衣服，一边讨饭一边摆架子，不懂道理偏要上台辩论——这三样是旁人看笑话的对象。

**7.4** 虽有美丽富饶境，恶人尚贪偏僻乡，如郁金花当成肉，除彼豺狼谁作想？
→ 白话：明明有富饶好地方，坏人偏去贪荒僻的角落。把野花当肉吃——除了豺狼，谁会有这种想法？

**7.5** 大者所受之迫害，出于自眷较敌多，如同狮子自身虱，此外含生谁敢咬？
→ 白话：有分量的人受的伤，多半来自自己人，不是敌人。狮子身上的虱子才敢咬它，别的动物不敢。

**7.6** 倘若主人害自己，则此余人谁拯救？设使显现遮色法，则见彼色有何法？
→ 白话：连自己人都要害你，还能指望谁来救？要是有人专门用东西遮住颜色，你用什么办法看出那是什么颜色？

**7.7** 若害如法静行者，此人极为卑鄙也，若杀托庇自己人，谁人会说彼英雄？
→ 白话：伤害老实本分、不惹事的人，这种人最卑鄙。杀投奔你求庇护的人，谁会说你是英雄？

**7.8** 尽管自己无稍利，恶人亦要害他众，犹如毒蛇虽食气，遇见他众尚咬死。
→ 白话：对自己一点好处都没有，坏人也照样害人。毒蛇喝风也能活，见着别的动物还是要咬。

**7.9** 愚者贪欲以为乐，实则行贪即苦因，如同饮酒以为乐，实则疯狂当安乐。
→ 白话：糊涂人把贪当成快乐，其实贪本身就是苦的来处。像喝酒当享受，其实是把发疯当舒服。

**7.10** 若有学问世人敬，学问亦从精进来，若不勤学诸知识，怨恨他人有何益？
→ 白话：有学问的人受敬重，学问靠勤奋换来。不肯勤学却眼红别人，一点用都没有。

**7.11** 诸人羡慕得长寿，又复恐惧成衰老，畏惧衰老望长寿，此乃愚者之邪念。
→ 白话：人人都羡慕活得长，又怕自己变老；一边怕老一边求长寿——这是糊涂人的拧巴念头。

**7.12** 何人学者身旁时，若不向他学知识，则定此人遭受魔，或是业力所逼也。
→ 白话：守着明白人却不学他的东西，这人不是被什么迷住了，就是运气堵着。

**7.13** 若人具备受用时，既不享受也不施，则定此人受疾病，或是现前饿鬼也。
→ 白话：手里有东西，既不用也不给，这种人要么是有毛病，要么就是活在眼前的饿鬼。

**7.14** 了知教法未修行，则彼教法有何用？庄稼长得虽壮盛，猛兽对此何生喜？
→ 白话：懂了道理不照着做，道理有什么用？庄稼长得再旺，猛兽看了也不高兴——它不吃这个。

**7.15** 业力所逼之众生，有财亦不会享用，如同乌鸦饥埋食，岂能复得自享用？
→ 白话：被时运逼住的人，有钱也不会花。像乌鸦饿的时候把食物藏起来，藏完就找不着了。

**7.16** 既不享受又不施，彼财若当成富裕，则可将山视黄金，此为富裕垂手有。
→ 白话：又不用又不给，这样也算有钱的话，那把山看成金子就行了——发财变得唾手可得。

**7.17** 能讲种种法非法，如此学者虽极多，然能知法修行者，于此世人真稀少。
→ 白话：能讲清什么对什么不对的人很多，可既懂又照着做的，世上极少。

**7.18** 贵种体端韶年者，若无学问不为美，如同孔雀羽虽美，岂为伟人之装饰？
→ 白话：出身高、长相好、年纪轻，没有学问也不算美。孔雀羽毛再漂亮，谁把它当大人物的装饰？

**7.19** 伪装鼻子购得子，借人之饰盗得财，无有师承之智等，虽得世众亦不齿。
→ 白话：装出来的、借来的、偷来的，还有没人教过却自称懂的——这些东西就算到手了，众人也不认。

**7.20** 何人不知报恩惠，此人先已害自己，如同学习害人术，损人之前先害己。
→ 白话：不懂报恩的人，先已经把自己害了。像学害人的法术，还没伤到别人，自己先受损。

**7.21** 尽管明知得受用，非理之处谁肯取？野羊相斗顶淌血，狐狸求之头撞破。
→ 白话：明知有好处，但不合道理的东西谁该去拿？野羊打架撞得头流血，狐狸想去捡便宜，反把头撞破了。

**7.22** 不应依照某关系，即将随意舍他人，即使帝释天王者，彼眷亦皆会逃避。
→ 白话：不能因为一点关系不合就把人随手丢掉。这样做，就算你是天帝，身边的人也会跑光。

**7.23** 情深老友不应舍，亦勿信任诸新友，鸱鸮王依乌鸦臣，最终摧毁自己也。
→ 白话：交情深老朋友不该丢，刚认识的人也别一上来就托底。猫头鹰王用乌鸦当臣子，最后把自己毁了。

**7.24** 竭力亲近恶劣者，亦不能成自己人，如同将水再煎熬，亦不会在火中燃。
→ 白话：再怎么贴混的人，他也成不了自己人。像把水一直烧，它也不会着火。

**7.25** 若知事因而生嗔，则稍有理亦知除，若无事因而生嗔，谁知除嗔之良法？
→ 白话：有来由的火气，讲点道理还能消；没来由的火气，谁有办法消？

**7.26** 若无观察怨敌力，虽是弱小不应辱，如同欺负达支巴，大鹏胜伏大海也。
→ 白话：没摸清对方的斤两，就算他看着弱小也别去侮辱。像去欺负那个小东西，结果引来大鹏把海都填了。

**7.27** 尽福之时生恶念，尽族之时生劣种，尽财之时生悭吝，尽寿之时生死兆。
→ 白话：福报快尽时生恶念头，家道快尽时出败家子，钱财快尽时越发小气，寿命快尽时净见死兆。

**7.28** 自己不为违法事，帝释诋毁亦无道，泉眼自己不干涸，泥土怎能堵塞彼？
→ 白话：自己不越界，别人再毁谤也没用。泉眼自己不干，土怎么能堵得住它？

**7.29** 同时启做百样事，一件事亦未究竟，狡黠之人如老狗，常于村间乱窜游。
→ 白话：同时开一百件事，一件都做不完。耍小聪明的人像老狗，在村子间窜来窜去。

**7.30** 若受业力感召时，智者亦会行邪道，外道胜师大自在，行持疯狂之禁戒。
→ 白话：时运裹住人的时候，聪明人也会走偏。连外道的大宗师，也会去修荒唐的苦行。

**7.31** 倘若何人违法规，暂时得胜终失败，如同曲甲违法规，虽得悉地终遭杀。
→ 白话：破了规矩的人，眼下赢了，最后还是要输。像曲甲违规修行，虽然一度得了成就，终究被杀。

**7.32** 过越聪明多事者，最后即将毁自己，国王广思多念者，终将摧毁自国政。
→ 白话：自作聪明、管得太多的人，最后毁的是自己。君王思虑过度、政令太繁，反而把国事搞坏。

**7.33** 积集财物过多者，彼财即为索命鬼，富翁往往遭祸害，乞丐岂非常安闲。
→ 白话：攒得太多，那堆东西就变成讨债的鬼。有钱人常惹祸，要饭的反而清闲。

**7.34** 威力过于高强者，此乃送命之前行，沙场之上死亡者，多半皆为强力士。
→ 白话：把强势用到过头，是找死的前兆。战场上死的多半是自以为最能打的那个。

**7.35** 财富智慧势力等，有福之人即助缘，倘若无有福泽者，彼等亦成毁己因。
→ 白话：钱、本事、势力，对有福气的人是帮手；对没福气的人，同样这几样变成毁他的东西。

**7.36** 智者无论为何事，观察自福而行之，诤时圆满福泽者，百人之中亦难得。
→ 白话：聪明人办任何事先掂量自己这点家底够不够。能在争斗中全身而退、什么都保住的，一百个人里也挑不出一个。

**7.37** 若于劣塘灌满水，定有一处会崩溃，何人具有财富时，其之种族极难旺。
→ 白话：把不好的池塘灌满，一定会从哪一处溃开。人有了大钱，家族反而很难兴旺。

**7.38** 有子之时无财富，有财之时受敌害，若此一切圆满时，往往众人速死亡。
→ 白话：有了孩子没钱，有了钱又受敌人害；等这一切都齐了，人往往也快走了。

**7.39** 是故智者积福德，造福即是安乐因，何人一切诸圆满，此乃积福之本相。
→ 白话：所以聪明人攒的是福德——造福才是安乐的来处。一个人样样齐全，那是攒出来的福的样子。

**7.40** 若思谎言诱他人，实为此人骗自己，若说一次妄语后，彼言实语亦生疑。
→ 白话：想用谎话钓别人，其实是骗自己。撒过一次谎，往后你说真话别人也要打折扣。

**7.41** 不细观察贤劣时，一嗔不应害他众，如同鸽子杀自妻，后生失伴之忧愁。
→ 白话：没看清对方是好是坏，别一怒就下狠手。像公鸽子一怒杀了自己的配偶，之后为失去伴而发愁。

**7.42** 未来众事不应管，到来之时竭力做，遇见河水方脱鞋，不见河水何必矣？
→ 白话：还没来的事别先操心，来了就尽全力去做。像走到河边才脱鞋，没见着河，脱什么鞋？

**7.43** 将来不能成之事，即使再妙亦勿为，腹中不能消化食，即使再香谁肯食？
→ 白话：注定成不了的事，再漂亮也别做。像吃了消化不了的东西，再香谁往嘴里送？

**7.44** 若无精进贪乐者，今生来世无成就，若无精勤耕耘者，肥田中亦不得收。
→ 白话：又懒又贪舒服，这辈子下辈子都成不了事。不肯下地耕，再肥的田也收不到东西。

**7.45** 非处过越柔弱者，则彼众人会使唤，如同棉花常作垫，谁人树枝当为垫？
→ 白话：在不该软的地方软过头，谁都能来使唤你。棉花天生当垫子，树枝谁拿去垫？

**7.46** 劣事或永不成事，让做即做为愚者，犹如谁信买毒药，谁人能说一切施。
→ 白话：坏事、永远做不成的事，别人一叫你就去，这是糊涂。谁会去买毒药？谁能真的什么都舍出去？

**7.47** 积财而不享用者，此乃积攒自焚薪，蜜蜂酿蜜自不食，他人取之自丧命。
→ 白话：攒着钱自己一分不用，那是给自己堆柴烧。蜜蜂酿蜜自己吃不着，别人来取，它反倒丢了命。

# 第八品 观察事业（上）　（48 颂）

**8.1** 智者虽办极小事，亦经协议方为之，其事成功何堪言，若遭失败亦为妙。
→ 白话：明白人就算办极小的事，也要先商量清楚再动手。办成了不用说，万一办砸了，因为事先讲明过，也好收场。

**8.2** 众生种种意乐故，诸众满意极难为，设使自己具学问，诸众欢喜并亲近。
→ 白话：每个人的心思都不一样，让所有人满意几乎不可能。真要有本事，让大家高兴又愿意靠近，才办得到。

**8.3** 即使十分衰老时，也要广学而博闻，闻慧有益于来世，布施亦无如是益。
→ 白话：老到不行了也要多学多听。听来的智慧对将来有好处，连布施都比不上这一点。

**8.4** 当依功德圆满士，或者结交平凡人，如同携带满水瓶，或者易携无水瓶。
→ 白话：要么跟功德齐全的人学，要么结交普普通通的人。就像要么提一瓶满水，要么提一瓶空水——半瓶水最难提。

**8.5** 一知半解学问者，谁人肯去依止彼，如装一半水之瓶，谁肯携带于头顶？
→ 白话：一知半解的人，谁愿意跟着他学？装一半水的瓶子，谁愿意顶在头上？

**8.6** 何人了知能辨别，智者愚者之差别，并能承办彼等事，此乃一切圆满根。
→ 白话：能分清谁是聪明人谁是糊涂人，并且按各自的特点安排事做——这是一切成事的根。

**8.7** 若经智者善培育，愚者亦会变高尚，犹如有师教言辞，鹦鹉亦会诵论典。
→ 白话：教得好，糊涂人也能变高尚。像有人一句句教，鹦鹉也能背出经文。

**8.8** 即使无力虚弱者，若依强者亦成事，如同水滴虽渺小，汇入大海永不涸。
→ 白话：再弱的人，挂到更强的系统上也能成事。水滴虽小，进了海就再也干不了。

**8.9** 倘若自己无理智，应当询问余智者，如手不能杀敌时，此人岂非取武器？
→ 白话：自己想不明白，就去问想得明白的人。手不够用时，不就得去抄家伙吗？

**8.10** 纵使害己之怨敌，若巧方便亦成友，剧毒对身虽有害，若知搭配成良药。
→ 白话：就算是害过你的敌人，办法对了也能变成帮手。剧毒伤身，配伍得当就成了药。

**8.11** 可取应得之食财，当除贪图不应财，如同可摘树上果，若超树梢则堕地。
→ 白话：该拿的坦然拿，不该拿的别贪。像伸手摘得到的果子，踮脚去够树梢以外的，只会摔下来。

**8.12** 设若智者不谨慎，此时彼生诸过患，设若智者极谨慎，则难发生诸过患。
→ 白话：聪明人一松劲，毛病全冒出来；聪明人真谨慎起来，祸事很难找上门。

**8.13** 其余论典中宣说，乃至势力未充足，尔时应当敬敌众，何时充力随意行。
→ 白话：别的书上说过：实力还不够时，先敬着对手；等攒够了，你说了算。

**8.14** 怨敌说得再悦耳，智者亦不应轻信，鱼鹰猫儿虽温柔，时常竭力杀余生。
→ 白话：敌人话说得再好听，也别当真。鱼鹰和猫看着温顺，抓别的生灵时一点不手软。

**8.15** 地主虽为嗔恚者，亦应悦意而亲近，如于地上虽滑倒，尚需依靠此地也。
→ 白话：管地盘的人就算脾气坏，也得和和气气相处。你在这块地上摔过跤，往后还得靠这块地站着。

**8.16** 若人过越贪欲妙，则彼将会速毁己，如同鱼众贪钩饵，立即彼等遭杀也。
→ 白话：贪得过头，很快把自己搭进去。鱼咬钩上那口饵，当下就没命。

**8.17** 对于应供或眷众，时常布施方能聚，如同施放供品者，神鬼皆乐而护之。
→ 白话：该敬的人和自己人，要常给好处才拢得住。像摆供品的人，神和鬼都高兴着护他。

**8.18** 大者当除游戏乐，亦断贪图食乐等，由贪所引之果报，楞伽罗刹王遭杀。
→ 白话：有地位的人该戒掉玩乐和口腹之欲。贪招来的果报——故事里的罗刹王楞伽罗就死在这上头。

**8.19** 高士方可慈与诤，劣者绝不应如此，如同珍宝有销赎，谁有毒药为如此？
→ 白话：只有正派人才有资格跟你讲交情、也能跟你吵；混的人不能这样。珍宝坏了能修能赎，毒药谁能这么处理？

**8.20** 国王为税勿广收，微财渐能积满仓，蚁垤蜂蜜上弦月，皆是由微而圆满。
→ 白话：收税别贪多。一点点攒也能堆满仓库——蚂蚁窝、蜂蜜、上弦月，都是一点点长满的。

**8.21** 国王不害诸眷民，并以合理收赋税，芸香树中之香脂，若过流淌则枯干。
→ 白话：不害自己人，按合理额度收税。芸香树的胶脂流得太狠，树就枯了。

**8.22** 国王应当极温和，不因小事而发怒，如同毒蛇虽有宝，智者谁肯近身旁？
→ 白话：当头的要温和，别为小事发火。毒蛇嘴里含着宝，谁敢靠近它？

**8.23** 纵使贪图财富者，亦应守护法为重，若坏法规虽得财，则此今世怎恒久？
→ 白话：就算再想钱，也得把规矩摆在头一位。坏了规矩挣来的钱，这辈子也守不长。

**8.24** 对戚亦勿过越亲，对敌亦勿过越恨，欲望亲友结怨因，对怨报复皆易行。
→ 白话：对亲戚别亲到没边，对敌人也别恨到没边。贪欲是让亲友变仇人的引子，而报复仇人反倒容易得很。

**8.25** 柔和既能胜柔和，柔和又能胜粗暴，柔和能成一切故，智者皆云柔最利。
→ 白话：温和能对付温和的人，也能对付粗暴的人。温和能成事，所以明白人都说柔软最锋利。（须配 8.34 的边界：手段随对象变，发心才恒慈）

**8.26** 不论谁为吾之敌，不说谁人不慈吾，虽不仁慈亦不言，一言即将成裂痕。
→ 白话：别到处说谁是你的敌人、谁对你不好。就算他真不仁，你也别说——一句话说出去，裂缝就定下了。

**8.27** 不顾惭愧与羞耻，不知敬蔑之差别，惟有贪图财食者，不应住于彼等处。
→ 白话：不要脸、分不清被敬和被蔑、只惦记吃钱——这种人的地方，别去待。

**8.28** 若未观察新境前，则彼不应弃旧境，一足尚未立稳时，若举双足定跌倒。
→ 白话：新环境没摸清之前，别急着甩掉旧的。一只脚还没站稳就把两只脚都抬起来，一定摔。

**8.29** 竭力隐藏自诸行，公之于众会遭殃，猴子设若不演戏，何必其颈系绳索。
→ 白话：尽量把自己的事藏住，摊开给人看会招祸。猴子要是自己不耍把戏，谁拿绳子拴它脖子？

**8.30** 即使现量见过患，若非合境不应说，世间众说见恶兆，最终见者自遭殃。
→ 白话：就算亲眼见过祸事，场合不对也别讲。人人都嚷嚷自己看见了凶兆，最后倒霉的是说的那个。

**8.31** 他人说笑之财食，彼等虽有亦何用？犹如猪狗食粪便，学者谁人有想望？
→ 白话：别人拿来开玩笑的那种财食，有又怎样？猪狗吃粪，明白人谁会眼红？

**8.32** 伤害他人之恶语，即使怨敌亦勿说，否则如同谷回声，立即自受报复也。
→ 白话：伤人的话，对仇人也不要说。像山谷里的回声，喊出去什么就收回来什么。

**8.33** 若欲损害诸怨敌，首先自应具功德，如是则能毁彼心，自己亦能增福分。
→ 白话：想收拾对手，先把自己本事练足。这样既能伤他的心，自己也添了福分。

**8.34** 发心仁慈暴行为，方能制服野蛮众，如同欲利自身者，以粗疗法而除疾。
→ 白话：心是好的、手段可以硬，才治得住蛮横的人。像想让自己好起来，得用猛药除病。

**8.35** 能害之事虽微小，亦应速治而和解，常见巨大之壕沟，起因即为小渠水。
→ 白话：会惹祸的事再小也要马上处理、马上和解。那些又深又大的沟，起初不过是一小股水冲出来的。

**8.36** 凡不合理之诸事，智者虽会亦不为，如同大象摧敌众，时常遭受王之缚。
→ 白话：不合道理的事，会做也不做。大象能冲垮敌阵，可它照样被国王拴住。

**8.37** 亲友虽恨亦莫弃，敌众虽慈亦莫喜，乌鸦互相虽受害，若依鸱鸮即遭殃。
→ 白话：亲人就算跟你别扭也别丢，敌人就算对你好也别高兴过头。乌鸦互相闹，但真去依靠猫头鹰，那就是送命。

**8.38** 事情无论大或小，智者恒为谨慎做，狮子扑杀象兔时，相同对待无松紧。
→ 白话：大事小事都按同一份认真去做。狮子扑兔子和扑大象，用的力气一样，不因为事小就松手。

**8.39** 若不尊重学者处，学者谁愿住此境？水晶若当火石处，则此谁愿卖水晶？
→ 白话：不敬重读书人的地方，读书人谁肯留？把水晶当打火石卖，谁还愿意把水晶拿出来？

**8.40** 智者或为人讲经，或者静处自修行，如同宝石或顶饰，或者住留海岛中。
→ 白话：明白人要么出来给人讲，要么自己安静待着。像宝石，要么戴在人头上的，要么留在海岛里——不必两头都要。

**8.41** 设若依止高尚士，则对自己有大益，住于山王之鸟群，彼等显成金色也。
→ 白话：跟着高尚的人走，对自己是大好处。停在雪山上的鸟，羽毛都显出金色来。

**8.42** 若依嫉妒心重者，则将自己不成名，如同靠近太阳故，月亮由盈变薄蚀。
→ 白话：跟爱嫉妒的人搅在一起，你的名声就毁了。像月亮靠太阳太近，圆了就开始亏。

**8.43** 何人友爱不坚定，谁愿与彼交为友，空中彩虹虽美妙，望其装饰即愚昧。
→ 白话：交情不牢靠的人，谁愿意跟他做朋友？彩虹再好看，想摘下来当装饰就是傻。

**8.44** 自己不喜之诸事，切莫强行让人作，当思他人对自己，损害之时有何感？
→ 白话：自己不喜欢的事，别硬塞给别人。想想别人这么对你的时候，你是什么滋味。

**8.45** 何事自己所喜爱，彼事让人亦可为，因此自己所喜事，他人亦会来承侍。
→ 白话：自己喜欢的事，也可以让别人去做。你喜欢的，别人也乐意来帮你办。

**8.46** 智者对于蛮横众，既不交亲亦不争，如同粗暴之老虎，不应结怨及交友。
→ 白话：对蛮横的人，既不套近乎也不结仇。像暴烈的老虎，别跟它做朋友，也别跟它结怨。

**8.47** 依止一切高尚士，学者之前常询问，交结义重情长者，谁具此等则常乐。
→ 白话：亲近所有高尚的人，在懂行的人面前多问，跟讲义气、念旧情的人来往——做到这三样的人，常是快活的。

**8.48** 谁说不合应时语，则彼众人会欺凌，语无伦次喋喋者，岂非推知疯人矣？
→ 白话：说话不看场合的人，谁都能欺负他。语无伦次说个没完，别人直接当他是疯子。

# 第八品 观察事业（下）　（47 颂）

**8.49** 弱者以为自所说，一切皆会出差错，了知此义不多言，彼者会受人尊敬。
→ 白话：没分量的人知道自己开口多半会出错，想明白这一点就少说话——这样反受人尊敬。

**8.50** 若遇应时合境时，当以谨慎说少语，虽有善说若过多，如同剩货无人用。
→ 白话：场合对了、时间对了，也要谨慎地说得少。话说得再多再漂亮，过了量就像卖剩的货，没人要。

**8.51** 虽是广闻博学士，亦难认识自过失，众人若指自过失，则能推知自有过。
→ 白话：见多识广的人也难看清自己的毛病。要是大家都来指出你的问题，那就能断定你确实有过错。

**8.52** 虽知过失而不改，此人定是遭魔缠，若尚不依对治者，自己切莫视为人。
→ 白话：知道错还不改，这人像被什么缠住了。连治法都不肯用的，你自己也别把他当可交往的人。

**8.53** 稍有辨别智慧众，当知过失并除之，如是常依对治者，此人日日会上进。
→ 白话：有一点判断力的人，看出毛病就改掉。能长期这么治自己的，每天都在往上走。

**8.54** 聪明之人仁慈者，随和之人勇敢者，彼等不知其余事，亦应各行而护之。
→ 白话：聪明又心软的、好相处又敢事的，就算他们别的都不懂，也该让他们各干各的、护住他们。

**8.55** 虽久交往蛮横者，然彼远离则安乐，翁云动牙虽为美，然彼拔掉得安乐。
→ 白话：跟蛮横的人处了多年，真离开才松快。就像老人那颗晃动的牙看着还舍不得拔，拔掉才知道舒服。

**8.56** 时常怨争之眷属，为彼稍施当驱逐，毒蛇所咬之伤口，不能切除则离命。
→ 白话：成天抱怨惹事的身边人，给点好处打发走。被毒蛇咬的伤口，不切掉就没命。

**8.57** 设使已成高者时，不必吝啬琐碎物，若能制服诸眷民，不必悭吝珠宝也。
→ 白话：已经站到位子了，就别在小东西上抠。真能管住自己人，珠宝也不必死攥着。

**8.58** 智者若欲积财富，稍微施舍方护财，若欲井水常充盈，舀水便是胜窍诀。
→ 白话：想攒钱，得舍出去一点才守得住。想让井一直满，最好的办法是常去舀它。

**8.59** 何者若欲皆圆满，彼当忙碌种种事，若见琐事痛苦因，则应断尽彼妄想。
→ 白话：什么都想要齐全，就得被各种杂事缠住。看清这些琐事正是苦的来处，就先把这个念头断掉。

**8.60** 无论需做任何事，当思功德与过患，德过等亦不应为，过多德少何堪言。
→ 白话：办任何事先掂量好处和坏处。好坏相等的都不该做，坏处多好处少的更不必说。

**8.61** 敬依正直之学者，谨慎狡诈之学者，慈护诚实之愚者，速弃狡诈之愚者。
→ 白话：四种人分开待——正直又有学问的，恭敬依靠；狡猾但有学问的，来往时要谨慎；糊涂但老实的，慈悲护着；又糊涂又狡猾的，赶紧甩掉。

**8.62** 虽无财富眷仆等，若有具慧之善友，傍生亦能成办事，何况说为人众矣？
→ 白话：没钱没仆人不要紧，只要有一个有智慧的益友，连畜生都能办成事，何况是人。

**8.63** 委托应予所知事，不知之事莫强迫，马车不能水上行，舳舻不能陆上行。
→ 白话：把事交给人，要交他会的；不会的别硬逼。马车下不了水，船也上不了岸。

**8.64** 结下深怨之恨敌，虽成和好莫密切，如同高温滚沸水，若遇火焰亦熄灭。
→ 白话：结过深仇的人，就算和好了也别交底。滚开的水再往上添火，也会浇熄——表面平了，底下还是烫。

**8.65** 若知羞耻忠厚者，虽是怨敌可信任，非天投靠忠厚敌，彼亦拼命护非天。
→ 白话：知道廉耻、待人厚道的人，就算是对手也可以托付。连非天去投奔忠厚的仇家，对方也会拼命护着他。

**8.66** 虽说自己无劣心，亦勿轻信所有众，野兽恒时心虽善，彼等猛兽当为食。
→ 白话：别因为自己没坏心，就谁都信。野兽平时看着驯，可它们照样要吃别的生灵。

**8.67** 倘若愚者入邪道，了知愚者即可足，倘若智者入邪道，则应观察其原因。
→ 白话：糊涂人走歪了，知道他是糊涂人就够了；明白人走歪了，得去查原因——他背后一定有别的因由。

**8.68** 学者善于用财物，即使不赐亦不夺，耗财之境虽不夺，亦以借贷等毁财。
→ 白话：会花钱的人，既不白给也不硬抢。那些败钱的地方，虽然没人抢你，靠借贷、人情也能把你掏空。

**8.69** 自己虽知一切事，亦尚需与人协商，谁者不愿人协议，此人自引自悔恨。
→ 白话：就算什么都懂，也还得跟人商量。谁不愿意商量，谁就是在给自己攒后悔。

**8.70** 设使协商险怖事，再亲亦莫过三者，如修起尸有恶伴，首先食掉修者也。
→ 白话：商量危险的事，关系再好也别超过三个人。像那种邪术修法，同伙先把他自己吃了。

**8.71** 了知取舍平等施，温和可亲尊重人，无所畏惧不唐捐，谁人具此得诸地。
→ 白话：懂取舍、施舍不偏、温和待人、心里不惧、 effort 不白花——谁具备这几条，就能到处站住脚。

**8.72** 设使敌人来投靠，亦应供养并赞美，传说乌鸦依老鼠，次后获得安乐也。
→ 白话：敌人来投奔，也该供着、说好话。故事里乌鸦投靠老鼠，后来过上了安稳日子。

**8.73** 交结劣友闻劣论，持执邪见作劣事，此等智者不应行，若行即是愚者也。
→ 白话：交坏朋友、听歪道理、抱错误见解、干下作事——这四样明白人不该碰，碰了就是糊涂。

**8.74** 若善观察而行动，此事怎能成失败？智者睁眼行大道，怎能堕入深渊中？
→ 白话：看清楚再动手，怎么会失败？明白人睁着眼走大路，怎么会掉进深坑？

**8.75** 既能利己又利他，学习知识智者相，有些知识如射者，一旦精通家族毁。
→ 白话：学了既帮自己也帮别人，这才是聪明人的学法。有些本事像射箭——练得再精，也可能把自家毁了。

**8.76** 自己若欲得高位，则当惟有利他众，如同修饰容貌者，首先岂非擦镜子。
→ 白话：想往上走，只管去利益别人。像想让自己好看的人，先擦干净镜子。

**8.77** 若欲降伏诸对方，则自竭力学本领，犹如欲杀怨敌者，先自竭力造兵器。
→ 白话：想压住对手，先把自己的本事练出来。像要上阵杀敌的人，先在家把兵器造好。

**8.78** 狡者之语有搀假，诚者对此需观察，诱后自称真诚者，如是自夸有何益？
→ 白话：狡猾人的话里掺假，老实人更得留神分辨。骗完人再自称真诚——这种自夸有什么用？

**8.79** 昔日褒文中宣说：狡者之前需狡诈，直者之前需真诚，动者之前需坚固。
→ 白话：古人说过：面对狡猾的人要会应变，面对直爽的人要真诚，面对动摇的人要站得稳。

**8.80** 智者恒时对怨敌，亦应和蔼如亲友，虽然不能得和解，定是熄怨之良药。
→ 白话：明白人对敌人也长期和和气气像自家人。就算和不成，这也是灭火的药。

**8.81** 若说恶言劣语者，此世不会成自愿，心中虽想为私利，言说亦应合世众。
→ 白话：说难听话的人，这辈子办不成自己想做的事。心里再为自己盘算，话也得说得合得住众人的口。

**8.82** 若对自他有利事，无论粗暴或温和，皆行善巧方便故，佛陀未说是谄诳。
→ 白话：对自己对别人都有好处的事，手段硬一点或软一点都行。那叫善巧方便，佛没说这是拍马骗人。

**8.83** 最终有利之协议，智者暂苦亦履行，学者衰老又遭苦，亦将知识传后人。
→ 白话：长远有利的约定，暂时吃亏也要守着。学问人又老又苦，也要把东西传给后人。

**8.84** 设使受用过增者，彼者速会遭衰失，如同池塘过满水，或是冲堤或越水。
→ 白话：享受加码太狠，很快就要栽。池塘灌太满，不是溃堤就是溢出去。

**8.85** 于某些人有利事，余人不定有利益，蒜头治风虽有效，而对胆病却成毒。
→ 白话：对一些人管用的，对另一些人不一定。蒜治风湿有效，落在胆病上就是毒。

**8.86** 若恒亲近脆弱者，大者亦恐将衰败，酥油若置劣器中，老鼠岂不啃坏彼！
→ 白话：长期跟不牢靠的人搅在一起，再大的架子也会塌。酥油放在劣质的容器里，老鼠能不啃穿它吗？

**8.87** 倘若依靠恶劣众，恶习熏染害自己，依赖渠水之鱼众，田地之上遭撒弃。
→ 白话：靠坏人，坏毛病会把你带坏。住在渠水里的鱼，水被田里放干，就摊在岸上晒死。

**8.88** 寡情之人来投靠，于彼稍施当驱逐，如同家中起恶兆，当需耗财而消灾。
→ 白话：没良心的人来投奔，给点东西打发走。像家里出了凶兆，花点钱消灾比留着它划算。

**8.89** 正士即使赴他处，亦应尊敬及承侍，若常敬奉如意宝，则增吉祥成所愿。
→ 白话：正派人就算去了别处，也该照样尊敬、照样照应。像常供着如意宝，好事会加上来，愿望会成。

**8.90** 若人过越赞劣者，次后自己受毁谤，如向空中掷粪便，其落掷者之顶上。
→ 白话：把小人捧得太过，回头挨骂的是你自己。像朝天扔脏东西，落下来扣在自己头上。

**8.91** 若人侮辱有学士，则彼自己会遭殃，犹如灯火向下垂，此人自手会烧伤。
→ 白话：侮辱有学问的人，遭殃的是自己。灯焰倒垂下来，烧的是拿灯的那只手。

**8.92** 无论何法何相应，彼法应当如是用，首饰不能戴足上，足镯不能用顶饰。
→ 白话：任何东西都有它对应的用法，按那个用。头饰不能套脚上，脚镯也不能戴在头上。

**8.93** 成办巨大事业时，竭力依靠善妙友，犹如火烧茂林时，务必依靠大风助。
→ 白话：要办大事，就尽力依靠好朋友。像烧一大片林子，非得有风帮忙不可。

**8.94** 仁慈者说温和语，他人欢喜易成事，谁能耗财令人喜，舍弃身寿亦难足。
→ 白话：心好的人说话温和，别人听着高兴，事就好办。要是非靠花钱买人高兴，把命和钱都搭进去也填不满。

**8.95** 不因穷困极忧伤，不因富有喜而慢，业力所牵遥远故，种种苦乐随后现。
→ 白话：别因为穷就痛不欲生，也别因为富就得意忘形。因果拉得很长，苦和乐都会在后头陆续显出来。

# 第九品 观察佛法　（61 颂）

**9.1** 众生怙主在世时，若人礼拜外道师，则如具八支河岸，又复欲掘盐水井。
→ 白话：众生的依止处就在世上，却去拜门外的人。好比河有八条好岸，还另外去挖一口咸水井。

**9.2** 无论一切任何事，若人习惯无微难，如同学习工巧明，修学佛法亦不难。
→ 白话：任何事只要成了习惯，就没有小的难处。学手艺是这样，修行也一样。

**9.3** 何人稍财能知足，彼者财富用不尽，若无知足求财者，恒临痛苦如雨水。
→ 白话：有一点钱就知足的人，那份财富用不完。不知足而一味找钱的人，苦像雨水一样落个不断。

**9.4** 佛说何者施舍财，彼人需时可收取，所积之财如蜂蜜，终将被他人享用。
→ 白话：佛说过：舍出去的钱，等你要用时能收回来。攒着不动的钱像蜂蜜，最后是被别人吃了。

**9.5** 此世虽然放债务，亦不一定偿清债，若与乞丐布施者，无勤定得百倍物。
→ 白话：这一世你借出去的钱，不一定还得上。可给叫花子的那一点，不费力气就百倍回来。

**9.6** 悭者不会成富裕，施者不会成贫困，似成啬者不喜财，施者似为贪图财。
→ 白话：小气的人不会因此变富，肯舍的人不会因此变穷。看上去像是吝啬的人不爱钱，肯舍的人倒像贪图钱。

**9.7** 若施恐怕变穷故，悭者不愿放布施，若啬必定变穷故，智者有财即布施。
→ 白话：怕舍了会变穷，所以小气的人一分不给。明白人算的是另一笔：攥着不放一定穷，所以手里有钱就舍出去。

**9.8** 屯集之物不增上，商者处处设货摊，如是积财不成富，智者十方放施财。
→ 白话：堆在库房里的货不增值，做生意的到处摆摊。攒钱不会攒出富贵，明白人在各处把钱放出去。

**9.9** 广闻博学之士云：虽具千百万宝藏，谁亦不愿布施者，此乃世间之贫者。
→ 白话：见多识广的人说：纵有千百万财宝，一个子儿都不肯舍的，就是世上最穷的人。

**9.10** 愚者顾虑失后代，所得微财亦积累，智者为兴自后代，如同贿赂而发施。
→ 白话：糊涂人怕后人没着落，挣一点也死攒。明白人为了后人好，像花钱打点一样把钱舍出去。

**9.11** 思为后代得福贵，抛售己身遗予子，劣子反而抗父母，耗尽诸财游如犬。
→ 白话：想着给后代积福，苦了自己把钱留给儿子。不争气的儿子反过来顶撞父母，把家财败光，像狗一样四处游荡。

**9.12** 父母极为慈爱子，子女并非如是待，父母竭力养子女，一旦衰老受子辱。
→ 白话：父母疼孩子疼到底，孩子并不这样回报。父母拼死拼活养大儿女，等自己老了，反受儿女的气。

**9.13** 积财悭吝之富者，积财乐施之富者，此二自己及后代，来世将有明差别。
→ 白话：一种有钱人只进不出，一种有钱人边攒边舍。这两种人自己和后代的下场，将来会分出明显的两样。

**9.14** 漂泊轮回诸众生，昼夜拼命求财富，知足之士虽得财，亦如菩萨施他众。
→ 白话：在轮回里打滚的人，日夜拼命找钱。知足的人就算得了钱，也像菩萨那样转手分给别人。

**9.15** 施舍一切圆施度，若起嗔恚增安忍，人足亦可随喜故，布施修法之根本。
→ 白话：把该舍的全舍掉，布施这一门就圆满了；火气上来时用忍来对治。连脚都能让人随喜，所以布施是修行的根本。

**9.16** 此身虽为苦海器，是故如同怨恨敌，智者若知役使法，则成一切福德因。
→ 白话：这副身子是盛苦的容器，本该像仇人一样防着。可明白人一旦知道怎么用它，它反倒成了所有福德的来处。

**9.17** 虽身刹那即消失，善业亦能传百世，如同风扬檀香味，传送虽远令人喜。
→ 白话：身体转眼就没了，做过的好事能传上百代。像风把檀香味扬出去，传得再远，人闻着还是高兴。

**9.18** 今世长期共用乐，一旦辞别极痛苦，终无自由而死亡，若执恒常真毁己。
→ 白话：这辈子处了这么久的亲人，一分别就痛得要命。到头来谁都得走。硬要相信能一直这样下去，才是真把自己害了。

**9.19** 亲友皆围自身旁，低声吐语失目光，不知死后归何处，此时无善者可怜。
→ 白话：亲人全围在身边，气声越来越细，眼神散了，谁也不知道他死后往哪儿去。这时候，平生没做过善事的人最可怜。

**9.20** 三种恶趣之诸病，未到之际当治之，否则如同遭霹雳，骤落自顶无可奈。
→ 白话：通向三处恶道的毛病，要在没发作之前治。不然像炸雷劈下来，落在头顶上就一点办法都没有。

**9.21** 明知离别诸亲友，亦知必定会死亡，仍旧安然入眠者，究竟吾心有何魔。
→ 白话：明知道亲人要散、自己必死，还照样睡得安稳——我这心里到底中了什么邪？

**9.22** 何者虽不能精进，亦不应该堕恶趣，勇者虽不能杀敌，怎会杀害自方矣？
→ 白话：就算使不上劲，也不该往坏处掉。勇士杀不了敌人，总不至于反过来杀自己人。

**9.23** 学者为得恒久乐，暂苦亦应求学问，如同刺灸法疗治，此乃巧医之论典。
→ 白话：读书人为长远的安稳，暂时的苦也该受。像扎针艾灸那样治，这是好医生的常规章法。

**9.24** 若他一切圆满时，自心生起不忍耐，则摧自己之福根，实为嫉自又毁己。
→ 白话：别人什么都顺的时候，你心里受不了——这一念把自己福气的根挖断了。既是嫉妒自己，也是毁掉自己。

**9.25** 若欲灭除诸害敌，则汝应除自嗔恨，是因无始轮回中，嗔恚害吾无穷尽。
→ 白话：想消掉害你的敌人，先消掉你自己的火气。因为从无始以来，真正害你没完的一直是嗔恨。

**9.26** 若欲灭尽一切敌，彼等怎能会杀尽，若能灭除自嗔敌，则能同时灭诸敌。
→ 白话：想把天下敌人杀光，杀得完吗？把心里那个"嗔"灭了，外面的敌人同时就没了。

**9.27** 若嗔高强鲁莽者，则将自己遭祸害，对于正士和蔼者，有何必要起嗔恚？
→ 白话：对又强又横的人发火，祸事落自己头上。对正派又和气的人，有什么理由发火？

**9.28** 同根所生之禾草，被风吹送于十方，如是俱生之众生，以业所牵各自分。
→ 白话：同一根上长出的草籽，被风一吹各奔东西。一起生下来的人也一样，各被自己的业牵走。

**9.29** 昔不相识今互爱，次后彼又各自行，此人与吾密切故，死后亦生巨痛苦。
→ 白话：从前互不相识，如今彼此相爱，过后又要各走各路。就因为这个人跟我这么亲近，死后那份痛也格外大。

**9.30** 若欲专为私利者，彼者先应利他人，专以私利为重者，彼人不会成自利。
→ 白话：一心想为自己好的人，反倒该先去为别人好。只盯着自己那点利益的，最后连自己都成不了。

**9.31** 何人利他为重者，倒如狡者为私利，一切利己为重者，倒如利他真诚者。
→ 白话：把利他摆在头里的人，办起事来倒像狡猾的人替自己盘算那么利索；只顾自己的人，倒像真心为别人那样费劲不讨好。

**9.32** 智者虽为利今生，亦应修法方得乐，当视正士与盗贼，彼二圆满有大异。
→ 白话：明白人就算只为这辈子过得去，也得照着规矩来才安生。看看正派人和盗贼各自的下场，差别大得很。

**9.33** 诸人寿短其一半，夜间入眠如死亡，又遭病老等众苦，余半亦无享乐际。
→ 白话：人的寿数先被睡掉一半，夜里睡着跟死了一回差不多。剩下的那一半又让病和老啃掉，真正享乐的时候没多少。

**9.34** 众人若能真现见，跟随自身之死主，则为余事何堪言，甚至食念亦无有。
→ 白话：人要是真能看见那个一直跟着自己的死，别的事就更别提了——连吃饭的心思都不会有。

**9.35** 无论汝事圆满否，死主绝不让汝停，设若尚有应做事，则应今起精进行。
→ 白话：不管你事情办完没办完，死都不会等你。要是还有该做的事，从今天起就得抓紧。

**9.36** 吾今诸事尚未满，恳请暂时等一日，如是涕泣复哀求，死主怎能改其时。
→ 白话："我事情还没做完，请宽限一天。"哭着求、跪着求——死期哪会因为你去求就挪一挪。

**9.37** 舍弃散乱即为妙，不能舍此依善友，喂养毒蛇不应理，若养便需勤诵咒。
→ 白话：能把散乱扔掉最好。扔不掉就得靠益友。养毒蛇本来不该，可要是非养着，就得一刻不停地念咒防它。

**9.38** 设若自心散乱者，彼无修法之良机，若人寂静而安住，彼心即可得堪能。
→ 白话：心散着的时候，根本没有用功的好时机。人安静下来，心才变得能使上劲。

**9.39** 精通一切所缘义，并以禅定调自心，勤学圣者之教言，此乃一切功德基。
→ 白话：把该懂的道理弄通，再用定来调自己的心，好好学圣人的话——这是一切功德的底子。

**9.40** 愚者学习执为耻，智者不学执为耻，是故智者再衰老，亦为来世学知识。
→ 白话：糊涂人把"去学"当丢人，明白人把"没学"当丢人。所以明白人再老，也照样为将来学东西。

**9.41** 愚者因无智慧故，彼等不愿求学问，若善观察无智故，愚者更应勤求学。
→ 白话：糊涂人正因为没智慧，才不愿意去学。可仔细想想：正因为没智慧，才更该拼命学。

**9.42** 是因前世未求学，今见终身成愚者，因恐后世成愚昧，今生再难亦勤闻。
→ 白话：因为前世没学，这辈子看自己是个糊涂人。怕下辈子还糊涂，这辈子再难也要多听多学。

**9.43** 浅学寡闻愚者云：修习不需广闻法，若无闻法仅修习，再勤亦成傍生因。
→ 白话：读书少的人说：修行不需要多听。可只听不做是另一回事，只做不听，再勤苦也只是畜生道的因。

**9.44** 无欺因果循环律，此乃遍知之特征，若无求学亦成佛，则彼因果何能真？
→ 白话：因果一环扣一环、不骗人，这是全知者的特点。要是说不用学也能成，那因果还怎么算数？

**9.45** 若无闻受仅修习，暂时修成亦速尽，犹如金银虽炼熔，一旦离火即变硬。
→ 白话：不听不学只闷头修，一时修出来的很快也没了。像金银化了，一离火就又硬回去。

**9.46** 纯依智力细观察，能断过根即修习，否则久修反照旧，如涤身垢复沾身。
→ 白话：靠自己的脑子看清，找到毛病的根并断掉，这才叫修。不然修多少年还是老样子，像洗完澡又滚了一身灰。

**9.47** 殊胜因缘未具时，虽证无我难成佛，未修殊胜方便者，虽见谛亦非罗汉。
→ 白话：条件没齐的时候，就算证到无我也成不了佛。没修过那套办法的人，就算见了真理，也还不算彻底解脱。

**9.48** 是故证悟诸法已，自心安住三摩定，断除过失习气俱，彼者方成正等觉。
→ 白话：所以要先把道理证悟，再把心安住在定里，把毛病连同老习惯一起断干净——这才算真正成了。

**9.49** 何人若无胜智慧，论典虽妙有谁学？镶宝金饰虽美妙，牦牛对此何理睬？
→ 白话：没有足够的见识，书写得再好谁去学？镶宝的金饰再漂亮，牦牛理都不理。

**9.50** 智者如若已精通，一切格言之真理，然而彼义不奉行，则知论文亦何用？
→ 白话：就算把书里讲的道理全弄通了，一条也不照着做，那懂了有什么用？

**9.51** 自己所需诸论典，每日之中记一句，如同蜂蜜及蚁窝，不久即将成智者。
→ 白话：把自己要用的书，每天记一句。像蜜蜂采蜜、蚂蚁垒窝，不久就成了有见识的人。

**9.52** 若愿行持诸善事，务必敬闻佛教言，一切诸时能忍耐，纵遇命难亦行法。
→ 白话：想做善事，就恭敬地听佛的话；任何时候都耐得住；就算要命，也照规矩做。

**9.53** 若能依据经教义，精进修行依对治，智者从不说妄语，彼德此后会明知。
→ 白话：照着经教的道理下工夫，按毛病对症下药，明白人从不说假话——这些好处以后自己会看见。

**9.54** 过去行此亦兴盛，如今行此亦复然，若学殊胜此格言，未来亦会得圆满。
→ 白话：过去照这套做的人兴旺，如今照这套做的一样成。学会这本格言，将来也能齐全。

**9.55** 智者自己虽了知，亦会恭学智者论，如同珍宝虽贵重，未销之前价极微。
→ 白话：明白人自己懂了，照样恭敬地去学前人的书。像宝贝虽然值钱，没经过鉴定师过手之前，没人认它的价。

**9.56** 树木纵使极众多，生长檀香林极少，如是学者虽众多，能说格言学者少。
→ 白话：树多得数不清，长出檀香林的极少。读书人再多，能留下几句好话的极少。

**9.57** 骏马行道知胜劣，金银冶炼知纯浊，大象战场知勇懦，学者著论知学问。
→ 白话：马要在路上跑才分好坏，金银要炼过才知纯杂，大象要上战场才知胆量，读书人要写出来才见学问。

**9.58** 若欲一切世间众，皆以自己当正量，则当推究此善论，对症下药勤修行。
→ 白话：想让天下人都拿你当标准，就得把这本好书琢磨透，然后按自己的毛病下工夫。

**9.59** 若知一切世间事，彼能修成诸正法，是故行持正法者，乃是菩萨之善规。
→ 白话：把世间的事都弄明白，才修得成真正的法。所以照着正法去做，是菩萨的规矩。

**9.60** 耆婆良医以巧法，以药为食治重疾，吾以随顺世间理，宣说殊胜此正法。
→ 白话：名医耆婆治重病时，把药当饭喂。我这边顺着世人的道理讲，讲出这本正法。

**9.61** 生自广阔海岛上，智慧龙王所摄持，具德格言珍宝藏，为满学者之慧库，为满智者之渴望，释迦比丘吉祥贤，根嘎嘉村善观察，为明诸世著此论。此中所生无垢善，犹如极明皎月光，遣除诸众之意暗，愿盛智者之慧莲。学习一切诸所知，为得一切智智位，是故吾造此论典，亦是为得圆佛果。
→ 白话：结语（作者自述）：我生在辽阔的海岛，得智慧龙王的护持，把这些有德行的格言聚成宝藏。为了让读书人的智慧库装满，让明白人的心愿得偿——释迦家的比丘吉祥贤（萨迦班智达·根嘎嘉村），经过仔细考察，为让世道明白而写了这部论。愿这里生出的干净善根，像极亮的月光，照掉众人心里那点暗，让智慧的花开得旺。学一切该学的，为的是无所不知的那个位置；所以我造这部论，也为了把佛果修圆满。
