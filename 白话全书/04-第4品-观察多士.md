# 《萨迦格言》白话全书 · 第四品 观察多士

> 体例：一行原文，一行「→ 白话」。白话只做直译＋喻体落地，不加感悟、不掺解释。
> 本品讲贤愚混杂的世道里怎么分辨、怎么取舍。本品的「劣者」与第三品的「愚者」用法有差别：三品重在"不辨善恶"，四品重在"混杂场景中看得清谁是谁"。

**4.1** 劣者尽管具受用，亦被贫穷智者胜，如饥老虎一声吼，树顶猢狲皆落地。
→ 白话：混的人再有钱有势，最后还是输给穷而有智的人。饿虎一声吼，树上猴子全吓掉下来。

**4.2** 愚者学问挂嘴上，智者学问藏心底，麦秸漂于水面上，宝石沉没于水底。
→ 白话：糊涂人把学问挂在嘴边，明白人把学问沉在心里。麦秸浮在水面，宝石自己沉到水底。

**4.3** 浅学之人极骄傲，学者谦逊又温和，溪水经常哗哗响，大海从来不喧嚣。
→ 白话：懂得少的人最张扬，真有学问的又谦虚又和气。浅溪一路哗哗作响，大海从来不吵。

**4.4** 劣者轻蔑高尚士，高士不会如是行，狮子善护诸狐狸，狐狸之间互争斗。
→ 白话：小人去贬低高尚的人，高尚的人不干这事。狮子反倒护着狐狸，狐狸自己互相咬。

**4.5** 正士发怒敬而息，劣者发怒敬更嗔，金银虽硬可熔化，狗粪熔化生臭气。
→ 白话：你敬他一分，正派人的火气就消；你敬他一分，小人的火气更大。金银虽硬，化了还是宝；狗粪化了只出臭味。

**4.6** 智者具足诸功德，愚者具有诸过失，宝贝能赐如意财，毒蛇唯能生过患。
→ 白话：聪明人身上是好处，糊涂人身上是毛病。宝贝能给人想要的财，毒蛇只会给人祸。

**4.7** 恶人住林亦粗暴，正士住城亦温柔，林中猛兽常发怒，市里良马亦驯顺。
→ 白话：坏人住在清净山林也粗暴，正派人住在闹市也温和。林里的野兽天生易怒，城里的良马照样驯顺——环境不决定人。

**4.8** 圣士观察自过失，劣者观察他过失，孔雀观察自身体，鸱鸮给人起恶兆。
→ 白话：明白人先查自己哪儿错了，小人专挑别人的毛病。孔雀照看自己身上有没有斑，猫头鹰一落下人就当它是坏消息。

**4.9** 温柔正士护自他，固执愚者害自他，犹如果树利自他，枯树烧人又焚自。
→ 白话：温和的正派人护得住自己也护得住别人，固执的糊涂人害自己也害别人。果树养活人，枯树只能当柴，烧了人又烧了自己。

**4.10** 有财之时皆为友，一旦穷困皆成敌，宝岛虽远皆来聚，海水干涸谁肯游？
→ 白话：你有钱时人人是朋友，你一落魄人人是敌人。宝岛再远也有人游过来，海水干了谁还肯下水。

**4.11** 愚者得财心安乐，正士施财心安乐，癞者搔痒觉痛快，智者见癞心生惧。
→ 白话：糊涂人攥着钱才安心，正派人把钱分出去才安心。癞病人挠痒觉得痛快，明白人看见癞就发怵——同一个动作，一种是病，一种是好。

**4.12** 智者遇难成助缘，愚者遇难成损害，如风助燃森林火，然彼吹灭小灯火。
→ 白话：同样的灾难，聪明人变成助力，糊涂人变成伤害。风能让森林大火更旺，也能吹灭一盏小灯。

**4.13** 狭慧之人常辨别，此是朋友彼是敌，智者仁慈一切众，因谁有利不定故。
→ 白话：心眼小的人成天分谁是朋友谁是敌人，明白人对谁都留余地——因为利益格局一变，敌友就换了。

**4.14** 有学之士爱学问，无学之士非如是，犹如蜜蜂喜鲜花，苍蝇从不喜爱花。
→ 白话：爱学问的是有根底的人，没根底的不爱。蜜蜂见了花就来，苍蝇从来不去花上。

**4.15** 智者总知学者贵，愚者谁知学者高，旃檀虽比黄金贵，愚者使彼烧成炭。
→ 白话：聪明人知道读书人值钱，糊涂人不知道。檀香比黄金贵，糊涂人拿它当柴烧。

**4.16** 智者自己能观察，愚者总是随声行，如同老狗狂乱吠，群狗亦是随声奔。
→ 白话：明白人自己判断，糊涂人跟着别人的话走。一条老狗乱叫，一群狗就跟着跑。

**4.17** 智者极为艰难时，亦以格言令人喜，愚者已成富裕时，唯以争吵毁自他。
→ 白话：聪明人再难，说出来的话还能让人受用；糊涂人已经发达了，却靠吵架毁掉自己也毁掉别人。

**4.18** 有些说后复办事，有些不悦而干事，恶犬见敌即狂吠，鱼鹰猫儿潜伏击。
→ 白话：有人先说后做，有人不说照做。恶狗一看见对手就先狂叫，鱼鹰和猫是先蹲住再出手。

**4.19** 高士责难亦有利，劣者亲近亦有害，圣神发怒亦护众，阎王发笑害他命。
→ 白话：高尚的人骂你，对你也有好处；混的人跟你亲热，反倒害你。护法神发怒还是在护众生，阎王笑着来是要你的命。

**4.20** 高尚之士如珍宝，何时亦无稍变质，卑劣之人如小秤，稍有不平成高低。
→ 白话：高尚的人像珍宝，什么时候都不变味。卑下的人像小秤杆，稍微压一下就有高低。

**4.21** 同心虽远亦得益，异心虽近将远离，如同莲花泥不染，太阳时常抚育彼。
→ 白话：一条心的，离得远也对你有益；两条心的，离得再近也会散。莲花出泥而不染，太阳还照着它。

**4.22** 乃至具有羞耻时，尔时彼有胜德饰，设若不顾羞耻时，则离功德增恶言。
→ 白话：只要还有羞耻心，他身上就还有像样的东西；一旦不要脸了，功德就跑了，闲话就多了。

**4.23** 未托圣者亦善示，询问贱者反邪说，蔑视佛子亦仁慈，敬奉阎王反遭害。
→ 白话：不用你求，圣者也会好好指点你；你去问格局小的人，他反倒给你歪主意。你轻慢菩萨，他还是慈悲；你巴结阎王，他照样害你。

**4.24** 一方有利之事情，余方或许会有害，犹如升出月亮时，盛开睡莲闭荷花。
→ 白话：一头得利的事，另一头可能受害。月亮升起来的时候，睡莲开了，荷花却合上。

**4.25** 有些造罪虽成事，智者对此怎羡慕，若造善事成错过，智者对此不耻笑。
→ 白话：有人靠造恶成了事，明白人不羡慕；有人做好事却办砸了，明白人不笑话他。

**4.26** 有些收益正收益，有些收益成仇怨，骒马怀驹增财富，骒骡怀胎则死亡。
→ 白话：有的收成是真收成，有的收成会变成仇怨。母马怀驹是添财，母骡怀胎要它的命——骡子本来不能生。

**4.27** 正士难分而易合，劣者易分而难合，树木难砍易生长，木炭易解难相合。
→ 白话：跟正派人闹翻难、和好容易；跟小人交好难、翻脸容易。树难砍倒却好活，木炭一碰就碎，碎了再也拼不回。

**4.28** 虽是弱者若谨慎，强者亦难以消灭，虽是大者若放逸，亦被弱者所摧毁。
→ 白话：弱的只要小心，强的也拿他没办法；大的只要松懈，也会被小的干掉。

**4.29** 多财势力亦增大，耗财势力亦减弱，西瓦意单宝被盗，偷盗之力亦失掉。
→ 白话：钱多势力就涨，钱光势力就落。像那件镇家的宝被盗走，连盗贼自己的力气也跟着丢了。

**4.30** 造有福德施舍者，财富如雨而涌来，若无福泽唯积财，当思谁人会享受。
→ 白话：肯舍的人，钱财像雨一样来。光攒不舍的，该想想最后是谁在享受这些。

**4.31** 高士暂时虽受衰，复盛犹如上弦月，劣者若遇一次衰，则灭犹如熄灯火。
→ 白话：底子好的人暂时栽了，会像上弦月一样一天天补回来；没底子的人一次失败就全灭，像灯被吹熄。

**4.32** 智者宽待敌人故，最后怨敌被制服，愚者报复敌人故，遭受苦难无间断。
→ 白话：聪明人对敌人宽一点，最后敌人反被收服；糊涂人只顾报复，苦就没完。

**4.33** 学者避开险恶境，此乃英勇之本志，狮子弑杀水牛时，躲开牛角岂胆怯？
→ 白话：聪明人绕开险地，这才是真胆气。狮子顶水牛时还先躲牛角，你能说它胆小？

**4.34** 毕竟一切不观察，盲冲敌众即愚蠢，飞蛾扑打油灯光，彼者岂能成英雄？
→ 白话：什么都不看清就冲进人堆，那是蠢。飞蛾扑油灯，扑得再猛也算不上英雄。

**4.35** 劣者摧毁自所依，正士保护自所依，如虫吃尽自所处，狮子保护自居地。
→ 白话：小人毁掉自己赖以立足的东西，正派人护住它。有些虫把自己待的地方吃光，狮子却守住自己的山头。

**4.36** 劣者隐瞒不密事，该密之事处处说，高士不隐非密事，宁死亦隐应密事。
→ 白话：小人把不该藏的藏起来，把该藏的到处说。高尚的人不隐瞒没什么好瞒的，该保密的宁死也不说。

**4.37** 劣者有财起慢因，高士有财和好因，狐狸充腹便嚎叫，狮子充腹安静睡。
→ 白话：小人有了钱就傲慢，正派人有了钱反倒好说话。狐狸吃饱就叫个不停，狮子吃饱安静睡。

**4.38** 高士劣者之行为，此二皆依串习力，如蜂寻花鸭喜水，此等不学亦自知。
→ 白话：好行为坏行为都是重复练出来的。蜂找花、鸭下水，不用学就会。

**4.39** 恶王若遇怨敌时，反而惩治自眷属，有些愚者未成事，亦以自杀而送命。
→ 白话：坏君王碰上对手，反倒收拾自己人。有些糊涂人事情没做成，先把命赔了。

**4.40** 法王若遇怨敌时，对自眷属更慈爱，如于生病之孩子，母亲更会起怜惜。
→ 白话：讲法的君王碰上对手，对自己人反而更疼。像孩子生病时，母亲格外心疼。

**4.41** 高士相合与劣者，则受恶习之熏染，恒河水味特甘美，若进大海成卤水。
→ 白话：高尚的人跟混的人搅在一起，也会被带坏。恒河的水再甜，流进大海就成了咸水。

**4.42** 劣者若依高尚士，则生高尚之行为，犹如涂抹麝香者，散发麝香之芬香。
→ 白话：混的人要是肯跟着高尚的人，也会做出高尚的事。像身上抹了麝香的人，走到哪儿都带那股香。

**4.43** 圣者巍然极稳固，犹如山王不动摇，劣者行为变化多，如同柳絮随风飘。
→ 白话：圣人在哪儿都稳，像大山不被风吹动。混的人一天一个样，像柳絮跟着风飘。
