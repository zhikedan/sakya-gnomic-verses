# 《萨迦格言》白话全书 · 第七品 观察非理

> 体例：一行原文，一行「→ 白话」。白话只做直译＋喻体落地，不加感悟、不掺解释。
> 本品讲不合理之行：越分、放逸、颠倒、积而不施、过量。
> 7.2「信赖女人」、7.4「豺狼」等是 13 世纪社会语境的表述，白话照原译写出，并在句末标注取其原则、不取对象。

**7.1** 奴仆之人自傲慢，苦行之士讲究衣，国王不依教法行，此三即是不合理。
→ 白话：当下人的摆架子，修行人讲究穿戴，君王不守规矩——这三样都是位置上不该有的样子。

**7.2** 承办力所不及事，结仇众人争强士，信赖女人交恶友，五者为速毁自因。
→ 白话：接自己扛不动的活、跟大众结仇、跟强者争、轻信不该托付的人、交坏朋友——这五条是自毁的快车道。【"女人"是13世纪语境，取其原则：别把身家押在你控制不了的人身上，不取性别判定】

**7.3** 无财而欲着妙衣，于人乞讨又自慢，不懂经论想辩论，此三众人所笑处。
→ 白话：没钱偏要穿好衣服，一边讨饭一边摆架子，不懂道理偏要上台辩论——这三样是旁人看笑话的对象。

**7.4** 虽有美丽富饶境，恶人尚贪偏僻乡，如郁金花当成肉，除彼豺狼谁作想？
→ 白话：明明有富饶好地方，坏人偏去贪荒僻的角落。把野花当肉吃——除了豺狼，谁会有这种想法？

**7.5** 大者所受之迫害，出于自眷较敌多，如同狮子自身虱，此外含生谁敢咬？
→ 白话：有分量的人受的伤，多半来自自己人，不是敌人。狮子身上的虱子才敢咬它，别的动物不敢。

**7.6** 倘若主人害自己，则此余人谁拯救？设使显现遮色法，则见彼色有何法？
→ 白话：连自己人都要害你，还能指望谁来救？要是有人专门用东西遮住颜色，你用什么办法看出那是什么颜色？

**7.7** 若害如法静行者，此人极为卑鄙也，若杀托庇自己人，谁人会说彼英雄？
→ 白话：伤害老实本分、不惹事的人，这种人最卑鄙。杀投奔你求庇护的人，谁会说你是英雄？

**7.8** 尽管自己无稍利，恶人亦要害他众，犹如毒蛇虽食气，遇见他众尚咬死。
→ 白话：对自己一点好处都没有，坏人也照样害人。毒蛇喝风也能活，见着别的动物还是要咬。

**7.9** 愚者贪欲以为乐，实则行贪即苦因，如同饮酒以为乐，实则疯狂当安乐。
→ 白话：糊涂人把贪当成快乐，其实贪本身就是苦的来处。像喝酒当享受，其实是把发疯当舒服。

**7.10** 若有学问世人敬，学问亦从精进来，若不勤学诸知识，怨恨他人有何益？
→ 白话：有学问的人受敬重，学问靠勤奋换来。不肯勤学却眼红别人，一点用都没有。

**7.11** 诸人羡慕得长寿，又复恐惧成衰老，畏惧衰老望长寿，此乃愚者之邪念。
→ 白话：人人都羡慕活得长，又怕自己变老；一边怕老一边求长寿——这是糊涂人的拧巴念头。

**7.12** 何人学者身旁时，若不向他学知识，则定此人遭受魔，或是业力所逼也。
→ 白话：守着明白人却不学他的东西，这人不是被什么迷住了，就是运气堵着。

**7.13** 若人具备受用时，既不享受也不施，则定此人受疾病，或是现前饿鬼也。
→ 白话：手里有东西，既不用也不给，这种人要么是有毛病，要么就是活在眼前的饿鬼。

**7.14** 了知教法未修行，则彼教法有何用？庄稼长得虽壮盛，猛兽对此何生喜？
→ 白话：懂了道理不照着做，道理有什么用？庄稼长得再旺，猛兽看了也不高兴——它不吃这个。

**7.15** 业力所逼之众生，有财亦不会享用，如同乌鸦饥埋食，岂能复得自享用？
→ 白话：被时运逼住的人，有钱也不会花。像乌鸦饿的时候把食物藏起来，藏完就找不着了。

**7.16** 既不享受又不施，彼财若当成富裕，则可将山视黄金，此为富裕垂手有。
→ 白话：又不用又不给，这样也算有钱的话，那把山看成金子就行了——发财变得唾手可得。

**7.17** 能讲种种法非法，如此学者虽极多，然能知法修行者，于此世人真稀少。
→ 白话：能讲清什么对什么不对的人很多，可既懂又照着做的，世上极少。

**7.18** 贵种体端韶年者，若无学问不为美，如同孔雀羽虽美，岂为伟人之装饰？
→ 白话：出身高、长相好、年纪轻，没有学问也不算美。孔雀羽毛再漂亮，谁把它当大人物的装饰？

**7.19** 伪装鼻子购得子，借人之饰盗得财，无有师承之智等，虽得世众亦不齿。
→ 白话：装出来的、借来的、偷来的，还有没人教过却自称懂的——这些东西就算到手了，众人也不认。

**7.20** 何人不知报恩惠，此人先已害自己，如同学习害人术，损人之前先害己。
→ 白话：不懂报恩的人，先已经把自己害了。像学害人的法术，还没伤到别人，自己先受损。

**7.21** 尽管明知得受用，非理之处谁肯取？野羊相斗顶淌血，狐狸求之头撞破。
→ 白话：明知有好处，但不合道理的东西谁该去拿？野羊打架撞得头流血，狐狸想去捡便宜，反把头撞破了。

**7.22** 不应依照某关系，即将随意舍他人，即使帝释天王者，彼眷亦皆会逃避。
→ 白话：不能因为一点关系不合就把人随手丢掉。这样做，就算你是天帝，身边的人也会跑光。

**7.23** 情深老友不应舍，亦勿信任诸新友，鸱鸮王依乌鸦臣，最终摧毁自己也。
→ 白话：交情深老朋友不该丢，刚认识的人也别一上来就托底。猫头鹰王用乌鸦当臣子，最后把自己毁了。

**7.24** 竭力亲近恶劣者，亦不能成自己人，如同将水再煎熬，亦不会在火中燃。
→ 白话：再怎么贴混的人，他也成不了自己人。像把水一直烧，它也不会着火。

**7.25** 若知事因而生嗔，则稍有理亦知除，若无事因而生嗔，谁知除嗔之良法？
→ 白话：有来由的火气，讲点道理还能消；没来由的火气，谁有办法消？

**7.26** 若无观察怨敌力，虽是弱小不应辱，如同欺负达支巴，大鹏胜伏大海也。
→ 白话：没摸清对方的斤两，就算他看着弱小也别去侮辱。像去欺负那个小东西，结果引来大鹏把海都填了。

**7.27** 尽福之时生恶念，尽族之时生劣种，尽财之时生悭吝，尽寿之时生死兆。
→ 白话：福报快尽时生恶念头，家道快尽时出败家子，钱财快尽时越发小气，寿命快尽时净见死兆。

**7.28** 自己不为违法事，帝释诋毁亦无道，泉眼自己不干涸，泥土怎能堵塞彼？
→ 白话：自己不越界，别人再毁谤也没用。泉眼自己不干，土怎么能堵得住它？

**7.29** 同时启做百样事，一件事亦未究竟，狡黠之人如老狗，常于村间乱窜游。
→ 白话：同时开一百件事，一件都做不完。耍小聪明的人像老狗，在村子间窜来窜去。

**7.30** 若受业力感召时，智者亦会行邪道，外道胜师大自在，行持疯狂之禁戒。
→ 白话：时运裹住人的时候，聪明人也会走偏。连外道的大宗师，也会去修荒唐的苦行。

**7.31** 倘若何人违法规，暂时得胜终失败，如同曲甲违法规，虽得悉地终遭杀。
→ 白话：破了规矩的人，眼下赢了，最后还是要输。像曲甲违规修行，虽然一度得了成就，终究被杀。

**7.32** 过越聪明多事者，最后即将毁自己，国王广思多念者，终将摧毁自国政。
→ 白话：自作聪明、管得太多的人，最后毁的是自己。君王思虑过度、政令太繁，反而把国事搞坏。

**7.33** 积集财物过多者，彼财即为索命鬼，富翁往往遭祸害，乞丐岂非常安闲。
→ 白话：攒得太多，那堆东西就变成讨债的鬼。有钱人常惹祸，要饭的反而清闲。

**7.34** 威力过于高强者，此乃送命之前行，沙场之上死亡者，多半皆为强力士。
→ 白话：把强势用到过头，是找死的前兆。战场上死的多半是自以为最能打的那个。

**7.35** 财富智慧势力等，有福之人即助缘，倘若无有福泽者，彼等亦成毁己因。
→ 白话：钱、本事、势力，对有福气的人是帮手；对没福气的人，同样这几样变成毁他的东西。

**7.36** 智者无论为何事，观察自福而行之，诤时圆满福泽者，百人之中亦难得。
→ 白话：聪明人办任何事先掂量自己这点家底够不够。能在争斗中全身而退、什么都保住的，一百个人里也挑不出一个。

**7.37** 若于劣塘灌满水，定有一处会崩溃，何人具有财富时，其之种族极难旺。
→ 白话：把不好的池塘灌满，一定会从哪一处溃开。人有了大钱，家族反而很难兴旺。

**7.38** 有子之时无财富，有财之时受敌害，若此一切圆满时，往往众人速死亡。
→ 白话：有了孩子没钱，有了钱又受敌人害；等这一切都齐了，人往往也快走了。

**7.39** 是故智者积福德，造福即是安乐因，何人一切诸圆满，此乃积福之本相。
→ 白话：所以聪明人攒的是福德——造福才是安乐的来处。一个人样样齐全，那是攒出来的福的样子。

**7.40** 若思谎言诱他人，实为此人骗自己，若说一次妄语后，彼言实语亦生疑。
→ 白话：想用谎话钓别人，其实是骗自己。撒过一次谎，往后你说真话别人也要打折扣。

**7.41** 不细观察贤劣时，一嗔不应害他众，如同鸽子杀自妻，后生失伴之忧愁。
→ 白话：没看清对方是好是坏，别一怒就下狠手。像公鸽子一怒杀了自己的配偶，之后为失去伴而发愁。

**7.42** 未来众事不应管，到来之时竭力做，遇见河水方脱鞋，不见河水何必矣？
→ 白话：还没来的事别先操心，来了就尽全力去做。像走到河边才脱鞋，没见着河，脱什么鞋？

**7.43** 将来不能成之事，即使再妙亦勿为，腹中不能消化食，即使再香谁肯食？
→ 白话：注定成不了的事，再漂亮也别做。像吃了消化不了的东西，再香谁往嘴里送？

**7.44** 若无精进贪乐者，今生来世无成就，若无精勤耕耘者，肥田中亦不得收。
→ 白话：又懒又贪舒服，这辈子下辈子都成不了事。不肯下地耕，再肥的田也收不到东西。

**7.45** 非处过越柔弱者，则彼众人会使唤，如同棉花常作垫，谁人树枝当为垫？
→ 白话：在不该软的地方软过头，谁都能来使唤你。棉花天生当垫子，树枝谁拿去垫？

**7.46** 劣事或永不成事，让做即做为愚者，犹如谁信买毒药，谁人能说一切施。
→ 白话：坏事、永远做不成的事，别人一叫你就去，这是糊涂。谁会去买毒药？谁能真的什么都舍出去？

**7.47** 积财而不享用者，此乃积攒自焚薪，蜜蜂酿蜜自不食，他人取之自丧命。
→ 白话：攒着钱自己一分不用，那是给自己堆柴烧。蜜蜂酿蜜自己吃不着，别人来取，它反倒丢了命。
