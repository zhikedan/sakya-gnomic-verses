# 《萨迦格言》白话全书 · 第三品 观察愚者

> 体例：一行原文，一行「→ 白话」。白话只做直译＋喻体落地，不加感悟、不掺解释。
> 本品的「愚者」是伦理判断（不辨善恶、不受教、自我中心），不是智商低。
> 3.19—3.22 含 13 世纪社会语境（把"像女人""有残疾"当贬义），白话照原意译，取其原则：反常环境会颠倒评价标准，不取其对特定人群的看法。

**3.1** 恶人尽管得财富，行为变得更恶劣，瀑布无论再阻挡，然彼一直往下流。
→ 白话：坏人有了钱，只会更坏。瀑布你越去拦，它越是一个劲儿往下冲。

**3.2** 劣者有时变善良，此行即是伪装相，玻璃涂上珠宝色，遇见水即露本相。
→ 白话：混的人偶尔装出好样子，那正是他在演。玻璃涂上一层珠宝的颜色，一沾水就露馅。

**3.3** 愚者虽然完成事，亦是运气非本事，如蚕会吐丝抽线，并非彼之巧本事。
→ 白话：糊涂人偶尔办成事，是运气不是能耐。蚕也会吐丝结线，那不算它的巧本事。

**3.4** 大者精勤成协议，恶人一瞬便摧之，农夫累时种庄稼，冰雹一瞬即毁尽。
→ 白话：正经人辛苦谈成的事，坏人一下子就能砸掉。农民起早贪黑种出的庄稼，一场冰雹就全没了。

**3.5** 劣者自己之过失，总是染推于他人，乌鸦自食不净嘴，使劲擦于干净处。
→ 白话：自己的毛病，全推到别人身上。乌鸦吃了脏东西，嘴要在干净地方使劲擦——脏在自己身上，却去弄脏别处。

**3.6** 若让愚者办事情，既是毁事又毁己，如兽狐狸立为王，众兽受苦自亦亡。
→ 白话：让糊涂人管事，事情毁掉，他自己也毁掉。狐狸被立成兽王，所有兽跟着受罪，它自己也活不长。

**3.7** 愚者欲求为安乐，所作皆成为痛苦，如同有些遭魔者，为除痛苦而自杀。
→ 白话：糊涂人想要的是安稳，做出来的却全是苦。像某些中了邪的人，为了摆脱痛苦反而把自己弄死。

**3.8** 愚蠢又是憨直人，有者毁己有伤他，林中直树被人砍，笔直利箭会伤他。
→ 白话：又蠢又"直"的人，有的先毁自己，有的直接伤人。林子里最直的树最先被砍，笔直的箭最会伤人——不加判断的直，是凶器。

**3.9** 平日不为利他想，此人行为如牲畜，唯寻自己之吃喝，岂非牲畜亦能行？
→ 白话：平时从不替别人想，这种活法跟牲畜没区别。只顾找吃找喝，牲口不也这样吗？

**3.10** 不察有益和无益，不求智慧不闻法，惟有寻求充腹者，真实一头无毛猪。
→ 白话：不管什么有用什么没用，不学不问，只想着填饱肚子——那就是一头没毛的猪。

**3.11** 愚者之中欢欣游，学者之前怯而躲，颈无垂肉顶无峰，具有上牙黄牯牛。
→ 白话：只在糊涂人堆里自在，见到明白人就发怵躲开。脖子上没垂肉、头顶没肉峰、还缺上牙的那头黄牛——它不是牛的样子，也干不了牛的活。

**3.12** 若有饮食至彼处，委托办事时逃避，虽能说话亦能笑，仍是无尾之老狗。
→ 白话：有吃的就到场，派他办事就溜。会说话、会陪笑，也只是条没尾巴的老狗——缺的那一件东西，正是干不了活的证据。

**3.13** 蹄窝易被水灌满，小库易被财装满，小田容易播种子，浅学之人易自满。
→ 白话：马蹄印一小洼水就满，小仓库装点东西就满。学得不深的人最容易满足——容器小，才显得满。

**3.14** 愚者傲慢轻诺者，势力再大亦失败，非天施给一步地，遍入天得三界也。
→ 白话：又骄傲又随便许诺的人，势力再大也要败。对方只给一步之地，他反倒把三界全丢了。

**3.15** 小人心藏怀恨时，害他之前露表情，恶狗已见怨敌时，咬人之前狂乱吠。
→ 白话：小人心里记恨，还没动手脸上先露出来。恶狗看见了要咬的人，先狂叫一通——藏不住，是它的破绽。

**3.16** 愚者唯受积财苦，始终不得积财乐，又复寻求看守财，悭吝积财如老鼠。
→ 白话：糊涂人只尝到攒钱的苦，从没尝到攒钱的乐。一边攒一边守，守得比挣还累，像老鼠屯粮。

**3.17** 学者处于愚者前，不如耍猴之高贵，耍猴之人得食财，学者空手而行也。
→ 白话：有学问的人在糊涂人堆里，还不如耍猴的吃香。耍猴的能讨到钱，读书人两手空空。这是环境的评价体系坏了，不是学问不值钱。

**3.18** 无有学问之士众，特别嫉恨有学者，冬天雪域长庄稼，诸人视为不祥兆。
→ 白话：没学问的人群里，最恨有学问的人。就像大冬天雪域高原上长出了庄稼，人不觉得稀奇，反倒认为是不祥之兆——环境排斥超出它认知的东西。

**3.19** 有些学习邪道者，经常轻毁好学士，如同某些岛屿上，无瘿当为残肢者。
→ 白话：学偏了的人，专门瞧不起真学问。就像某些岛上人人脖子上都长肉瘿，谁没有反倒被当成残疾人。【13世纪社会语境，取其原则：标准颠倒时，正常反被视为异常】

**3.20** 有些仪轨不全者，欺凌圆满仪轨士，犹如至于仔达地，凡长双足不算人。
→ 白话：自己规矩不全的人，去欺负做得圆满的人。到了某些地方，长着两条腿的都不算人——规则由当地定，你按外面的标准去比没用。【同上，取原则不取对象】

**3.21** 有些邪行仪轨者，辱骂正行仪轨士，如同自长狗头者，美男讥毁为女人。
→ 白话：行为不正的人反骂品行端正的人。就像自己长了狗头，反倒讥笑相貌堂堂的人。【原译把"像女人"当贬义，是13世纪语境；取其原则：有毛病的人靠贬低别人来抬高自己，不取其对女性的看法】

**3.22** 有些邪命养活者，特别蔑视穷学者，犹如老猴抓住人，嘲笑说他无尾巴。
→ 白话：靠不正当手段谋生的人，最看不起清贫的读书人。像老猴抓住人，反过来笑人没尾巴——它只看见别人缺的那一样。

**3.23** 若遭业力之逼迫，智者亦入愚人中，犹如芬香茉莉花，被风刮进粪中踏。
→ 白话：时运不济的时候，聪明人也会落到糊涂人堆里去。像香的茉莉被大风刮进粪堆踩了——不是花不香，是位置错了。

**3.24** 精勤持执诸过患，不存毫许之功德，劣者即同滤水器，唯留渣滓漏精华。
→ 白话：勤奋地抓住毛病不放，一点好处都不留。混的人就像滤水器，渣滓留下，精华漏掉。

**3.25** 无有辨别善恶者，学者之前受驱逐，整天谈论钱财食，此即双足之畜牲。
→ 白话：分不清好坏的人，在明白人面前待不住。整天只谈钱和吃，那就是长了两条腿的牲口。

**3.26** 小人即使再多聚，不能成办大事件，犹如芨草捆再多，不能作为大厦柱。
→ 白话：靠不住的人再多，也办不成大事。芨草捆成一堆堆，也当不了房子的柱子——数量补不了材质。

**3.27** 未经观察虽成事，谁会当彼为智者，如虫咬出花纹时，虽成文字非书家。
→ 白话：没经过思考就做成的事，谁也不会因此当他聪明。虫子偶尔咬出了像字的纹路，那是巧，它不是书法家。

**3.28** 愚者所说之诳语，未经驯服之良马，掉落战场宝剑等，对谁有利尚不定。
→ 白话：糊涂人的谎话、没驯过的好马、战场上掉落的宝剑——这三样落在谁手里还不一定，别以为它们只伤别人。

**3.29** 无智愚者再众多，亦会被敌所制服，成群具势大象众，亦被一兔皆驱逐。
→ 白话：没脑子的再多，也会被对手压住。成群的大象，可能被一只兔子全赶跑——人数和块头都不算数。

**3.30** 无智光有财富者，多半对自无益处，犹如奶牛之乳汁，牛犊能喝极罕见。
→ 白话：有钱没脑的人，多半享受不到自己的钱。像母牛的奶，小牛能喝上的机会极少。

**3.31** 学者处于愚者前，亦不一定会尊敬，犹如阳光虽明灿，岂非魔鬼皆逃避？
→ 白话：有学问的人在糊涂人面前，不一定受敬重。阳光再亮，见不得光的东西只会躲开它，不会感谢它。

**3.32** 愚者唯顾积财富，此人怎有亲友念？苦罪积财如老鼠，终于人死财留世。
→ 白话：只顾攒钱的人，哪还有心思顾亲友？辛辛苦苦攒下，到头人死了钱留在世上，一分没带走。

**3.33** 恶劣愚者聚会中，有学之士怎受敬？犹如居住毒蛇处，灯火再亮不发光。
→ 白话：在坏人堆里，有学问的人得不到尊重。像屋里满是毒蛇，灯再亮也不敢点。

**3.34** 恶业深重悭吝者，有财亦无享受时，犹如葡萄成熟时，乌鸦经常生嘴疮。
→ 白话：又吝啬又造业的人，有钱也轮不到享受。像葡萄熟的时候，乌鸦偏偏嘴上长疮——东西熟了，他正好吃不了。

**3.35** 常依他人扶持者，一旦此人会遭殃，天鹅所携之乌龟，终于摔死于地上。
→ 白话：一直靠别人抬着的人，那个人一倒，他也完蛋。天鹅叼着乌龟飞，乌龟最后是被摔死的——它的命不在自己爪子上。

**3.36** 不辨善恶忘恩惠，希有谈论不生奇，现量所见亦询问，胆怯盲从愚者相。
→ 白话：分不清好坏、记不住人情，听到稀罕事也不觉稀奇，亲眼见到的还要反复问，遇事就跟着人走——这是糊涂人的几个记号。

**3.37** 懦夫仅嘴说灭敌，远见怨敌恐叫号，战场遇敌敬合掌，返回家中说大话。
→ 白话：胆小鬼嘴上说要灭敌，远远看见对手就吓叫；真到阵前双手合十客客气气，回到家又吹得天花乱坠。

**3.38** 懦夫商议时勇敢，一旦派差即算财，出征之时复生病，远见战场亦惧喊。
→ 白话：议事的时候他最勇敢，一派任务就装病算账；还没开打，远远望见战场就先喊怕。

**3.39** 懦夫稍胜便自诩，一旦失败恨亲友，集会讨论引争论，秘密商议亦泄漏。
→ 白话：赢一点就到处吹，输了就怪自己人。开会时挑事吵架，机密的事转头就说出去。

**3.40** 沙场之上擦拭衣，遇见恨敌即躲避，亲近彼较敌生惧，武器送于怨敌前。
→ 白话：战场上只顾掸自己衣服，见了仇人就躲；跟他亲近的人比对手还怕他，手里的兵器反倒送到了敌人面前。

**3.41** 列队上阵在排尾，凯旋归回在排头，若见吃喝拼命挤，遇见难事设法躲。
→ 白话：上阵时站最后，得胜回来时跑最前；有吃的拼命挤，有难事先躲开。

**3.42** 如此凡是恶人相，虽有不可思议数，然谁愿掏脏水坑，智者谁尝呕吐味。
→ 白话：坏人的样子说也说不完。但谁愿意去掏那口脏水坑？明白人连尝过的苦头都不肯再尝第二次。

**3.43** 为人指示撅嘴唇，说话之时仅眨眼，听闻传记出呻吟，此人亦具庸俗相。
→ 白话：给人指路时撅嘴，说话时只会挤眼睛，听人讲事迹就哼哼出声——这些也是上不了台面的样子。
