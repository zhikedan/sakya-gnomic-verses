# 《萨迦格言》白话全书 · 第八品 观察事业（下：8.49—8.95）

> 体例：一行原文，一行「→ 白话」。白话只做直译＋喻体落地，不加感悟、不掺解释。

**8.49** 弱者以为自所说，一切皆会出差错，了知此义不多言，彼者会受人尊敬。
→ 白话：没分量的人知道自己开口多半会出错，想明白这一点就少说话——这样反受人尊敬。

**8.50** 若遇应时合境时，当以谨慎说少语，虽有善说若过多，如同剩货无人用。
→ 白话：场合对了、时间对了，也要谨慎地说得少。话说得再多再漂亮，过了量就像卖剩的货，没人要。

**8.51** 虽是广闻博学士，亦难认识自过失，众人若指自过失，则能推知自有过。
→ 白话：见多识广的人也难看清自己的毛病。要是大家都来指出你的问题，那就能断定你确实有过错。

**8.52** 虽知过失而不改，此人定是遭魔缠，若尚不依对治者，自己切莫视为人。
→ 白话：知道错还不改，这人像被什么缠住了。连治法都不肯用的，你自己也别把他当可交往的人。

**8.53** 稍有辨别智慧众，当知过失并除之，如是常依对治者，此人日日会上进。
→ 白话：有一点判断力的人，看出毛病就改掉。能长期这么治自己的，每天都在往上走。

**8.54** 聪明之人仁慈者，随和之人勇敢者，彼等不知其余事，亦应各行而护之。
→ 白话：聪明又心软的、好相处又敢事的，就算他们别的都不懂，也该让他们各干各的、护住他们。

**8.55** 虽久交往蛮横者，然彼远离则安乐，翁云动牙虽为美，然彼拔掉得安乐。
→ 白话：跟蛮横的人处了多年，真离开才松快。就像老人那颗晃动的牙看着还舍不得拔，拔掉才知道舒服。

**8.56** 时常怨争之眷属，为彼稍施当驱逐，毒蛇所咬之伤口，不能切除则离命。
→ 白话：成天抱怨惹事的身边人，给点好处打发走。被毒蛇咬的伤口，不切掉就没命。

**8.57** 设使已成高者时，不必吝啬琐碎物，若能制服诸眷民，不必悭吝珠宝也。
→ 白话：已经站到位子了，就别在小东西上抠。真能管住自己人，珠宝也不必死攥着。

**8.58** 智者若欲积财富，稍微施舍方护财，若欲井水常充盈，舀水便是胜窍诀。
→ 白话：想攒钱，得舍出去一点才守得住。想让井一直满，最好的办法是常去舀它。

**8.59** 何者若欲皆圆满，彼当忙碌种种事，若见琐事痛苦因，则应断尽彼妄想。
→ 白话：什么都想要齐全，就得被各种杂事缠住。看清这些琐事正是苦的来处，就先把这个念头断掉。

**8.60** 无论需做任何事，当思功德与过患，德过等亦不应为，过多德少何堪言。
→ 白话：办任何事先掂量好处和坏处。好坏相等的都不该做，坏处多好处少的更不必说。

**8.61** 敬依正直之学者，谨慎狡诈之学者，慈护诚实之愚者，速弃狡诈之愚者。
→ 白话：四种人分开待——正直又有学问的，恭敬依靠；狡猾但有学问的，来往时要谨慎；糊涂但老实的，慈悲护着；又糊涂又狡猾的，赶紧甩掉。

**8.62** 虽无财富眷仆等，若有具慧之善友，傍生亦能成办事，何况说为人众矣？
→ 白话：没钱没仆人不要紧，只要有一个有智慧的益友，连畜生都能办成事，何况是人。

**8.63** 委托应予所知事，不知之事莫强迫，马车不能水上行，舳舻不能陆上行。
→ 白话：把事交给人，要交他会的；不会的别硬逼。马车下不了水，船也上不了岸。

**8.64** 结下深怨之恨敌，虽成和好莫密切，如同高温滚沸水，若遇火焰亦熄灭。
→ 白话：结过深仇的人，就算和好了也别交底。滚开的水再往上添火，也会浇熄——表面平了，底下还是烫。

**8.65** 若知羞耻忠厚者，虽是怨敌可信任，非天投靠忠厚敌，彼亦拼命护非天。
→ 白话：知道廉耻、待人厚道的人，就算是对手也可以托付。连非天去投奔忠厚的仇家，对方也会拼命护着他。

**8.66** 虽说自己无劣心，亦勿轻信所有众，野兽恒时心虽善，彼等猛兽当为食。
→ 白话：别因为自己没坏心，就谁都信。野兽平时看着驯，可它们照样要吃别的生灵。

**8.67** 倘若愚者入邪道，了知愚者即可足，倘若智者入邪道，则应观察其原因。
→ 白话：糊涂人走歪了，知道他是糊涂人就够了；明白人走歪了，得去查原因——他背后一定有别的因由。

**8.68** 学者善于用财物，即使不赐亦不夺，耗财之境虽不夺，亦以借贷等毁财。
→ 白话：会花钱的人，既不白给也不硬抢。那些败钱的地方，虽然没人抢你，靠借贷、人情也能把你掏空。

**8.69** 自己虽知一切事，亦尚需与人协商，谁者不愿人协议，此人自引自悔恨。
→ 白话：就算什么都懂，也还得跟人商量。谁不愿意商量，谁就是在给自己攒后悔。

**8.70** 设使协商险怖事，再亲亦莫过三者，如修起尸有恶伴，首先食掉修者也。
→ 白话：商量危险的事，关系再好也别超过三个人。像那种邪术修法，同伙先把他自己吃了。

**8.71** 了知取舍平等施，温和可亲尊重人，无所畏惧不唐捐，谁人具此得诸地。
→ 白话：懂取舍、施舍不偏、温和待人、心里不惧、 effort 不白花——谁具备这几条，就能到处站住脚。

**8.72** 设使敌人来投靠，亦应供养并赞美，传说乌鸦依老鼠，次后获得安乐也。
→ 白话：敌人来投奔，也该供着、说好话。故事里乌鸦投靠老鼠，后来过上了安稳日子。

**8.73** 交结劣友闻劣论，持执邪见作劣事，此等智者不应行，若行即是愚者也。
→ 白话：交坏朋友、听歪道理、抱错误见解、干下作事——这四样明白人不该碰，碰了就是糊涂。

**8.74** 若善观察而行动，此事怎能成失败？智者睁眼行大道，怎能堕入深渊中？
→ 白话：看清楚再动手，怎么会失败？明白人睁着眼走大路，怎么会掉进深坑？

**8.75** 既能利己又利他，学习知识智者相，有些知识如射者，一旦精通家族毁。
→ 白话：学了既帮自己也帮别人，这才是聪明人的学法。有些本事像射箭——练得再精，也可能把自家毁了。

**8.76** 自己若欲得高位，则当惟有利他众，如同修饰容貌者，首先岂非擦镜子。
→ 白话：想往上走，只管去利益别人。像想让自己好看的人，先擦干净镜子。

**8.77** 若欲降伏诸对方，则自竭力学本领，犹如欲杀怨敌者，先自竭力造兵器。
→ 白话：想压住对手，先把自己的本事练出来。像要上阵杀敌的人，先在家把兵器造好。

**8.78** 狡者之语有搀假，诚者对此需观察，诱后自称真诚者，如是自夸有何益？
→ 白话：狡猾人的话里掺假，老实人更得留神分辨。骗完人再自称真诚——这种自夸有什么用？

**8.79** 昔日褒文中宣说：狡者之前需狡诈，直者之前需真诚，动者之前需坚固。
→ 白话：古人说过：面对狡猾的人要会应变，面对直爽的人要真诚，面对动摇的人要站得稳。

**8.80** 智者恒时对怨敌，亦应和蔼如亲友，虽然不能得和解，定是熄怨之良药。
→ 白话：明白人对敌人也长期和和气气像自家人。就算和不成，这也是灭火的药。

**8.81** 若说恶言劣语者，此世不会成自愿，心中虽想为私利，言说亦应合世众。
→ 白话：说难听话的人，这辈子办不成自己想做的事。心里再为自己盘算，话也得说得合得住众人的口。

**8.82** 若对自他有利事，无论粗暴或温和，皆行善巧方便故，佛陀未说是谄诳。
→ 白话：对自己对别人都有好处的事，手段硬一点或软一点都行。那叫善巧方便，佛没说这是拍马骗人。

**8.83** 最终有利之协议，智者暂苦亦履行，学者衰老又遭苦，亦将知识传后人。
→ 白话：长远有利的约定，暂时吃亏也要守着。学问人又老又苦，也要把东西传给后人。

**8.84** 设使受用过增者，彼者速会遭衰失，如同池塘过满水，或是冲堤或越水。
→ 白话：享受加码太狠，很快就要栽。池塘灌太满，不是溃堤就是溢出去。

**8.85** 于某些人有利事，余人不定有利益，蒜头治风虽有效，而对胆病却成毒。
→ 白话：对一些人管用的，对另一些人不一定。蒜治风湿有效，落在胆病上就是毒。

**8.86** 若恒亲近脆弱者，大者亦恐将衰败，酥油若置劣器中，老鼠岂不啃坏彼！
→ 白话：长期跟不牢靠的人搅在一起，再大的架子也会塌。酥油放在劣质的容器里，老鼠能不啃穿它吗？

**8.87** 倘若依靠恶劣众，恶习熏染害自己，依赖渠水之鱼众，田地之上遭撒弃。
→ 白话：靠坏人，坏毛病会把你带坏。住在渠水里的鱼，水被田里放干，就摊在岸上晒死。

**8.88** 寡情之人来投靠，于彼稍施当驱逐，如同家中起恶兆，当需耗财而消灾。
→ 白话：没良心的人来投奔，给点东西打发走。像家里出了凶兆，花点钱消灾比留着它划算。

**8.89** 正士即使赴他处，亦应尊敬及承侍，若常敬奉如意宝，则增吉祥成所愿。
→ 白话：正派人就算去了别处，也该照样尊敬、照样照应。像常供着如意宝，好事会加上来，愿望会成。

**8.90** 若人过越赞劣者，次后自己受毁谤，如向空中掷粪便，其落掷者之顶上。
→ 白话：把小人捧得太过，回头挨骂的是你自己。像朝天扔脏东西，落下来扣在自己头上。

**8.91** 若人侮辱有学士，则彼自己会遭殃，犹如灯火向下垂，此人自手会烧伤。
→ 白话：侮辱有学问的人，遭殃的是自己。灯焰倒垂下来，烧的是拿灯的那只手。

**8.92** 无论何法何相应，彼法应当如是用，首饰不能戴足上，足镯不能用顶饰。
→ 白话：任何东西都有它对应的用法，按那个用。头饰不能套脚上，脚镯也不能戴在头上。

**8.93** 成办巨大事业时，竭力依靠善妙友，犹如火烧茂林时，务必依靠大风助。
→ 白话：要办大事，就尽力依靠好朋友。像烧一大片林子，非得有风帮忙不可。

**8.94** 仁慈者说温和语，他人欢喜易成事，谁能耗财令人喜，舍弃身寿亦难足。
→ 白话：心好的人说话温和，别人听着高兴，事就好办。要是非靠花钱买人高兴，把命和钱都搭进去也填不满。

**8.95** 不因穷困极忧伤，不因富有喜而慢，业力所牵遥远故，种种苦乐随后现。
→ 白话：别因为穷就痛不欲生，也别因为富就得意忘形。因果拉得很长，苦和乐都会在后头陆续显出来。
