# 《萨迦格言》白话全书 · 第一品 观察学者

> 体例：一行原文，一行「→ 白话」。白话只做直译＋喻体落地，不加感悟、不掺解释。
> 校验：`node check_baihua.js` 逐颂比对颂文与 `references/20-全文.md` 是否一致，并检查是否每颂都配了白话。

**1.1** 智者即是学问库，彼等收集格言宝，如海即是江河库，是故百川流大海。
→ 白话：有智慧的人本身就是一座知识仓库，好的道理都往他那儿聚；就像海是江河的仓库，所以百川统统流进海里。

**1.2** 无论有或无学问，能知取舍为智者，犹如铁屑混灰尘，磁石方能吸出彼。
→ 白话：读没读过书不算数，能挑出该要的、扔掉该扔的，才算聪明。铁屑和灰尘混在一堆，只有磁石能把铁吸出来。

**1.3** 智者以慧知格言，然而愚者非如是，犹如阳光普照时，鸱鸮皆成盲眼也。
→ 白话：同一句好话，聪明人读出道理，糊涂人只看见字。就像太阳出来，人见光明，猫头鹰反倒瞎了眼——条件一样，接收的人不一样。

**1.4** 智者能除诸过患，然而愚者非如是，大鹏能啄有毒蛇，乌鸦不能如是行。
→ 白话：毛病和祸患，聪明人治得了，糊涂人治不了。大鹏鸟敢去啄毒蛇，乌鸦干不了这事。本事得配得上要解决的问题。

**1.5** 智者即使受挫折，彼智更加成顽强，犹如兽王饥饿时，速能撕裂大象脑。
→ 白话：受了挫，聪明人的脑子反而更硬更清楚。像饿了的狮子，出手就能撕开大象。挫折对他是加压，不是断电。

**1.6** 不询不辩于学者，不知学识之深浅，犹如槌子不擂鼓，彼与余物有何异？
→ 白话：不问、不跟他辩，你永远不知道他懂多深。鼓不拿槌子敲，跟一块木头有什么两样——测深浅唯一的办法是敲。

**1.7** 即使明早要死亡，亦应学习诸知识，今生虽不成智者，来世如自取储存。
→ 白话：就算明天就死，今天照样学。这辈子成不了行家，学到的东西也像存起来的财物，将来自己取得回来。学习不因"来不及"就失去意义。（原译依托轮回观；不接受这套框架，可读作：学问会以你察觉不到的方式留存并传下去。）

**1.8** 设若具有真知识，众人自然会集聚，犹如香花虽远方，蜜蜂环绕如云集。
→ 白话：真有本事，人自己会聚过来。花香再远，蜜蜂也会成片飞过去——不用你到处去找人。

**1.9** 智者学习诸知识，究竟一门通世间，愚者虽是见识广，不能照明如星光。
→ 白话：学问要学到能把一件事彻底想通。见得多懂得杂，像满天的星星，照不亮脚下这条路；一盏小灯胜过一堆星。

**1.10** 智者知识虽渊博，亦取他人之微德，长期如是行持者，速成一切智智位。
→ 白话：懂得再多，也照样从别人身上捡一点长处；能长期这么干的人，进步最快。

**1.11** 智者以慧护自己，怨敌虽多亦无奈，如吾仗那婆罗门，彼子一人摧敌众。
→ 白话：聪明人靠判断力保护自己，敌人再多也拿他没办法。像经书里那个婆罗门，他一个儿子就击溃了整群敌人。

**1.12** 愚者争吵哄闹时，智者设法使之静，如水浑浊不清时，澄清宝珠能清之。
→ 白话：一群人在吵，明白人想法子让它静下来。水浑的时候往里放一颗澄清珠，泥沙自己就沉底了。他的作用是让浑水沉淀，不是把水搅得更浑。

**1.13** 智者无论再计穷，绝不迈步愚者道，犹如燕子虽口渴，绝不吸饮落地水。
→ 白话：办法再穷也不走蠢路。燕子再渴，也不喝落在地上的那口水。看一个人聪明不聪明，就看他走投无路时选什么。

**1.14** 智者虽然被人骗，亦不入迷诸事业，含生蚂蚁虽无眼，较与有眼者更快。
→ 白话：上过当，也不因此把该做的事搞糊涂。蚂蚁看不见路，走得比看得见的人还利索。被骗一次，不等于要丢掉方向感。

**1.15** 若二智者共商议，则将生出善智慧，姜黄硼砂配一起，便会变出余色彩。
→ 白话：两个明白人商量，会长出比两人各自都更好的判断。姜黄和硼砂搁到一起，会调出第三种颜色——结果不等于两样东西相加。

**1.16** 具备智慧造福者，一人亦能胜一切，犹如狮子转轮王，彼等不需友相助。
→ 白话：又有智慧又能给人好处的，一个人也顶用。像狮子和转轮王，不靠帮手。

**1.17** 若有善巧方便法，役使大者亦不难，如同大鹏高本领，亦成毗纽天之骑。
→ 白话：会想办法，使动比你强的人也不难。大鹏鸟本事通天，也只是毗纽天（毗湿奴）的坐骑——本事挂在别人的需要上，才叫杠杆。

**1.18** 求得今生来世乐，皆为依靠智慧力，达瓦王子用智慧，拯救暂桑今来世。
→ 白话：眼前和长远的安稳，都靠智慧挣来。像达瓦王子凭智谋救了整个地方，连后人跟着受益。

**1.19** 即使英勇又顽强，若非智者难得盛，即使获得诸财富，若无福份岂能常？
→ 白话：又勇又猛，但没脑子，很难真正成事。钱拿到了也守不住，不会长久。

**1.20** 谁能了知过与德，智者方能辨彼二，从牛挤奶皆能会，由水分奶唯天鹅。
→ 白话：谁能分清毛病和好处？只有明白人。牛奶谁都会挤；可把混在一起的奶和水分开，只有天鹅办得到。

**1.21** 即使嘱咐又催促，虽是傍生亦能知，他人未说亦未催，自觉领会方智者。
→ 白话：要人反复交代、催着才动的，畜生也做得到。不用人说、不用人催，自己就领会的，才是聪明人。

**1.22** 若具智慧虽不说，表情亦能知所想，未尝尼泊尔之榴，看色亦能知滋味。
→ 白话：有智慧的人不开口，看神色也知道他想什么。没吃过尼泊尔的石榴，看颜色就能把味道猜出来。

**1.23** 智者离开自处境，至于余处更受敬，犹如外地宝畅销，岛上岂有彼销售？
→ 白话：明白人离开本地，到别处反而更受尊重。珍宝常常在产地不值钱，运到外地才卖得上价。

**1.24** 智者学时即困苦，贪乐安住不成名，贪图微小逸乐者，彼将不会得大乐。
→ 白话：学的时候本来就苦。贪图舒服的人成不了事；恋着一点小安逸的人，拿不到真正的大好处。

**1.25** 若具智慧虽弱小，有势怨敌亦无奈，兽王虽有强势力，具智兔儿谋杀之。
→ 白话：有脑子，弱小也不怕，势力再大的敌人也拿你没办法。狮子力气那么大，却被一只动了脑筋的兔子弄死。

**1.26** 若知所作同他人，和睦相处即智者，即便傍生同类众，岂非类聚住一群？
→ 白话：知道怎么跟人配合、处得来，就是聪明。连动物都是同类凑在一块儿过活的。

**1.27** 必定发生之事前，对此研究则分清，智者愚者之差别，事后观察即愚者。
→ 白话：一定会发生的事，提前研究清楚，这是聪明；事后才来复盘"我早知道"，这是糊涂。聪明和糊涂的分界线就在这儿。

**1.28** 智者若以善观察，精通知识是学者，鉴别牦牛之大小，愚者亦能非学问。
→ 白话：经过仔细考察才弄通的，才叫学问。一眼看出这头牦牛大、那头小，谁都会，那不算本事。

**1.29** 大海不厌河水多，国库不厌珠宝多，欲者不厌受用多，学者不厌格言多。
→ 白话：海不嫌河多，国库不嫌宝多。贪的人不嫌享受多，做学问的人不嫌好话多。

**1.30** 即使由从孩童前，智者亦要闻格言，气味芬芳之麝香，虽在兽脐亦取之。
→ 白话：哪怕是从小孩嘴里听来的道理，明白人照样学。麝香长在野兽肚脐上，位置不雅，香是真的香——取的是那条道理，不是取它的来源。
