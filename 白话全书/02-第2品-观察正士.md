# 《萨迦格言》白话全书 · 第二品 观察正士

> 体例：一行原文，一行「→ 白话」。白话只做直译＋喻体落地，不加感悟、不掺解释。
> 校验：`node check_baihua.js` 逐颂比对颂文与 `references/20-全文.md` 是否一致，并检查是否每颂都配了白话。

**2.1** 正士特意常宣扬，所有高士之功德，马拉雅山檀香味，被风传送于十方。
→ 白话：品行端正的人，总爱把别人的好处讲出去。像马拉雅山的檀香，香气被风送到各个方向——他不藏，也不独占。

**2.2** 若立正士为高官，既能成事又得乐，如宝供于幢顶上，智者称颂境吉祥。
→ 白话：让正派人当官，事情办得成，大家也得好处。像把宝珠供在幡杆顶上，有眼光的人一看就知道这地方要兴旺。

**2.3** 若被暴君残害时，则彼更为念法王，犹如众生受疫时，心里总是念雪水。
→ 白话：被横暴的上司折磨时，人反而更想念讲道理的领袖。就像瘟疫流行那阵子，谁心里都惦记着清凉的雪水。

**2.4** 遭受暴君迫害时，人主法王特护之，如当恶魔缠身时，密咒上师会摄收。
→ 白话：真到了被暴君迫害的关头，讲法的君王反而格外护着你。像人撞见邪祟缠身，这时候有本事的上师才会出手收摄。

**2.5** 正士断除微小罪，劣者大罪亦不断，犹如奶酪清除尘，酒中特为放酒曲。
→ 白话：正派人连小毛病都肯去掉，糊涂人大错也不改。一个像往奶酪里挑干净灰，一个像往酒里故意下曲——方向是反的。

**2.6** 正士虽然遭衰失，行为显得更如法，犹如火把向下垂，火焰一直向上燃。
→ 白话：正派人就算倒了霉，行事反而更守规矩。火把即使被倒着拿，火焰照样往上烧——处境可以往下，标准不必往下。

**2.7** 正士虽然住远方，亦会守护自眷属，天空密布浓云时，地上庄稼更增长。
→ 白话：正派人哪怕离得很远，也照样护得住自己人。天上乌云密布的时候，地里的庄稼反倒长得更欢。

**2.8** 名声今生欢喜因，福份来世欢喜因，此外惟有凭财富，智者绝不生欢欣。
→ 白话：好名声让人这辈子高兴，福德让下辈子高兴。只有钱这一样，聪明人绝不会拿它当快乐的本事。

**2.9** 往后应有远目光，忍苦耐劳不放逸，勤学稳重机灵者，即使奴仆亦为官。
→ 白话：往远处看、肯吃苦、不松劲，又勤学又稳重又机灵——这样的人哪怕眼下是奴仆，也能做到官位。

**2.10** 恒时欢喜发施者，名声如风传诸方，如同乞丐聚施处，愿意赠者将更多。
→ 白话：乐意一直施舍的人，名声像风一样传开。就像乞丐都往肯给的地方聚，越肯给的人，聚到手的越多。

**2.11** 若已施舍不收回，能容劣者之侮辱，受恩虽小亦不忘，此等即是圣者相。
→ 白话：给出去的不往回要，受得了混人的冒犯，别人帮过一点小忙也记着——这三条就是明白人的样子。

**2.12** 正士学问虽隐藏，声望传扬诸世界，犹如密藏豆蔻花，芬香遍于诸四方。
→ 白话：正派人的学问藏着不露，名声却传得开。像裹在里面的豆蔻花，包得再严实，香气照样飘到四面。

**2.13** 国王仅在本国大，智者处处受人敬，花朵仅是一天饰，顶宝永时受供奉。
→ 白话：国王只在自己国内算大，有智慧的人走到哪儿都被敬重。花只能戴一天，头顶的宝珠是长久供着的。判断标准是"有德"，不是"有位"。

**2.14** 弯弯树木果实多，雅驯孔雀尾屏美，驯良骏马行道快，诚挚温和智者相。
→ 白话：压弯的树都是果子多的，孔雀的尾屏好看在温顺，骏马走得快在听话。诚实、脾气好，是聪明人的长相。

**2.15** 正士常人同做事，彼二报恩却不同，于田撒下同种子，长出庄稼不相同。
→ 白话：正派人和普通人做一样的事，回报却差得远。同样的种子撒进两块地，长出来的庄稼不一样——差别在地不在种。

**2.16** 若于圣者作贤事，无论再小亦有果，犹如施一油柑果，法王待彼若王子。
→ 白话：对值得敬的人做件好事，再小也有结果。像只布施了一颗油柑果，法王却待他如同王子。

**2.17** 行为护持高门阀，若失行为则无义，诸人喜爱檀香味，烧尽成炭谁需之。
→ 白话：撑得起好门第的是品行，品行没了，门第就不值一提。人都爱檀香的味儿，烧成了炭，谁还要它？

**2.18** 大者暂虽受衰失，不必为彼生忧伤，月亮暂被罗睺食，立即将会得解脱。
→ 白话：有分量的人暂时栽了跟头，不必替他难过。月亮被罗睺（食月的魔神）咬了一口，很快就会松开——蚀不是坏了，是暂时走到影子里。

**2.19** 大者仁慈诸怨敌，则能制服怨敌众，众人敬王护他众，故彼推选为国王。
→ 白话：对敌人也能仁慈，反而能把敌人收服。大家推一个人当国王，是因为他能护住所有人——权力来自"护"，不来自"压"。

**2.20** 正士无论再困苦，不吃杂罪之食物，狮子无论再饥饿，不会食用呕吐物。
→ 白话：正派人再难，也不吃沾着罪过的那口饭。狮子饿到极点，也不会回头吃吐出来的东西。

**2.21** 正士即使遇命难，亦不舍弃善本性，真金无论再烧砍，彼色总是不会变。
→ 白话：正派人到了要命的关头也不丢掉本性。真金怎么烧、怎么砍，颜色都不会变。

**2.22** 卑者虽嗔高尚士，正士不会复发怒，胡狐发出大嚎声，兽王于彼起可怜。
→ 白话：小人冲高尚的人发火，高尚的人不接着骂。狐狸叫得再凶，狮子听了只觉得它可怜——不是被激怒，是被降级。

**2.23** 众人寻察智者过，常人不会有如是，如于珠宝寻瑕疵，谁管烬薪有裂痕。
→ 白话：大家都拿着放大镜找聪明人的毛病，对普通人却不管。珠宝才有人验瑕疵，烧过的柴谁看它裂没裂——被挑剔本身是身价。

**2.24** 不因赞称而高兴，不因辱骂而忧伤，善持自之功德者，此乃正士之法相。
→ 白话：夸他不飘，骂他不垮，守得住自己的好处——这就是正派人的标准像。

**2.25** 依罪武力所得财，怎能算为真财富，犹如猫狗虽充腹，皆是无耻之经历。
→ 白话：靠狠和脏弄来的钱，算不上真财富。猫狗也吃得肚圆，可那经历是丢人的。

**2.26** 眷属若得诸圆满，此乃长官之光彩，为马严饰缨络者，岂非主人之庄严？
→ 白话：手下人过得好，就是长官的脸面。马身上披金挂银，好看的是主人，不是马。

**2.27** 长官如何以大恩，爱护一切诸眷属，如是所有眷民众，亦对长官敬服侍。
→ 白话：上头怎么用心护着下面，下面就会怎么敬着上头。这条是双向的，护在先。

**2.28** 圣者居住之住所，谁有尊敬余学者，太阳照射天空时，星星虽多亦不见。
→ 白话：圣人在的地方，别处的学者就没人敬了。太阳一当空，星星再多也看不见。
