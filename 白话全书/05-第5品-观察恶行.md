# 《萨迦格言》白话全书 · 第五品 观察恶行

> 体例：一行原文，一行「→ 白话」。白话只做直译＋喻体落地，不加感悟、不掺解释。
> 本品是恶的形态学：伪装、无耻、恶语、暗恨、小恶滋长。
> 5.48「贱种」是 13 世纪种姓语境，取其原则：出身低微的人容易被人轻视、处境更糟，不取其对阶层的判定。

**5.1** 奸诈者虽说爱语，是为私利非真敬，亲近鸱鸮虽发笑，此乃凶兆非真喜。
→ 白话：狡猾的人说得好听，是为自己的好处，不是真敬你。猫头鹰冲你笑，那是凶兆，不是高兴。

**5.2** 劣者先用言所哄，安心之后再欺骗，渔翁先放香饵后，诱杀极多鱼类也。
→ 白话：混的人先用话把你哄踏实，等你放下戒心再骗。打鱼的人先撒香饵，之后钓上来的多得很。

**5.3** 劣者乃至弱小时，本性尚是善良者，有毒荆棘未成时，尔时不能刺伤人。
→ 白话：小人还没得势时，看着也像好人。带刺的毒荆棘还没长成，那时候扎不了人。

**5.4** 心里思维一件事，口上言说另一事，此乃名为狡猾者，亦是愚人装学者。
→ 白话：心里想一套、嘴上说一套，这叫狡猾，也是糊涂人装读书人。

**5.5** 若是极为狡猾者，暂时虽成终摧毁，驴蒙豹皮偷食禾，最后被人杀掉已。
→ 白话：太狡猾的人，眼下占了便宜，最后要栽。驴披着豹皮去偷庄稼吃，最后被人认出来杀了。

**5.6** 若是奸猾诈巧者，公开谎言能骗人，盗者山羊说为狗，婆罗门便舍山羊。
→ 白话：真会骗的人，睁着眼睛说瞎话也能骗到手。小偷把羊说成狗，读书人就把羊让给了他。

**5.7** 狡者亲自行罪恶，反以诳言欺哄人，大天口出伤叹声，骗人而说苦谛声。
→ 白话：自己作恶，反用假话哄人。像故事里的大天，故意发出叹气声，让人以为他在念"苦谛"——把恶行包装成修行。

**5.8** 狡者伪装语甜蜜，未经观察勿轻信，孔雀身美声悦耳，然彼所食皆为毒。
→ 白话：狡猾的人话说得甜，没看清之前别信。孔雀好看也好听，可它吃的是毒虫。

**5.9** 狡者伪装老实人，一旦他会引诱人，无耻之人卖驴肉，先用兽尾让人看。
→ 白话：装老实的人，一旦动手就是引人上钩。不要脸的人卖驴肉，先把驴尾巴挂出来给人看——用一点真东西钓整笔假买卖。

**5.10** 有些寡廉鲜耻者，以他财物装门面，如同友衣当座垫，以表对客之尊敬。
→ 白话：有人拿别人的东西撑自己的场面。像把朋友的外套铺在地上当坐垫，用来招待客人——客气是做了，用的是人家的。

**5.11** 本来稍无羞耻者，丑事亦是当光荣，甘存地方诸王族，擂鼓庆贺杀父者。
→ 白话：脸皮厚到一定程度，丑事也当光荣事。像某些地方的王族，杀了父亲还击鼓庆祝。

**5.12** 愚者虽作有利事，有些亦成大祸根，如同雏鹊拔母羽，尚自以为报母恩。
→ 白话：糊涂人也在"为你好"，可有些做法是大祸。像小喜鹊给母鸟拔羽毛，还以为自己在报恩。

**5.13** 有些薄情寡义者，他恩所得装门面，龙王勤降之雨水，农夫以为自福德。
→ 白话：没良心的人，把别人给的恩惠拿来充自己的面子。像龙王辛苦下的雨，农夫当成是自己的福报。

**5.14** 愚者以业享福时，以为自己精勤果，啃骨刺破上颚血，老狗当作骨髓精。
→ 白话：糊涂人靠旧业享福，却以为是自己的努力。老狗啃骨头，上颚被刺出血，满嘴红还当是吃到了骨髓。

**5.15** 有些愚者夺亲人，仅为养活无关人，如于砍首严饰尾，除非疯人谁肯为？
→ 白话：有人坑自家人，只为养活不相干的人。头都砍了还去装饰尾巴，除非疯了谁干这种事？

**5.16** 愚者不至所需处，反而常诣无用外，无用泉水夏天流，春天需水时干涸。
→ 白话：糊涂人该去的地方不去，净往没用的地方跑。没用的泉水夏天哗哗流，春天要用水时它干了。

**5.17** 对于善良之正士，劣者特别会欺凌，如同火舌会焚烧，含油灯芯非余尔。
→ 白话：好人反而最招小人欺负。火苗专烧泡了油的灯芯，不烧别的东西。

**5.18** 粗者方能调粗暴，温者对此怎调伏？拔除痈疽须炙割，和缓治疗将毒化。
→ 白话：对付横的人得用硬手段，温和的那一套对他没用。大疮要灸要割，慢慢敷药只会让毒散开。

**5.19** 国王依法当护国，否则彼将会衰败，太阳若不除黑暗，则定彼受罗睺食。
→ 白话：君王得按规矩护住国家，不然自己先垮。太阳要是照不亮黑暗，就轮被罗睺吞掉。

**5.20** 若在恶人当管下，或速坍塌楼房下，或将崩溃山峰下，则会时时常生惧。
→ 白话：落在坏人管下、住在快塌的楼下、走在要崩的山下，这三处的人天天提心吊胆。

**5.21** 即使具有高智慧，性情恶劣亦被舍，毒蛇顶上虽饰宝，智者谁肯抱怀里？
→ 白话：本事再大，脾气坏到极点也没人跟他来往。毒蛇头上镶了宝，谁肯把它搂在怀里？

**5.22** 有些国王如烈火，亲近彼难满其愿，疏远亦惧不摄收，不亲不疏亦畏惧。
→ 白话：有的君王像火：凑上去，怎么都填不满；离远了，又怕他不收留；不亲不疏，照样害怕。

**5.23** 劣妻恶友及暴君，此三谁人肯亲近，猛兽横行之林中，智者谁人常安住？
→ 白话：坏伴侣、恶朋友、暴君，这三样谁愿意靠近？猛兽乱跑的林子，明白人不会常住。

**5.24** 傲慢令人变无知，贪欲令人变无耻，若常轻视自眷仆，则此长官定衰败。
→ 白话：傲慢把人变成没脑，贪欲把人变成不要脸。当头的要是长期瞧不起自己手下，这个头一定做不长。

**5.25** 有利之语说者少，听受彼言更为少，高明医师极难得，遵医嘱行者更少。
→ 白话：肯说有用话的人本来就少，肯听的人更少。好医生难得，照医嘱吃药的人更少。

**5.26** 过越狂妄自大者，不断遭受诸痛苦，狮子极为傲慢故，狐狸让它背象体。
→ 白话：狂妄过头的人，苦就没断过。狮子太自大，被狐狸哄去背整头大象。

**5.27** 乌鸦埋藏之食物，或为恶人谋福利，或于瘠田撒种子，此等望多受益少。
→ 白话：乌鸦藏的食物多半便宜了别人；替坏人谋好处也是白费；在瘦田里撒种，指望得多收成得少。

**5.28** 若无详细观察前，对谁亦不应信任，放逸之中出过错，亲友往往成怨仇。
→ 白话：没看清之前，谁都别全信。一松劲就出事，最亲的人常常变成最狠的对手。

**5.29** 世上劣物虽众多，然无劣人更可恶，其余劣物可改造，改造劣人除非灭。
→ 白话：坏东西很多，但没有比坏人更难缠的。东西坏了能修，人坏了除非他自己完蛋。

**5.30** 虽用百种知识来，助利劣者亦不喜，凡诸亲近人成敌，此乃劣者之特征。
→ 白话：用一百种办法帮他，他还不领情。谁靠近他谁变成他的敌人——这就是混人的标志。

**5.31** 劣者无论再改造，性情不会变贤善，煤炭无论再改造，其色无法变雪白。
→ 白话：小人怎么调教，性子也变不成好的。煤怎么洗，也洗不白。

**5.32** 遭受恶人所欺处，遇见贤人亦会舍，如被毒蛇所害处，虽见金链亦逃避。
→ 白话：被坏人骗过的人，连好人也会躲开。在蛇那儿吃过亏，看见金链子也要跑。

**5.33** 恭敬之境即圣者，恭敬劣者即祸根，乳汁对人是甘露，若喂毒蛇则增毒。
→ 白话：该敬的是圣人，敬小人招祸。奶对人像甘露，喂给毒蛇反倒让它更毒。

**5.34** 纵使设法依劣者，然而不会成齐心，如同麻雀再喂养，彼亦不会安心住。
→ 白话：你千方百计对小人好，也拢不到一条心。麻雀喂得再好，它也不肯在你家里安心住下。

**5.35** 时常精勤分裂者，甚至好友亦离开，如同河水常冲刷，岩石亦会出裂缝。
→ 白话：成天忙着拆台挑拨，再好的朋友也会走。水一直冲，石头也会裂。

**5.36** 自己骗人或害他，或谈上师友等过，彼等若假不必信，或若真实令人惊。
→ 白话：当着你面骗你、害别人，或者讲师父朋友的坏话——这些话是假的就别信；要是真的，这人更可怕。

**5.37** 本来不应所说事，他人之前谁讲说？无论虚假或是真，智者对此当小心。
→ 白话：不该说的事，谁在他面前讲？不管真假，明白人对这种人都得防着。

**5.38** 贪欲财富之劣者，虽是亲友勿信赖，大人面前受贿赂，多被亲友毁灭之。
→ 白话：贪财的人，就算是亲戚也别托底。他们到有权的人那儿告状，多半是自家亲友先被拖垮。

**5.39** 口说害人之语者，此等怨敌易制服，心恨口说利人者，此等怨敌难制服。
→ 白话：嘴上就说要害你的，好对付。心里恨你、嘴上净说为你好的，最难对付。

**5.40** 巧治余痕能愈合，恶语创伤难复愈，如同乌鸦谤鸱鸮，累劫彼此成仇恨。
→ 白话：伤疤好好治也能长平，被恶话刺出来的伤很难好。像乌鸦和猫头鹰互相毁谤，多少代都成死仇。

**5.41** 心里总是挂仇恨，嘴上尽说善妙语，此乃恶劣仙人教，即违圣者之法则。
→ 白话：心里装着恨，嘴上全是好话。这是坏人的路数，跟圣人的规矩正相反。

**5.42** 王规论中虽宣说，一切怨敌全消灭，应如拔除毒树根，然爱如子待如父。
→ 白话：治国书上说要彻底清除敌人，像拔掉毒树的根；但对人还得像父亲爱儿子那样。狠在事上，不在心上。

**5.43** 专门力求私利者，谁肯与彼交为友，农夫勤耕田地中，难以成长余杂草。
→ 白话：一心只谋自己好处的人，谁愿意跟他交朋友？农夫勤耕地，田里就长不出杂草——反过来，人只为自己，身边就没人。

**5.44** 何人不知报恩惠，谁肯与彼交为友，勤劳亦无熟果地，农夫谁肯去耕耘？
→ 白话：不懂报恩的人，谁跟他来往？一块再怎么种也不结果的地，没有农夫愿意去耕。

**5.45** 蛮横又是鲁莽者，此人速将遭失败，厚颜野象极横暴，岂非急受被阉割？
→ 白话：又横又莽的人，败得最快。脸皮厚的野象越凶，越会被牵去阉掉。

**5.46** 如何布施恶劣者，自需之时不回报，钳子虽常夹铁球，铁球怎能夹钳子。
→ 白话：给坏人好处，等他该出力的时候不会还你。钳子天天夹铁球，铁球什么时候夹过钳子？

**5.47** 劣者借口为利他，反而行持罪恶事，是为假装利众生，智者谁肯毁自己？
→ 白话：小人打着"为你好"的旗号作恶。嘴上说利益众人，明白人谁会为了这种话把自己搭进去？

**5.48** 债务尾数余恨敌，恶劣刑法恶语论，贱种以及劣行为，彼等自然会滋长。
→ 白话：欠债的零头、剩下的怨敌、糟糕的刑法、难听的争论、出身低微、恶劣行为——这六样都会自己往上长，不处理就越来越多。【"贱种"是13世纪种姓语境，取其原则：处境差、被人轻视的类别会自我繁殖，不取其对出身的判定】
