# 《萨迦格言》白话全书 · 第六品 观察性情

> 体例：一行原文，一行「→ 白话」。白话只做直译＋喻体落地，不加感悟、不掺解释。
> 本品讲人性与处境：傲慢、贪欲、亲疏、盛衰、多语、嗔。
> 6.56「男汉以及妇女」是 13 世纪同类比较的表述，取其原则：同一起点的人高下差别极大，不取性别判定。

**6.1** 设若何人当长官，难以了知自过失，如眼能见诸余法，观察自体需镜子。
→ 白话：当了头的人，最难看清自己的毛病。眼睛能看见别的东西，要看自己得靠镜子。

**6.2** 仅有一方智慧者，亦难精通一切事，极为敏锐之眼睛，亦是不能见声音。
→ 白话：只在一个方面聪明，不可能样样精通。眼睛再利，也看不见声音。

**6.3** 有时实话成过失，歪曲之语成功德，笔直道中亦遭难，右旋海螺成吉祥。
→ 白话：有时候实话反倒惹祸，绕着说倒成了得体。笔直的路照样让人摔倒，右旋的海螺却当吉祥物。

**6.4** 若无福分光有学，学问即将毁自己，犹如蚌壳有珍珠，因此彼者送性命。
→ 白话：没有护得住的运气，只有学问反而会害了自己。蚌壳里含着一颗珍珠，就为这个被人撬开丢了命。

**6.5** 过分亲近有学者，多半亦会生厌烦，如同甘蔗极甜美，若常食用则厌弃。
→ 白话：跟聪明人贴得太紧，多半会惹人烦。甘蔗再甜，天天吃也会腻。

**6.6** 性情尽管善良者，若常折磨亦生嗔，犹如檀香本清凉，若常磨擦亦燃烧。
→ 白话：脾气再好的人，被反复折磨也会翻脸。檀香本是凉的，磨得太久照样起火。

**6.7** 天下国王虽众多，依法护国极少数，天上神仙虽众多，无如光明日月轮。
→ 白话：世上国王多，按规矩护住百姓的极少。天上的神多，都不如日头月亮亮堂。

**6.8** 何人能作害人事，彼者亦有利人力，如能折砍人头王，彼王亦能施国政。
→ 白话：有能力害人的，也就有能力利人。敢砍人头的君王，也治得了一国政事——本事是中性的，看往哪头用。

**6.9** 具慧正直之大臣，能成君民诸事业，如同巧者射直箭，瞄准何处皆中鹄。
→ 白话：又有智慧又正直的大臣，能把君王和百姓的事都办成。像好射手放直的箭，瞄哪儿中哪儿。

**6.10** 若王何人不理睬，全知亦无人尊敬，如同离开命根时，尸体再妙有谁取？
→ 白话：君王谁都不搭理，就算什么都懂也没人敬。像人断了气，尸身长得再好谁要？

**6.11** 倘若众人一齐心，弱者亦能成大事，如蚂蚁曾聚成群，最后弑杀幼狮也。
→ 白话：人一齐心，弱的也能办成大事。蚂蚁成群，最后咬死了小狮子。

**6.12** 胆怯不肯勤奋者，虽有强力亦衰败，犹如大象力虽大，牧童役彼使作仆。
→ 白话：胆小又不肯下力的，条件再好也要败。大象力气那么大，照样被放牛的使唤。

**6.13** 充满自信精进者，强者亦能被胜伏，海螺躯体虽渺小，而能啖食摩羯鱼。
→ 白话：敢持续下手的人能赢过强者。海螺那么小，却吃得下大鱼。

**6.14** 大者无须自傲慢，劣者傲慢有何用？真宝不用语夸赞，假宝再夸亦谁买？
→ 白话：真有分量的人不用自己吹；没分量的人吹有什么用？真宝贝不用夸，假的夸上天谁买？

**6.15** 圣者财富能长久，劣者发财速衰失，太阳时常放光芒，月过望日便薄蚀。
→ 白话：明白人的财路能长久，混的人来得快去得也快。太阳天天亮，月亮一过十五就开始亏。

**6.16** 国王过越赞地位，则彼最后将毁灭，如同鸡蛋扔高空，最后必定摔粉碎。
→ 白话：君王把自己地位捧得越高，最后摔得越惨。像把鸡蛋往高空扔，落地必碎。

**6.17** 世上多半士夫众，常受同类所损害，如同阳光普照时，星宿皆成无踪影。
→ 白话：大多数人常常是被同行、同辈拖累的。太阳一出，星星全看不见。

**6.18** 若利敌人亦接近，若害亲人亦远离，海宝虽远亦购买，腹疼虽近亦治疗。
→ 白话：能对自己有好处的，就算是敌人也要靠近；会伤自己的，就算是亲人也要疏远。海底的宝再远也去买，肚子疼离自己再近也得治。

**6.19** 内有稍微财富时，便外露出傲慢相，如同饱含雨水时，浓云飘动雷声响。
→ 白话：肚子里刚有点货就摆架子。云吸饱了水，就飘着打雷。

**6.20** 具足诸德者极少，无有微德者亦少，德过混为一起时，智者依止多德者。
→ 白话：全是优点的人极少，一点优点没有的人也少。多数人好坏掺在一起，那就挑好处占多的来往。

**6.21** 最初尚未了解时，无法肯定敌或友，食不消化变为毒，认清毒亦变良药。
→ 白话：还没摸清之前，说不准谁是敌谁是友。吃下去不消化就成了毒，摸清了毒性反倒能入药。

**6.22** 何处有缘彼兴盛，若无业缘彼衰退，野鸭屋中不肯住，从湖驱彼亦返回。
→ 白话：跟哪儿有缘分，就在哪儿兴旺；没缘分，怎么都留不住。野鸭不肯住屋里，从湖里赶它，它还是飞回湖。

**6.23** 智者花钱求学问，愚者虽学亦舍弃，众人生病即服药，有人亦会自杀也。
→ 白话：聪明人掏钱去换学问，糊涂人学到手又扔掉。人生病都吃药，也有人偏要自己寻死。

**6.24** 诸有自由即安乐，诸无自由即痛苦，共同即是争论根，誓愿即是束缚因。
→ 白话：能做主就自在，做不了主就苦。跟人合伙是吵架的根，许下的愿是绑住自己的绳。

**6.25** 即使内具诸学问，装束褴褛受人欺，如同蝙蝠有本事，无羽之故被鸟弃。
→ 白话：肚里有学问，穿得破烂照样被人轻看。蝙蝠有本事，因为没羽毛，鸟都不认它是同类。

**6.26** 非应之处若正直，往往毁他亦毁己，如同直箭毁他人，或者毁坏自己也。
→ 白话：在不该直的地方硬要直，往往伤了别人也伤了自己。箭射出去，可能中别人，也可能扎自己。

**6.27** 雨水江河入大海，智者方有智慧心，国王能集财眷民，温湿之处长丛林。
→ 白话：雨水和江河都往海里汇。有智慧的人聚得住东西，君王聚得住钱财、人手、百姓，潮湿的地方长得成林子——东西都往能装它的地方去。

**6.28** 夏天泉水燃草火，云间太阳十五月，愚者学问恶劣友，需时不定能用上。
→ 白话：夏天的泉水、烧草的火、云里的太阳、十五的月亮，还有糊涂人的学问、坏朋友——这六样都靠不住，真要用的时候不一定在。

**6.29** 愚者少说极为佳，国王深居极为妙，魔术偶尔观为奇，珍宝罕见亦为贵。
→ 白话：糊涂人少开口最好，君王少见人最好。戏法偶尔看才叫奇，宝贝少见才值钱。

**6.30** 倘若过分慈爱者，亦会变成仇恨因，世人众多之纠纷，亦从相属而产生。
→ 白话：好得过了头，也会变成结仇的原因。世上多半的纠纷，都出在原本亲近的关系里。

**6.31** 即使激烈之争论，亦会变成友爱因，常见争论之结局，多以和解而告终。
→ 白话：再激烈的争吵，也可能变成交情的起点。吵到最后，多半是握手。

**6.32** 悭吝富人之财物，嫉妒心重之友伴，卑劣恶人之理智，彼等不会令人喜。
→ 白话：小气的有钱人、爱嫉妒的伴、坏人的那点理智——这三样没人受用。

**6.33** 贪者得财即欢喜，慢者夸奖即欢喜，愚者同行即欢喜，正士讲实即欢喜。
→ 白话：贪的人给钱就高兴，傲的人夸他就高兴，糊涂人有人陪就高兴，正派人听到实话才高兴。

**6.34** 卑劣恶人之学问，胆怯士夫之理智，横暴长官之恩惠，彼等难以利他人。
→ 白话：坏人肚子里的学问、胆小鬼的理智、暴官的恩典，都帮不了人。

**6.35** 有财人语皆入耳，无财讲实亦不闻，如同产自玛拉雅，即使朽木亦贵重。
→ 白话：有钱人说什么大家都爱听，没钱人说实话也没人理。像产自马拉雅山的东西，哪怕是块烂木头也值钱——值钱的是产地，不是木头。

**6.36** 多语即是过患因，少语即是除过根，解语鹦鹉进笼中，喑哑飞禽均自由。
→ 白话：话多是惹祸的根，话少是避祸的法子。会说话的鹦鹉被关进笼子，不会叫的鸟都自在。

**6.37** 何人若于怨敌前，经常无欺而饶益，则敌亦会如是敬，此乃诸法之规律。
→ 白话：一个人能长期不掺假地对手下人好，连敌人都照样敬他。事情本来就是这个规律。

**6.38** 弱者发怒有何用？强者为何起嗔恚？是故为办事务时，若生嗔恨即自焚。
→ 白话：弱的发起火来有什么用？强的何必动气？所以办事的时候生气，等于先烧自己。

**6.39** 有施敌人亦自聚，无施亲人亦远离，犹如母牛尽乳时，虽持牛犊亦离开。
→ 白话：肯给，敌人也会聚到你身边；不给，亲人也会走。母牛没奶的时候，就算小牛在跟前它也走掉。

**6.40** 即使精通某些事，不定了知余一切，如鹅虽能辨水乳，仍自身影为食物。
→ 白话：精通一件事，不等于什么都懂。鹅能把水和奶分开，却把自己的影子当吃的。

**6.41** 主人经常爱护人，则彼易得自眷仆，如于莲花盛开湖，水鸭亦会自然聚。
→ 白话：当头的常护着人，手下就容易拢住。莲花开满的湖，水鸭自己会来。

**6.42** 富人广施自享受，学者温雅又善良，大者爱护卑劣众，此三利他亦益己。
→ 白话：有钱又肯舍肯享受、有学问又和气善良、有地位又爱护底下人——这三种人帮了别人也成全了自己。

**6.43** 若依福德成诸事，如同阳光不依余，若依精勤成事业，如同灯光仍依余。
→ 白话：靠福分成事，像阳光不用添油；靠苦拼成事，像点灯还得有人添油护着。

**6.44** 倘若依止高尚士，劣者亦会得高位，如同藤蔓依大树，一直盘绕于树顶。
→ 白话：肯跟着高尚的人走，混的人也能爬到高位。藤靠着大树，一路绕到树顶。

**6.45** 有学之士虽有过，爱学之人尚依止，如同雨水虽害屋，世间之人令生喜。
→ 白话：读书人也有毛病，爱学问的人照样跟他学。像雨水也会漏坏屋顶，可地里还是靠它长庄稼。

**6.46** 若无学问凭装束，智者不能生欢喜，如同骏马不奔驰，虽美亦为无价值。
→ 白话：没学问只靠穿戴，明白人不会看重。马长得再漂亮不跑，也不值钱。

**6.47** 愚者当中富翁多，猛兽群中有英雄，世上学者正士中，能出格言极罕见。
→ 白话：糊涂人里有钱的多，猛兽里有英雄，可在读书人和正派人里，能留下几句好话的极少。

**6.48** 何人具有何本领，彼人亦闻彼声誉，学者能闻智者名，英雄能闻英勇名。
→ 白话：你有什么本事，就听得见谁的名声。读书人认得聪明人的名字，勇士认得勇士的名字。

**6.49** 诸大能人行供时，劣者对此会轻蔑，如同自在天顶饰，却被非天所食也。
→ 白话：有大本事的人被人供奉，小人反而瞧不起。像神头顶上的装饰，却被魔吃了——好东西落在看不懂的人那儿就是糟蹋。

**6.50** 书卷当中之学问，尚未修成之密咒，健忘者之学处等，需用之时常诱人。
→ 白话：只存在书里的学问、还没修成的咒、记性差的人学过的那些东西，真要用时都靠不住，只会勾着你以为自己有。

**6.51** 纵有智慧具财富，懒汉难以得高位，如耳虽是先长出，岂能高超角顶矣？
→ 白话：又聪明又有钱，只要懒，也上不去。耳朵虽然先长出来，位置却高不过头顶的角。

**6.52** 猪狗香味有何用？盲人灯火有何用？停食者食有何用？愚者正法有何用？
→ 白话：猪狗闻不出香，盲人用不上灯，断食的人不能吃，糊涂人听不进道理——这四样给了也是白给。

**6.53** 深慧学者纯黄金，沙场英雄胜骏马，善巧医师妙饰品，赴于何处受欢迎。
→ 白话：见识深的学者像纯金，战场上的英雄像好马，高明的医生像顶好的首饰——这种人走到哪儿都受欢迎。

**6.54** 若有智慧精进者，则彼怎不成诸事？如班图子曾消灭，十二兵队俱卢族。
→ 白话：又有脑子又肯下手的，怎么会办不成事？像故事里班图家的儿子，一个人灭了对面十二支军队。

**6.55** 所有儿孙之行为，皆为跟随前祖辈，如小杜鹃随鹞子，此乃即是少见也。
→ 白话：儿孙的做派都是跟着长辈学的。小杜鹃跟着鹰长大，这倒是少见——环境能改习性，但极少改得动。

**6.56** 山岳河水大象马，树木光耀珍宝石，男汉以及妇女等，虽是同类异胜劣。
→ 白话：山、河、象、马、树、光、宝石，还有男女——同一类里，好和差的能差出十万八千里。【13世纪同类比较的表述，取其原则：起点相同不等于结果相同，不取性别判定】

**6.57** 有福之人说一句，弱者对此亦难当，如同果札王一言，加措国王被束缚。
→ 白话：有分量的人说一句，分量轻的人根本扛不住。像果札王一句话，就把另一个国王捆住了。

**6.58** 虽勤承办一切事，真得成功靠福份，犹如商人入海中，未得之宝在王库。
→ 白话：再拼命把事都办了，真到手还得看运气。像商人下海找宝，那颗宝却在国王的库里。

**6.59** 愚者爱憎易推知，智者爱憎却相反，老狗微笑知彼欣，阎王微笑即杀众。
→ 白话：糊涂人高兴讨厌一眼就看得出，明白人正相反。老狗咧嘴是真高兴，阎王咧嘴是要杀人。

**6.60** 最胜财物即施舍，最胜安乐心舒畅，最胜装饰闻正法，最胜之友诚实者。
→ 白话：最值钱的财产是能舍出去的那份，最踏实的安乐是心里不堵，最好的装饰是听过道理，最好的朋友是不骗你的人。

**6.61** 谁人不为财所苦？谁人永时住安闲？一切安乐及痛苦，如同冬夏而循环。
→ 白话：谁没为钱苦过？谁能一直清闲？安乐和痛苦像冬天夏天一样轮着来。

**6.62** 弱者仅提强者名，他人亦会守护彼，如人唯说指鬘名，众多邪魔保护之。
→ 白话：弱小的人只要报出强者的名字，别人也会让着他。像只提那个凶人的名号，连魔都护着他。

**6.63** 众生谁与谁相属，皆由前世业所感，犹如鹰鹫背旱獭，水獭供养鸱鸮矣。
→ 白话：谁跟谁缠在一起，都说前世结下的缘。像老鹰驮着旱獭，水獭反倒喂猫头鹰——关系常常不讲道理。

**6.64** 若欲积累受用者，增时发施最殊胜，若欲河水引进塘，放水养池是良方。
→ 白话：想攒东西，最好的办法是在进账时舍出去一点。想把河水引进塘，得先把塘里的水放掉腾出地方。
