# 《萨迦格言》白话全书 · 第八品 观察事业（上：8.1—8.48）

> 体例：一行原文，一行「→ 白话」。白话只做直译＋喻体落地，不加感悟、不掺解释。
> 本品讲做事之法：协议、择友、用人、收税、施政、柔刚。

**8.1** 智者虽办极小事，亦经协议方为之，其事成功何堪言，若遭失败亦为妙。
→ 白话：明白人就算办极小的事，也要先商量清楚再动手。办成了不用说，万一办砸了，因为事先讲明过，也好收场。

**8.2** 众生种种意乐故，诸众满意极难为，设使自己具学问，诸众欢喜并亲近。
→ 白话：每个人的心思都不一样，让所有人满意几乎不可能。真要有本事，让大家高兴又愿意靠近，才办得到。

**8.3** 即使十分衰老时，也要广学而博闻，闻慧有益于来世，布施亦无如是益。
→ 白话：老到不行了也要多学多听。听来的智慧对将来有好处，连布施都比不上这一点。

**8.4** 当依功德圆满士，或者结交平凡人，如同携带满水瓶，或者易携无水瓶。
→ 白话：要么跟功德齐全的人学，要么结交普普通通的人。就像要么提一瓶满水，要么提一瓶空水——半瓶水最难提。

**8.5** 一知半解学问者，谁人肯去依止彼，如装一半水之瓶，谁肯携带于头顶？
→ 白话：一知半解的人，谁愿意跟着他学？装一半水的瓶子，谁愿意顶在头上？

**8.6** 何人了知能辨别，智者愚者之差别，并能承办彼等事，此乃一切圆满根。
→ 白话：能分清谁是聪明人谁是糊涂人，并且按各自的特点安排事做——这是一切成事的根。

**8.7** 若经智者善培育，愚者亦会变高尚，犹如有师教言辞，鹦鹉亦会诵论典。
→ 白话：教得好，糊涂人也能变高尚。像有人一句句教，鹦鹉也能背出经文。

**8.8** 即使无力虚弱者，若依强者亦成事，如同水滴虽渺小，汇入大海永不涸。
→ 白话：再弱的人，挂到更强的系统上也能成事。水滴虽小，进了海就再也干不了。

**8.9** 倘若自己无理智，应当询问余智者，如手不能杀敌时，此人岂非取武器？
→ 白话：自己想不明白，就去问想得明白的人。手不够用时，不就得去抄家伙吗？

**8.10** 纵使害己之怨敌，若巧方便亦成友，剧毒对身虽有害，若知搭配成良药。
→ 白话：就算是害过你的敌人，办法对了也能变成帮手。剧毒伤身，配伍得当就成了药。

**8.11** 可取应得之食财，当除贪图不应财，如同可摘树上果，若超树梢则堕地。
→ 白话：该拿的坦然拿，不该拿的别贪。像伸手摘得到的果子，踮脚去够树梢以外的，只会摔下来。

**8.12** 设若智者不谨慎，此时彼生诸过患，设若智者极谨慎，则难发生诸过患。
→ 白话：聪明人一松劲，毛病全冒出来；聪明人真谨慎起来，祸事很难找上门。

**8.13** 其余论典中宣说，乃至势力未充足，尔时应当敬敌众，何时充力随意行。
→ 白话：别的书上说过：实力还不够时，先敬着对手；等攒够了，你说了算。

**8.14** 怨敌说得再悦耳，智者亦不应轻信，鱼鹰猫儿虽温柔，时常竭力杀余生。
→ 白话：敌人话说得再好听，也别当真。鱼鹰和猫看着温顺，抓别的生灵时一点不手软。

**8.15** 地主虽为嗔恚者，亦应悦意而亲近，如于地上虽滑倒，尚需依靠此地也。
→ 白话：管地盘的人就算脾气坏，也得和和气气相处。你在这块地上摔过跤，往后还得靠这块地站着。

**8.16** 若人过越贪欲妙，则彼将会速毁己，如同鱼众贪钩饵，立即彼等遭杀也。
→ 白话：贪得过头，很快把自己搭进去。鱼咬钩上那口饵，当下就没命。

**8.17** 对于应供或眷众，时常布施方能聚，如同施放供品者，神鬼皆乐而护之。
→ 白话：该敬的人和自己人，要常给好处才拢得住。像摆供品的人，神和鬼都高兴着护他。

**8.18** 大者当除游戏乐，亦断贪图食乐等，由贪所引之果报，楞伽罗刹王遭杀。
→ 白话：有地位的人该戒掉玩乐和口腹之欲。贪招来的果报——故事里的罗刹王楞伽罗就死在这上头。

**8.19** 高士方可慈与诤，劣者绝不应如此，如同珍宝有销赎，谁有毒药为如此？
→ 白话：只有正派人才有资格跟你讲交情、也能跟你吵；混的人不能这样。珍宝坏了能修能赎，毒药谁能这么处理？

**8.20** 国王为税勿广收，微财渐能积满仓，蚁垤蜂蜜上弦月，皆是由微而圆满。
→ 白话：收税别贪多。一点点攒也能堆满仓库——蚂蚁窝、蜂蜜、上弦月，都是一点点长满的。

**8.21** 国王不害诸眷民，并以合理收赋税，芸香树中之香脂，若过流淌则枯干。
→ 白话：不害自己人，按合理额度收税。芸香树的胶脂流得太狠，树就枯了。

**8.22** 国王应当极温和，不因小事而发怒，如同毒蛇虽有宝，智者谁肯近身旁？
→ 白话：当头的要温和，别为小事发火。毒蛇嘴里含着宝，谁敢靠近它？

**8.23** 纵使贪图财富者，亦应守护法为重，若坏法规虽得财，则此今世怎恒久？
→ 白话：就算再想钱，也得把规矩摆在头一位。坏了规矩挣来的钱，这辈子也守不长。

**8.24** 对戚亦勿过越亲，对敌亦勿过越恨，欲望亲友结怨因，对怨报复皆易行。
→ 白话：对亲戚别亲到没边，对敌人也别恨到没边。贪欲是让亲友变仇人的引子，而报复仇人反倒容易得很。

**8.25** 柔和既能胜柔和，柔和又能胜粗暴，柔和能成一切故，智者皆云柔最利。
→ 白话：温和能对付温和的人，也能对付粗暴的人。温和能成事，所以明白人都说柔软最锋利。（须配 8.34 的边界：手段随对象变，发心才恒慈）

**8.26** 不论谁为吾之敌，不说谁人不慈吾，虽不仁慈亦不言，一言即将成裂痕。
→ 白话：别到处说谁是你的敌人、谁对你不好。就算他真不仁，你也别说——一句话说出去，裂缝就定下了。

**8.27** 不顾惭愧与羞耻，不知敬蔑之差别，惟有贪图财食者，不应住于彼等处。
→ 白话：不要脸、分不清被敬和被蔑、只惦记吃钱——这种人的地方，别去待。

**8.28** 若未观察新境前，则彼不应弃旧境，一足尚未立稳时，若举双足定跌倒。
→ 白话：新环境没摸清之前，别急着甩掉旧的。一只脚还没站稳就把两只脚都抬起来，一定摔。

**8.29** 竭力隐藏自诸行，公之于众会遭殃，猴子设若不演戏，何必其颈系绳索。
→ 白话：尽量把自己的事藏住，摊开给人看会招祸。猴子要是自己不耍把戏，谁拿绳子拴它脖子？

**8.30** 即使现量见过患，若非合境不应说，世间众说见恶兆，最终见者自遭殃。
→ 白话：就算亲眼见过祸事，场合不对也别讲。人人都嚷嚷自己看见了凶兆，最后倒霉的是说的那个。

**8.31** 他人说笑之财食，彼等虽有亦何用？犹如猪狗食粪便，学者谁人有想望？
→ 白话：别人拿来开玩笑的那种财食，有又怎样？猪狗吃粪，明白人谁会眼红？

**8.32** 伤害他人之恶语，即使怨敌亦勿说，否则如同谷回声，立即自受报复也。
→ 白话：伤人的话，对仇人也不要说。像山谷里的回声，喊出去什么就收回来什么。

**8.33** 若欲损害诸怨敌，首先自应具功德，如是则能毁彼心，自己亦能增福分。
→ 白话：想收拾对手，先把自己本事练足。这样既能伤他的心，自己也添了福分。

**8.34** 发心仁慈暴行为，方能制服野蛮众，如同欲利自身者，以粗疗法而除疾。
→ 白话：心是好的、手段可以硬，才治得住蛮横的人。像想让自己好起来，得用猛药除病。

**8.35** 能害之事虽微小，亦应速治而和解，常见巨大之壕沟，起因即为小渠水。
→ 白话：会惹祸的事再小也要马上处理、马上和解。那些又深又大的沟，起初不过是一小股水冲出来的。

**8.36** 凡不合理之诸事，智者虽会亦不为，如同大象摧敌众，时常遭受王之缚。
→ 白话：不合道理的事，会做也不做。大象能冲垮敌阵，可它照样被国王拴住。

**8.37** 亲友虽恨亦莫弃，敌众虽慈亦莫喜，乌鸦互相虽受害，若依鸱鸮即遭殃。
→ 白话：亲人就算跟你别扭也别丢，敌人就算对你好也别高兴过头。乌鸦互相闹，但真去依靠猫头鹰，那就是送命。

**8.38** 事情无论大或小，智者恒为谨慎做，狮子扑杀象兔时，相同对待无松紧。
→ 白话：大事小事都按同一份认真去做。狮子扑兔子和扑大象，用的力气一样，不因为事小就松手。

**8.39** 若不尊重学者处，学者谁愿住此境？水晶若当火石处，则此谁愿卖水晶？
→ 白话：不敬重读书人的地方，读书人谁肯留？把水晶当打火石卖，谁还愿意把水晶拿出来？

**8.40** 智者或为人讲经，或者静处自修行，如同宝石或顶饰，或者住留海岛中。
→ 白话：明白人要么出来给人讲，要么自己安静待着。像宝石，要么戴在人头上的，要么留在海岛里——不必两头都要。

**8.41** 设若依止高尚士，则对自己有大益，住于山王之鸟群，彼等显成金色也。
→ 白话：跟着高尚的人走，对自己是大好处。停在雪山上的鸟，羽毛都显出金色来。

**8.42** 若依嫉妒心重者，则将自己不成名，如同靠近太阳故，月亮由盈变薄蚀。
→ 白话：跟爱嫉妒的人搅在一起，你的名声就毁了。像月亮靠太阳太近，圆了就开始亏。

**8.43** 何人友爱不坚定，谁愿与彼交为友，空中彩虹虽美妙，望其装饰即愚昧。
→ 白话：交情不牢靠的人，谁愿意跟他做朋友？彩虹再好看，想摘下来当装饰就是傻。

**8.44** 自己不喜之诸事，切莫强行让人作，当思他人对自己，损害之时有何感？
→ 白话：自己不喜欢的事，别硬塞给别人。想想别人这么对你的时候，你是什么滋味。

**8.45** 何事自己所喜爱，彼事让人亦可为，因此自己所喜事，他人亦会来承侍。
→ 白话：自己喜欢的事，也可以让别人去做。你喜欢的，别人也乐意来帮你办。

**8.46** 智者对于蛮横众，既不交亲亦不争，如同粗暴之老虎，不应结怨及交友。
→ 白话：对蛮横的人，既不套近乎也不结仇。像暴烈的老虎，别跟它做朋友，也别跟它结怨。

**8.47** 依止一切高尚士，学者之前常询问，交结义重情长者，谁具此等则常乐。
→ 白话：亲近所有高尚的人，在懂行的人面前多问，跟讲义气、念旧情的人来往——做到这三样的人，常是快活的。

**8.48** 谁说不合应时语，则彼众人会欺凌，语无伦次喋喋者，岂非推知疯人矣？
→ 白话：说话不看场合的人，谁都能欺负他。语无伦次说个没完，别人直接当他是疯子。
